# RFL — 强化反馈学习研究快照

这是截至 **2026-11-12** 的活动项目工作区快照，包含此前已提交的内容及本地尚未提交的研究代码、数学笔记、实验方案和结果。它不是一个已经证明普遍优于强化学习的算法发布版。

## 当前研究在做什么

研究如何利用当前观察、历史经验、失败后调查及真实试验，改善后续行动和学习效率。历史经验作为有适用条件的证据，而不是当前场景的固定答案；候选改变需要通过实际运行检验。

已开展纯 RL、增强 RL、纯反馈、反馈＋奖惩、反馈＋仅奖励，以及新网络的阶段性比较。不同阶段的任务、预算和机制有变化，不能直接跨阶段比较分数或把一次工程个案当总体结论。正、零、负结果与失败记录均属于研究历史。

## 明确未上传的内容

本地活动目录约 72 GB，大部分为模型检查点、原始轨迹和大型日志。普通 Git 快照没有包含：

- `.pt/.pth/.ckpt` 及相应压缩模型检查点；
- `.jsonl/.jsonl.gz/.bin.gz` 原始轨迹或状态载荷；
- `.npy/.npz/.bin` 数组载荷；
- 单文件超过 10,000,000 字节的其他产物；
- Git 元数据、Python 缓存、本地环境和凭据文件。

逐文件路径、大小与排除原因见 **[EXCLUDED_LOCAL_FILES.json](EXCLUDED_LOCAL_FILES.json)**。这些文件保留在原本地位置，没有因上传而删除。此快照不是完整模型备份或全部原始证据备份，不能声称仅凭本分支即可恢复每次历史运行。

例外是单独导出的 `model_weights/`：这里只保留网络张量和必要来源信息，不包含原检查点的优化器、历史记忆或完整训练状态。权重相同不等于在缺少原记忆的情况下能重现原评估行为。导出清单见 [model_weights/MANIFEST.json](model_weights/MANIFEST.json)。

## 复现与使用边界

不同历史版本具有各自的依赖、配置和运行入口。导出保留原文与原代码，部分脚本仍包含原 Windows 路径；部分审计脚本需要本快照未包含的原始数据或检查点。请先阅读对应版本的 README、MATH、contract 和报告，而不要把所有版本脚本批量执行。

根目录保留的包配置属于早期重构系统，不表示最新神经网络实验的所有依赖均已统一封装。此次是保存研究现状，不是新增训练、重新验收旧结果或宣称新的科学 PASS。

该快照单独发布在 `snapshot/current-20261112` 分支，未覆盖仓库原有分支，也未改动原活动工作区。
