# V0.8：更难的选择，及时使用事实

**当前交付：方案、候选一步读出与纯算例检查。没有启动新任务回合、训练或评估矩阵。**

V0.7已经完成，不因本轮提出新问题而重开。用户最新要求是增加实验难度，并继续改善“事实记住了却没用好”。本轮将这两个方向合在同一个新版本中：在每个相同新任务上对照旧、新读出，不拿V0.7简单地图的分数与新难地图的分数直接判断算法进退。

## 1. 接下来改善的具体位置

V0.7的真实记录中，某末端状态两个动作的Q为`[1/6, 0]`，事实计数分别是`[前进0, 碰撞1]`与`[0, 0]`。事实估计为`[1/3, 1/2]`，但FT只在Q平局时使用事实，所以仍选择第一个动作。

这不是“没有记住”，而是**旧的动作价值排序挡住了新的事实**。V0.7对比中FT大幅改善旧F-R，但FT与简单次数规则CT只差很小；不能把全部改善归给概率内容，更不能声称所有事实利用问题都已解决。

本轮不加惩罚来掩盖这个断点，也不把概率与Q随意加权。新增 **M1（model one-step）**：选择前用当前事实模型和后继价值重新估计两个动作的一步后果。

## 2. 难度不是只把地图加长

|条件|结构|到成功至少需要的连续决策|用途|
|---|---|---:|---|
|chain3|一通一堵的3段串联；通路每次有10%偶然碰撞|3|简单桥接；新种子、新实现，不重跑V0.7|
|branch3|3个“分叉→两条支路→汇合”单元|6|结果有随机性，局部容易不等于整条路线更好|
|branch5|同一种单元串联5次|10|只在branch3基础上增加深度、状态数与延迟后果|

每个分叉单元固定为：

```text
                  前进概率.95           最好出口.60（另一出口.45）
               ┌──────────────→ A ───────────────────┐
  分叉状态 ────┤                                      ├─→ 下一单元/目标
               └──────────────→ B ───────────────────┘
                  前进概率.80           最好出口.95（另一出口.65）
```

以上数值是**环境配置和外部分析信息，不提供给学习器**。两份镜像在每个状态交换命令标签，学习器没有“A好/B坏”语义标签。状态按本地编号呈现，不能从编号读取概率模板。

- “眼前更容易”的A路线，单元最好成功率为`.95×.60=.57`；B为`.80×.95=.76`。因此一味选择当前前进概率最大者也会走错方向。
- branch3与branch5的最优成功概率分别为`.76^3≈.4390`和`.76^5≈.2536`，不是把所有方法扔进几乎不可能成功的环境。
- 每条分支都可能成功，也可能失败；一次失败不够判定整个动作不可用。任何碰撞均终止当次任务，不透露“运气/策略”隐藏原因。
- 所有组得到同样的目标、动作及公开有向无环拓扑；**边的可靠性未知**，只能从自己的真实历史估计。未知拓扑、隐状态、地图漂移和跨任务迁移本轮不同时加入。
- chain3到branch3同时改变拓扑与概率结构，属于难度组合，不声称单独识别了“长度效应”；branch3到branch5才是同模板的深度比较。

## 3. 新读出怎样让事实不再受当前Q排序限制

对动作`a`，使用已有Beta(1,1)事实估计：

`p_hat(s,a)=(n_forward+1)/(n_forward+n_collision+2)`

新的只读一步分数：

`M1(s,a)=p_hat(s,a)×C_Q(next(s,a))+(1-p_hat(s,a))×r_failure`

其中，直接到达目标时`C_Q=1`；其它后继状态`C_Q=max_b Q(next,b)`。非终止奖励0、gamma=1，有奖惩组失败-1，仅奖励组失败0，均不改。

按`M1`最大者选择；**M1精确平局时**优先较大`p_hat`，仍相同再命令0优先。不加容差、调权重、额外随机数或永久禁令。

与旧FT的关键区别：

1. 不先要求`Q(s,0)==Q(s,1)`。当前Q已明显偏向旧动作时，事实仍可使实际选择改变。
2. 两个候选动作同时用同一公式估计，未试动作使用声明的先验；不再把“旧动作已经被模型备份为正数、未试动作的Q还是0”当作充分选择依据。
3. 同时看后继价值，不把“眼前前进概率较大”当作整条路线较好。
4. `Q(s,a)`不被这个读出直接改写。真实TD、有限模型备份、计数学习、alpha=.5、buffer64、每回合`min(12, buffer长度)`额外备份都保留。一次训练回合内策略固定，真实结束后再按原时间顺序学习；不在本轮顺便改更新时机。
5. 每次M1计算的两个后继估计单独计费，不冒称与旧方法计算量完全相同，也不把模型估计当新环境经验。

**已知边界：** M1仍依赖后继Q；后继Q若没有学好，它仍可能选错。这是纠正一个更具体断点的候选，不保证一次解决全部长期信用分配。纯反馈F0的完整概率规划作为另一条真实对照保留，不能把M1偷偷改成F0再给同一行为贴多个胜利标签。

这属于模型辅助的决策时规划思路，不宣称发明全新算法范式。已有模型学习、规划与行动选择的联系见[Sutton与Barto第8章](https://incompleteideas.net/book/bookdraft2016sep.pdf)；这里待检验的是所选修正能否在本实验中带来实际增量。

## 4. 保留核心对照，共九组

|组|方法|成功/失败信号|
|---|---|---|
|RL-RP|模型无关Q＋自身真实经验回放|+1 / -1|
|RL-R|同一纯RL路径|+1 / 0|
|F0|真实事实计数＋完整到达概率规划，无Q或reward输入|事实与目标，无reward字段|
|F-RP-FT、F-R-FT|V0.7事实平局读出，移植到相同新图|分别+1/-1、+1/0|
|F-RP-CT、F-R-CT|V0.7次数平局读出，保留简单竞争解释|分别+1/-1、+1/0|
|F-RP-M1、F-R-M1|本轮的一步事实读出|分别+1/-1、+1/0|

不另加已完成的固定命令平局混合组F-R/F-RP：这轮直接对照已修正的FT与有竞争力的CT，不永久累积每个历史变体。纯RL仍能正常学习、保存和回放全部合法自有经验；不是一个被冻住的弱基线。

FT/CT/M1之间每个奖励条件使用同一份真实TD、事实更新及模型备份实现，区别只在读出。拓扑扩展必须适用于全部方法，不能继续假设后继一律为`room+1`。F0使用`reach(s)=max_a p_hat(s,a)×reach(next(s,a))`逆拓扑计算；纯RL只用实际转移，模型备份仍只备份实际访问过的上下文。

历史尝试次数也属于反馈。如果CT仍然同样好，就承认简单经验利用已经解释了收益。奖惩与纯反馈比较仍是不同完整学习路径的比较，不假称只增删一个标量。

在本轮二元终止、gamma=1、无步罚条件下，完整策略的真实目标仍为`J_R=P(success)`、`J_RP=2P(success)-1`。它们的最优排序相同；有无处罚比较的是有限学习过程，而不是预设最优路线必须不同。

## 5. 重复、评估与指标

- 每条件 **32个独立训练seed：8001–8032**，每seed两份镜像。各组同源配对。
- 每流 **256个连续训练任务**，前128冷启动与积累、后128保留经验继续学习，不重置。
- 冻结点 **0/8/16/32/64/128/256**；每点 **512次实际评估**，epsilon=0，零学习、零历史写入。
- 所有训练组epsilon=.10。训练、探索、评估使用分开的本地随机流；坐标不含arm，评估坐标不含checkpoint，不让不同路径消耗错位。
- 保留逐任务训练成功/失败、实际步数、更新工作与完整冻结曲线，不只报最好一次。

### 主要问题

在branch3与branch5分别报告：

1. **F-R-M1 − F-R-FT：** 能否比V0.7更及时地使用事实？
2. **F-R-M1 − F-R-CT：** 能否超出简单尝试历史的收益？

两地图、两比较全部报告，不挑有利者。RP下相同比较、纯反馈对纯RL及每条方法内有/无处罚对比作为明确的次要结果全部保留。

### 更难环境里，先区分策略质量与抽样运气

本图小且无环，外部评估器可以对每个冻结策略精确算出`J_pi`，以及该固定世界的`J_star`。这两个值绝不回流给训练、动作选择、参数设置或停止决策。

本轮主指标预先选为：**前64回合，冻结策略相对可达最优值`J_pi/J_star`的归一化梯形AUC**，使用0/8/16/32/64点。这与V0.7的实测前32AUC口径不同，不能直接相减声称跨阶段增益。

同时公布512回合实际成功率、Wilson区间、对应实际AUC及与精确值的差。精确计算去掉此小图的评估抽样噪声，不会去掉训练随机性，更不证明真实大环境也有这种精确尺子。

### 效率不只看最终成功率

- 前64/128/256任务累计成功与失败；越早少失败仍有价值，最终追平不抹去早期收益。
- 同一配对的共同训练步预算`B=min(两方法总训练步数)`，在.25/.5/.75/1倍B下比较已完成成功任务。早撞墙导致步数少不算效率优势。
- 首次达到`.9×J_star`的检查点与当时真实任务数/步数；未达到为null，后续跌落保留。检查点间具体达标时刻未知，不把第8点达标说成恰好第8次才学会。
- 真实回放、事实更新、模型备份、读出计算、CPU/墙钟与存储分别计数。不将M1多算了一步说成完全免费。
- 各方法失败与成功经验都学习。成功不新增诊断归因、额外环境调查或隐含治疗。

推断单位为32个seed块，先平均同seed的两份镜像，每个地图分别做成对差值；公布均值、中位数、正/零/负seed数与10000次配对bootstrap区间。不把回合数当独立训练重复，不追加到显著，不将未显著当等效。[有限训练重复下报告不确定性的原研究](https://proceedings.neurips.cc/paper_files/paper/2021/hash/f514cec81cb148559cf475e7426eed5e-Abstract.html)。

## 6. 机制检查：事实改变选择，还是只是多做了计算？

真实访问处保存读出前完整Q、计数、后继、M1分数及旧FT/CT建议，记录：

- 当前Q是否严格偏向一个动作，而M1实际改变了它；是否被训练探索覆盖。
- 改变后实际发生的可见结果，以及在外部真实模型上的一步选择质量；方向可好可坏。
- 当前更容易但后继更差的分支是否仍被过多选择。
- 事实方向、下游Q方向及最终选择之间的分歧；重复碰撞分状态/动作统计，不能把所有随机碰撞都算无效尝试。
- 每个组机制字段都有覆盖标记；未安装或不适用记为null，不重现V0.7原自动表的“未观测填0”口径问题。

图中**即时前进概率较小不等于动作较坏**，不能沿用简单串联环境的这条诊断捷径。外部质量判断须包含后继可达性。只读的同状态替代建议不是已经执行过的反事实训练。
