# V0.8结论：事实现在可以推翻非平局的旧Q，但不总是推翻得对

**V0.8按V175固定矩阵完成。** 新接线、真实矩阵、新存储审阅和存储分析均首次exit0；没有重跑、挑seed、按效果改地图或追加样本。完整九组结果见`result.md`、`analysis.json`与各CSV。本文件解释结果，不新增训练或改原分析口径。

## 3. 相同环境步预算下仍有收益，但不是免费改进

新方法更常走到后面，因此完整256任务的步数更多。例如6步图F-R-M1用64806步、FT用61570步；不能直接把成功更多全算作同成本获益，也不能把早失败导致的少步数算成对照效率优势。

按每个seed/镜像配对取共同预算`B=min(两方法实际总训练步数)`，只给预算内已完成的成功任务计数，再汇总：

|地图/比较|共同预算合计|新M1完成成功|对照完成成功|
|---|---:|---:|---:|
|6步：F-R-M1 vs FT|61461步|4742|4191|
|6步：F-R-M1 vs CT|61983步|4784|4315|
|10步：F-R-M1 vs FT|73479步|1762|1526|
|10步：F-R-M1 vs CT|72739步|1745|1452|

这是交互效率收益，不是所有计算成本都下降。M1新增一步后继估计；实际读出、模型备份、TD、诊断shadow、CPU与存储均分列。约254秒native计时包含仪器和capture，不是生产算法耗时或整项研究用时。

## 4. “事实记住了却没用好”的非平局断点确实进入了真实行动

原方案的算例不再只是离线假设。新真实chain3流seed8001/mirror1/F-R-M1第4任务，在state2：

- Q为`.25`与`0`，旧FT会选择动作0；
- 事实估计为`1/3`与`1/2`；
- M1真实选择动作1，实际SUCCESS，两个动作的外部真实成功概率分别是0与.9。

更难的branch5也有例子：seed8001/mirror0/F-R-M1第62任务state1，Q为`.0408360`与`.0606026`、事实估计约`.585366`与`.571429`。M1真实改选动作0，其真实最优后继条件下动作值更高（约`.200173`对`.150130`），但**该次仍发生COLLISION**。选择更可靠不意味着每一次都成功，不能把这一次失败当作应否定该动作的充分依据。

在6步图F-R-M1的实际访问中，不被探索覆盖、相对同状态FT真实改变选择5240次：按外部真实模型、假定后续最优时的动作质量，较好3855次，较差1385次。10步图对应7448次改变，较好5414、较差2034次。影子建议和外部动作值不是完整反事实训练；这些计数说明路径进入实际选择，也同时保留误改。

## 5. 纯反馈、纯RL与处罚：不是一个统一冠军故事

|方法|6步图训练成功|10步图训练成功|6步/10步终点精确成功率|
|---|---:|---:|---|
|纯RL：奖惩|4296|1644|30.8662% / 12.3915%|
|纯RL：仅奖励|4033|1422|28.9209% / 11.3741%|
|纯反馈F0|4811|1883|38.7494% / 16.2597%|
|新反馈＋仅奖励M1|5057|1945|40.3671% / 16.9837%|
|新反馈＋奖惩M1|5465|2199|40.5899% / 18.6736%|

- 纯反馈F0终点与全过程训练成功高于本轮纯RL，但前64相对AUC略低于RL-RP，区间包含0：不能说纯反馈在所有阶段都学得更快。
- 同为M1，有奖惩版本早期相对AUC比仅奖励版本高约.07036（6步）、.08963（10步）；相应配对区间为[.02959,.11062]、[.05317,.12807]。这是预定次要比较，仍有6/7个不利seed。处罚在这条有限Q学习路径中提供了帮助，不由旧V0.5个案推断它处处无用，也不由本轮推断它必不可少。
- 简单chain3上F0、F-R-M1、F-RP-M1的64条完整训练行为逐流hash相同；不能把这些行为当三份独立机制证据。两档分叉图上它们每一条流均不再完整相同，任务结构确实让方法差异显现。
- 全部九组，包括RP-FT与RP-CT的零/小差结果均保留。所称纯RL是明确的有限模型无关Q基线，不代表全部RL算法；CT仍通过共同模型备份利用结果，不是完全没有结果反馈的组。

## 6. 暴露出的剩余问题

1. **事实会有噪声。** 一次较好动作碰撞后，有限样本估计可能低于未试动作的先验，从而把本来较好的选择改坏。新M1改善了事实入口，不保证事实判断每次正确。保存的branch3第5任务反例里，M1选择真实较差的动作，但该次恰好NEXT；不能以一次成功倒推判断正确。
2. **后继Q仍是瓶颈。** M1重算当前一步，却仍依赖后面的Q；更深图的数据稀疏、后继估计和价值传播需要进一步区分。10步图最好的M1-RP终点约18.67%，低于该图可达25.36%；64条流中仅23条曾到达90%最优值。不能把新规则称为完整规划或事实利用已解决。
3. **512评估也会波动。** 1728条流里有27条的实测首次达标标签与精确策略标签不同；12096个银行里711个Wilson区间跨过阈值。精确标签达到986流、实测961流。主指标已预定用外部精确值，不让这类小图测量运气决定结论；原始实测和null/退步不改。
4. **仍是固定已知拓扑的小世界。** 32个seed减少了训练运气干扰，不等于32种未知环境，更不等于通用迁移、LLM品味或全部反馈形式已被检验。

下一研究重点宜是**事实可信度与后继价值传播**，而不是只继续增加地图长度或自动扩大训练到正收益。本轮没有启动下一阶段。

## 7. 完成与证据范围

合计6635556真实回合、23702368步、7990594 canonical记录；两个新存储审阅首次exit0，检查完整raw/TD/模型/读出/冻结/配对坐标和成本；分析首次完成。该内部审阅不重建序列化运行时身份，不是独立专家或科学总体资格。

**阶段结论：在提高难度后，允许当前事实重新参与非平局选择，带来了可重复的局部早期改善和交互效率收益；同时真实观察到误改、有限估计噪声和深层后继价值不足。V0.8完成，但不宣称事实利用已完全解决。**
