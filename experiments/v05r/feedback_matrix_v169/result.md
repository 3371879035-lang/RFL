# V0.5结果：广义反馈、奖惩通道与学习效率

**按v168所定的局部计划，本轮V0.5已完成。** 三种信号路径和两种反馈利用方式真实接通，六份固定案例、36条流全部运行并完成存储核对。完成不依赖正收益，也不代表完整/通用强化反馈学习。

## 1. 做了什么

- 新的串联岔路房间：1、3、5个连续决策点，各两份镜像布局；每层固定两个活跃控制映射（一个有害、一个有保护作用）和两个未读保护哨兵。只有深度显式变化，终止奖惩规则、观测字段、动作集和12步上限不变。
- RP成功+1/失败-1；R成功+1/失败0；F完全不接收标量奖惩，但保留任务目标和实际结果。
- P为正常学习、固定补充练习/候选循环；S为同一基础学习器加条件化经验索引和定向试验。所有组拥有相同的普通动作、局部修正、保护规则和12次额外试验上限，每次失败最多两次。
- 每条流48个主任务，前24冷启动、后24保留原状态继续学习；不重置、不复制其他组的知识。P也学习所有真实经验，不是冻结的NoWrite。
- 首个真实调用前已固定contract、场景清单、P/S规则及源码输入。主任务探索使用事前有限工程坐标，不是新的随机seed/Xi资格研究。

### 问题一：更好利用反馈，是否有实际价值？

**有条件地有，且不必靠最终成绩更高。**

- RP下，P/S的288个主任务完整轨迹逐项相同，S额外试验45→25，环境步数957→910。它没有提高主任务成绩，优势是达到相同效果少做无效试验。普通Q数值状态不完全相同，不能把轨迹相同写成两算法全状态等价。
- R下，S比P多39次主任务成功，额外试验少16次；但环境步数730→809，**不是所有成本都减少**。P在深层案例经常更早失败，因此少走路本身不代表更有效率。
- F下，S少做19次试验、少55步，但主任务成功255→254，**这个负差保留**，不宣称全指标获胜或统计等效。

按每个案例/通道的共同环境步数范围B=min(P实际总步数,S实际总步数)，比较B以内已经交付的主任务成功数，六案例合计：RP为240→255，R为168→199，F为238→254。两组在每个比较点支付相同步数；这是固定案例上的工作量对照，不是新的全局成本权重或独立统计检验。参见matched_cost.csv与matched_cost_curves.svg。

### 问题二：处罚是不是一直没用？

**不是。这轮的Q学习路径中，负奖励确实提供了额外帮助。**

P条件下RP比R多80次成功；S条件下多41次。RP/R使用相同零值初始化、同一事实学习和TD公式，只改变终止失败奖励，未隐藏R的失败反馈，也没有附加步罚或诊断罚。

与观察一致的机制是：R的零失败目标在冷启动时不能像RP那样区分坏行动与尚未得到正回报的行动；多步终止信用传播也需要经历成功。R-P有101次在已有同条件证据下仍可预测的命令失败，R-S为60次。RP对应P/S均17次。这里“处罚有帮助”是这个有限学习器/探索流/期限下的结论，不意味着失败必须处罚；下一问给出了另一条不依赖负奖励的学习路径。

### 问题三：纯反馈能不能真正学会？

**在这个环境与给定表示下，可以。** F没有Q表、任务reward字段、回报训练标签或旧Q*。它从实际执行—后果记录学习条件转移，再围绕已给目标选择可行路径、尝试未知分支。最终学到的表格不是预先填写的出口答案。

F-P从前24任务123/144成功到后24的132/144；F-S从122/144到132/144。它们保持同一学习状态继续任务，未重新安装来源或额外训练。F与RP的成功数接近，但F有模型式规划而RP/R使用Q头，因此这是**完整方案比较，不是单一奖励变量的消融，也不是普遍等效证明**。

纯反馈仍有目标、动作语义、可见拓扑、成功/碰撞等事实标签和可行性偏好；没有外加奖惩不等于没有任何方向或先验。

## 4. 更快学好与未达标案例

共同指标在运行前已定为“首次出现连续12个主任务成功的窗口结束点”，不因结果不理想修改阈值。

- d1_m0的F组：S在第13个主任务形成该窗口，P在第20个；截至该点总环境步数14对22，是本轮一个明确的提前达标个案。
- d3_m1的R组：S第31个达到，P在48个任务内未达到。
- RP两组在各可达标案例中的主任务达标位置相同，但S截至达标时所需试验和步数较少；不能把“少试验”偷换为“每例主任务都更早达标”。
- d5_m1全部六组均未达到该窗口。所有NOT_REACHED保留为空值/右删失，不补0，不从平均数里静默删除。
- 有些达到窗口后仍发生失败；例如RP与F在各自已达标案例合计仍有8次后续失败。持续工程探索也是其中的条件，窗口不等于永久掌握或知识未损坏证书。

targets.csv保留全部36条达标/未达标结果、成本和后续失败。学习曲线不只显示最终值。

## 5. 历史经验在这里确实属于反馈

S三组共116次查询复用：85次复用当前主任务已经产生的观测，31次复用更早主任务期间产生的真实试验经验（RP/R/F分别10/11/10次）。两类均有当前世界、完整控制器、命令程序及工程坐标的精确绑定。

这些不是116个新的环境回合或训练样本。原回合的真实成本已记入冷启动/全过程，复用时不重复学习。所有1951份矩阵实际观测均被所属学习器消费一次；没有从JSON恢复旧运行时身份或复制私有学习表。

这个索引和事实转移表随经验增长，但S选择规则本身是事前手写规则，不是已训练的通用归因器或最优调查价值模型。精确缓存依赖本轮确定且不变化的世界；不能直接迁移到有噪声或漂移的环境。

## 6. 错误、保护与成本完整性

- 全矩阵34次局部提交、34地址删除，已读位置和本次真实试验支持范围一致；已提交的有益保护映射误删0，未读保护哨兵变化0。
- P在私有试验中有21次尝试删除实际有益的映射，S有1次；这些失败试验仍计入总成本。它们没有被提交成最终修正，不把“试过错误假设”伪装成零风险。
- 联合候选语法在双方同一源码中定义，但本矩阵每条实际轨迹最多咨询一处有映射的房间，没有触发多位置joint；不冒称多位置形状资格已经测完，也不为凑覆盖追加新canary。
- 成功主任务额外归因/试验为0，所有组普通学习仍开启。研究端使用共同任务结果衡量效果，不把跨组不同原始reward直接相加排名。

含6回合最小接线，本轮合计1957回合、5299环境步、3410次真实TD更新（F为0）、10598次事实字段更新、37次控制器提交、39份新独立运行来源。矩阵为1728主任务＋223试验，未达2160回合上限；无新随机keys/RNG、旧checker/native、正式collector、GPU、付费资源或自动安排变动。

两个native阶段首次均exit0，合计约2.826秒instrumented runtime；捕获合计8,714,524字节。该计时含本小原型的记录和tracemalloc，不是生产速度证书；矩阵Python traced heap peak为2,740,572字节，不等于完整进程RAM。

## 7. 真实审阅错误与修正

首个静态AST检查发现尚未执行的审阅器中缺一个右括号，修正后才开始第一次native，未因此发生任务调用。

最小接线的首次存储审阅exit0。矩阵首次审阅exit1：旧审阅器断言每个短区间wall >= .9*CPU；实际有393个检查点不满足，例如wall约.00835秒而GetProcessTimes读数为.015625秒。这个短区间的跨时钟比例不是有效不变量。

原审阅器、exit1和原native捕获全部保留。新audit_stored_v2.py的逻辑修改只有去掉这个比例假设和更换输出名，仍检查两种时间非负、单调；生成新文件时另有LF→CRLF行尾变化，两版已执行字节均原样保留。未改native源码或重跑任务。新审阅首次exit0，读完矩阵8665条、接线45条canonical记录，独立重建全部运动/执行/终止、事实记忆、binary64 TD、动作程序、候选、复用、提交、连续状态、预算和汇总。

这不是独立专家或sciencegate；源码/运行边界、运行时挑战与存储核对共同支撑本局部结果，不从序列化数据伪造运行时身份。未依据毫秒级CPU读数宣布某算法CPU更快。

## 8. 阶段结论与剩余边界

1. 更好组织当前/历史反馈，已经在这批案例中产生同效果节省和有限成本下更多成功；有小负差和成本权衡，不是全胜。
2. 奖惩作用依赖学习规则和任务条件。本轮负奖励帮助Q路径，不能沿用旧实验的“小差异”作为永久结论。
3. 不靠显式奖惩也可以改进行为，但前提包括目标、事实表示和模型式决策规则；不推出无目标学习、无先验或通用AI品味。
4. 三档深度没有替代陌生机制、噪声、变化环境或人类/Codex文本反馈验证；本阶段不把这些自动变成未完成门槛。

本轮已按计划收束，不为了追回纯反馈的1次负差、更大的效果或全例达标再换规则重跑。原V0.3/V0.4结果和未执行正式方案状态不改，也未启动V0.6。
