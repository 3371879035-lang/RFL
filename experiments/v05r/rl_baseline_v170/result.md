# V0.5基础对照已完成：纯反馈与标准强化学习（v170）

**关键结果：纯反馈F、标准有奖惩Q学习、带有限回放的有奖惩Q学习，在本轮288次主任务中逐条产生相同真实轨迹。没有观察到F更早改善或更省环境交互。无处罚Q学习明显落后。**

这是按用户最新要求补齐的基础对照，不是重跑v169来追正收益。已有255与254原值不动，视为很小的描述性差异，不据此宣称明显退步，也没有把固定案例差异称为已估计的随机误差或统计等效。

## 1. 这次真正补了什么

4组×6个固定案例×48个连续主任务，合计1152个主任务；另有独立8回合最小接线。深度1/3/5、每层两镜像、原root命令交换及未读哨兵、共同有限探索坐标沿用v169。

- **F**：复用v169实际未修改的FactLearner，无Q或标量奖惩；用实际物理转移、命令执行事实与给定目标选动作。
- **Q-RP**：新的标准直接命令Q(room,command)，成功+1、失败-1；不是继承F的旧RewardLearner。无事实模型、命令执行模型或诊断模块。
- **Q-R**：相同Q实现，只把终止失败reward设为0，成功仍+1；无隐藏步罚。
- **Q-RP-Replay12**：相同Q普通更新；每回合结束后，对自身至多64条真实历史转移，最新优先最多12次额外Q备份。不产生新环境回合，不调用模型虚构经验。

所有组都正常学习、保留经验，24/25处不重置。这次**全部禁止控制器编辑，额外调查/试验0**。世界、合法动作与可见事实相同，F与Q如何利用它们不同，所以仍是完整方法比较，不是“唯一差别是reward字段”的消融。普通Q回放缓冲保留历史不等于执行回放，实际执行次数单独记账。

这也意味着v170的237不能与v169的255直接相减，解释为算法退步：v169有额外试验和实际修正，而这里控制映射一直固定，双方权限/交互条件一起改变了。

## 3. 同资源与更早学会

预定的共同资源比较按每案例B=min(F总步数,Q总步数)，在B的25/50/75/100%比较已交付成功数，全部回合和失败成本都计算。

- 对Q-RP与Replay12：每个已定共同步数位置均与F完全相同，无样本效率优势。
- 对Q-R：六例共同步数预算合计474步时，F已交付172次成功，Q-R为108。F在同样环境交互预算下更有效；不能因Q-R早早撞墙、总步数少就说它更省成本。
- 四组都只有2/6案例达到“连续12个主任务成功”窗口。F/Q-RP/Replay12在d1_m0第20任务、d1_m1第19任务达到；Q-R分别为40与19。达到后各自仍有失败，没有删掉。
- 全部24条流都跑满48；16个NOT_REACHED保留null/右删失，不是漏跑实验。

**该12连胜指标的限制也暴露了出来。** 三个同轨迹组各有51次失败，其中42次是在最后失败位置实际执行了不同于自身greedy选择的预设探索命令。这不自动意味着42次对应的完整无探索策略都已成功，但明确说明持续探索参与了在线失败，不能把未出现长连胜全解释为“没有学会”。本轮不事后改阈值或补跑无探索评估。

## 4. 这对强化反馈学习意味着什么

1. **在这些确定性小任务上，不用显式奖惩，真实事实记忆与目标驱动选择可以达到标准有奖惩Q学习相同的行为效果。** 这是可行性结果，不是普遍统计等效。
2. **没有证明纯反馈在这里比正常有奖惩强化学习更快。** 标准RL基线并不弱，原先基于P/S额外试验的节省不能直接升级成“优于标准RL”。
3. **处罚是否有用取决于学习路径。** 对零初始化、此探索流与期限下的Q更新，失败负值帮助区分已知坏动作和未获成功回报的动作。F用分类事实排除已知碰撞动作，提供另一条不用显式负奖励的行为改进路径；不是说失败必须处罚或无处罚学习必然差。
4. 与结果一致的局部机制是：确定性二选一房间中，F记住碰撞后避开相应行动，Q-RP将失败命令价值压低；两者足以产生相同选择。这里是基于已审轨迹/实现的解释，不是全算法等价证明。

F仍依赖给定目标、表示、固定世界和手写决策规则；“无显式reward”不是无任务偏好。标准Q只是一个明确的强化学习基线，不代表所有模型式RL、优化器或超参数。没有在结果出来后为任一组调参、扩预算或挑换案例。

## 6. 本轮结束，不新增隐性门槛

这个基础对照已经完成，并得到了有用的持平结论。当前值得后续单独研究的是：在偶然失败/变化环境中，经验如何区分稳定规律与偶然结果；以及把持续探索的在线成本与已学策略表现分开测量。二者本轮都没有运行，也不是回头宣称本轮没完成的理由。
