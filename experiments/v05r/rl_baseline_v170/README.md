# V0.5补充：固定动作接口的纯反馈 / 标准Q学习基础对照（v170）

本文件在本轮首次native之前制定。结果另写`result.md`，不把计划原文覆盖成结果。

## 具体问题与边界

用户要求补齐纯反馈与纯强化学习基础对照；保留255与254原值，将其作为很小的观察差异，不声称已有随机误差估计或统计等效。随机后果、环境漂移、通用品味/涌现均不作为本轮要求。

- 新建4组：F、Q-RP、Q-R、Q-RP-Replay12。
- F直接复用v169未改字节的`FactLearner`，不是把Q奖励清零；事实转移、命令执行记忆和给定目标保留。
- Q三组为新的直接命令Q(room, command)，零初始化、alpha=.5/gamma=1。不继承事实学习器，不使用命令执行模型、不调用诊断/定向试验/控制器编辑；普通Q不是“没有经验”的弱对照。
- RP终止成功+1、失败-1；R成功+1、失败0；非终止0。普通更新对实际回合按时间顺序一次执行。固定无环房间里，回合结束后按顺序更新与逐步在线更新得到相同普通备份数值；不声称一般循环环境等价。
- Replay12在同样普通更新后，从自己的至多64条真实转移缓冲区，最新优先最多12次额外Q备份。有限、无RNG、无模型生成样本；重复计算计入资源，不冒充新环境反馈。它只是一个明确的经验回放基线，不代表所有强化学习方法。

## 同环境、同权限

复用v169的真实环境kernel、6个固定场景（深度1/3/5×两镜像）和共同有限探索坐标。每组新建独立来源与空学习状态，48个真实主任务，24/25处不重置。源码组件复用不是重跑v169的runner/fixture或复用旧raw充当新回合。

原root命令交换与未读哨兵固定，双方都没有控制器写入、额外调查或特殊重置权限。Q按实际选择的命令学习；F仍使用原物理转移/命令事实表示。任务、合法命令、可见过程字段相同，处理信息的方法不同。因此它是完整学习方法对照，不是只改reward字段的消融。

Agent只收到公开任务和真实观测，不收到门真值、完整控制映射或其它组经验。所有组都保留自己的历史；Q有经验缓冲，只有Replay12执行额外备份。初始健康Q*、旧checkpoint、预训练调查模型均不导入。

## 预先确定的有限预算与结果

- matrix24条流×48=1152主回合，无额外试验；最小wiring4组×2=8回合，合计上限1160回合/13920环境步。
- Replay额外备份上限matrix3456+wiring24=3480；F无TD。每phase最多300秒、64MiB捕获，本地CPU，无正式keys/RNG/collector/自动任务。
- 首次错误/partial完整保存，不自动重试；任何修订另建版本。旧V03/V04/V05的已执行源与结果不动。
- 先看12/24/48主任务的成功/累计失败；首次12连胜窗口及全部成本，未达保留null，窗口之后的失败保留。
- 同环境交互成本：对每个案例，F分别与每个Q组在共同实际步数范围B=min(两组总步数)的25/50/75/100%位置比较已完成成功数。边界采用完整回合结束点，未完成回合不提前计成功。
- 计算开销分开报告：实际Q普通/回放备份、事实字段写入、规划/更新计时、状态序列化大小及instrumented进程计时。不得把不同计数简单加成统一成本，微秒级计时不用于宣称生产CPU优胜。
- 全部6案例原样报告，正/零/负都结束，不靠换超参数/探索流追回优势。这些固定案例不是独立seed，总回合数不是独立统计N。

## 最小使用方式

`experiment.py`只在新目录独占输出；`audit_stored.py`独立stdlib核对物理轨迹/动作/Q与事实状态/回放来源，不执行native、不导入实验代码；`analyze_stored.py`只分析真实已存结果。

算法参考：[Watkins和Dayan，Q-learning](https://www.gatsby.ucl.ac.uk/~dayan/papers/cjch.pdf)。本轮固定最新优先Replay12调度是公开的工程选择，不冒称原论文指定或最优回放。
