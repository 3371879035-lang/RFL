# V0.6 已完成：偶然失败、纯反馈与奖惩

**按用户批准的v171有限方案，本轮V0.6已完成。** 五组真实学习、80条连续流、5120训练回合、6600冻结评估回合全部运行；另有20回合最小接线。首次两native、首次两存储核对及首次分析均exit0。没有为了获得优势换参数、随机带、场景或重跑。

核心结论：**事实概率学习可以保留同一操作的成功与失败，不需外部处罚也能形成较好选择；随机条件下看到一个提前改善个案，但尚无稳定、普遍优于有奖惩RL的证据。把事实模型接到Q头上也不自动带来收益。**

## 1. 五条路径确实不同，权限相同

|组别|实际路径|成功reward|碰撞reward|
|---|---|---:|---:|
|RL-RP|直接命令Q＋最多12次自有真实历史回放|+1|-1|
|RL-R|同一Q实现，只改变失败reward|+1|0|
|F0|Beta(1,1)平滑的事实计数＋目标到达概率规划；无Q|字段不存在|字段不存在|
|F-RP|相同事实计数＋Q头＋有限模型期望备份|+1|-1|
|F-R|与F-RP同实现，只改变失败reward|+1|0|

四个Q组均alpha=.5、gamma=1、零Q初始化；两类额外Q备份都有b=min(12,当前自有64转移buffer长度)预算。模型概率中的先验不是新事实，模型备份也不是新环境回合。

所有组保持相同公开目标、分层拓扑、动作权限与事实输入。控制映射全程固定，额外原生调查/控制器写入/成功归因均0；成功和失败都正常学习。F0与混合组是完整方法比较，不是单独reward字段消融。旧kernel/Q*/checkpoint/旧runner均未导入。

## 2. 主结果

每行4个工程seed×2镜像，共8条流、512训练任务。最终冻结评估关闭探索、0学习写入；括号分母是实际评估回合数，不是独立统计N。

### 确定性桥接条件 p=0

|组别|训练成功/512|前16任务成功/128|最终冻结成功|冻结成功率曲线AUC|
|---|---:|---:|---:|---:|
|RL-RP|437|97|8/8|0.875000|
|RL-R|194|25|4/8|0.406250|
|F0|437|97|8/8|0.875000|
|F-RP|429|89|8/8|0.875000|
|F-R|194|25|4/8|0.406250|

F0与RL-RP的512条训练轨迹逐条相同；F-R与RL-R也是512/512相同。混合F-RP比RL-RP少8次早期训练成功，负差保留，最终相同。不能把增加事实模型说成必然提高效率。

### 可行操作每步有10%偶然失败 p=0.10

|组别|训练成功/512|前16任务成功/128|最终冻结成功|冻结成功率曲线AUC|
|---|---:|---:|---:|---:|
|RL-RP|315|71|184/256 = 71.875%|0.607421875|
|RL-R|129|14|93/256 = 36.328125%|0.272949219|
|F0|318|73|184/256 = 71.875%|0.628906250|
|F-RP|315|70|184/256 = 71.875%|0.628906250|
|F-R|129|14|93/256 = 36.328125%|0.272949219|

每一步可行操作仍可能失败，所以三步最佳路线的理论成功概率是0.9^3=0.729。184/256是这批固定评估数值下的实际观测，不是模型只学到71.875%的确定正确率。

F0比RL-RP多3次训练成功，是小差异，不称明显总体胜出或统计显著。F-R与RL-R在随机条件下仍512/512训练轨迹相同；它们的Q数值/计算状态不是同一算法全状态等价。

## 3. 提前改善发生在哪里？

随机条件的冻结评估汇总如下，所有组使用同一套独立于训练的评估数值，整个银行没有学习回写：

|训练回合检查点|RL-RP|F0|F-RP|RL-R / F-R|
|---:|---:|---:|---:|---:|
|0|0/256|0/256|0/256|0/256|
|16|162/256|184/256|184/256|70/256|
|32|184/256|184/256|184/256|70/256|
|48|184/256|184/256|184/256|93/256|
|64|184/256|184/256|184/256|93/256|

**一个具体提前改善个案是seed6004、mirror0。** 在第16训练回合，RL-RP的greedy程序为[1,1,1]，最后房间选了未证实的另一命令；F0和F-RP均为可通行的[1,1,0]。第32回合RL-RP也变成[1,1,0]。这使第16回合两种事实方法多22次固定银行成功，之后追平。

与这个现象一致的已存状态：RL-RP在e16的Q(2,0)约-0.2833，未试过的Q(2,1)=0，因而转向后者；F0在该条件记录8次成功前进、1次碰撞，平滑概率9/11，没有把这次碰撞当必然失败。F-RP也保留同样计数，其模型Q(2,0)约0.6364。这里是实际状态与选择的解释，不是额外做过“删除某次失败”的因果干预。

**这不构成四个seed都稳定更快。** F0−RL-RP的每seed冻结AUC差（先平均两镜像）为[0,0,0,0.0859375]，均值0.021484375。对应训练成功差每seed为[+1,-1,+1,+2]。全部差值见`paired_seed_deltas.csv`，不能把256回合或多个检查点冒充独立样本量。

## 4. 同资源与计算开销

- 确定性条件F0/RL-RP同437成功、1451训练步；无交互效率优势。
- 随机条件F0用1324训练步、318成功，RL-RP用1315步、315成功；F0多9步，不说全部成本更低。
- 在每个案例共同训练步数B=min(两组总步数)范围内比较，随机条件八例合计预算1315步时F0完成316次成功、RL-RP315次。这仍是很小的局部差异。
- 与无处罚RL-R比较，F0在成对共同训练预算下更多成功；不能将RL-R因更早撞墙导致的少步数称作效率优势。
- 随机条件F-RP和RL-RP都315训练成功，但混合组没有降低计算过程复杂度：前者1313普通Q备份＋5893模型备份＋1313事实计数更新，后者1315普通Q备份＋5910真实回放。等备份上限不等CPU开销相同。

F0没有TD，却有概率规划与计数工作。完整组别成本包含`train_steps/eval_steps`、普通/回放/模型备份、事实计数、规划边展开、微小计时和状态字节，见`group_summary.csv`；不把不同计数简单相加成统一成本，也不基于一次instrumented短计时宣布生产CPU速度优胜。

## 5. 关于“失败不应直接判死刑”，本轮证明到哪一步？

### 已经实际做到了

- 独立20回合接线中，五组每组先对同一命令实际训练成功→碰撞，再对冻结角色评估成功→成功。三种含模型路径保留计数[1,1]、概率0.5，未抛冲突错误、覆盖旧成功或置永久禁令。
- 矩阵随机条件下，F0/F-RP各8流共24个上下文都真实出现成功与碰撞；F-R为13个，因其访问轨迹不同。模型计数逐个与完整raw历史核对，两类结果全部保留。
- 这些模型能在不知道“这次是不是运气”的条件下更新概率，F0与F-RP最终达到与RL-RP相同的冻结效果。

### 尚不能推出

- 不能从一次失败准确识别隐藏原因；这里是多次证据下的概率判断，不是学出了通用因果解释器。
- 不能说处罚必需。纯反馈F0没有外部负奖励也能改善，是本轮的直接反例。
- 不能说处罚无用。对这套零初始化、稀疏终止信号的Q路径，有处罚的两个版本明显强于仅奖励版本。
- 不能说“增加事实模型就能救好Q学习”。F-R虽然真实维护概率并做模型备份，但通过Q头选择行动，visited-only有限备份仍有冷启动/价值传播限制，行为与RL-R完全相同。模型正确存储信息，不等于信息已有效改变选择。
- 不能宣称品味涌现、陌生问题迁移或完整/通用强化反馈学习。这些不是本轮完成门槛。

## 6. 达标尺子的真实限制，没有用补跑掩盖

预定阈值仍是确定性0.90、随机0.6561，网格e=0/16/32/48/64，未达保留null。80条流全部完成，61达到该指标、19未达到；后者不是漏跑。

其中seed6002、mirror0的32项随机评估银行，按已存外生数值计算，即使每个房间都走正确路线，上界也只有19/32=0.59375，低于0.6561。这是一个共同银行，投影到五组产生5个“该银行阈值不可达”标记；不是5个独立偶然问题。F0等已采用正确路线的组也仍如实NOT_REACHED。

这个诊断在首次native前就写入执行说明/分析源码。原阈值、银行、null和统计全部不改；没有把它重标成通过、补0、换seed或增加评估回合。原始成功率曲线比单个达标标签更可解释。

## 8. 阶段结论

V0.6在批准范围内完成：从确定性事实扩到真实偶然失败，纯反馈入口可用，冻结评估隔离有效，五组比较与成本齐全。

真正的进展是：**可以不靠外部处罚来保留并利用失败信息；出现一个早期更稳定选择的个案；也清楚看到概率模型、Q更新和行动选择之间仍可能脱节。** 大部分优势是持平或条件性的，混合模型有额外成本与负差，全部保留。

不为追回更大正收益继续加案例，不自动启动V0.7。未来若继续，优先针对“事实信息为何没能改变仅奖励Q的选择”和“小固定随机银行的达标解释”提出独立可检验问题，而不是先加大地图或宣称涌现。
