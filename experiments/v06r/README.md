# V0.6 研究方案：偶然失败、反馈与奖惩

**状态：方案已制定，未实现、未运行新实验。**

用户要求：“规划V0.6吧，分别是纯强化学习，纯反馈，奖励和处罚都有，只有奖励。”

## 1. 这轮只回答一个核心问题

> 当同样的做法有时成功、有时失败，怎样利用事实与历史，既不因一次失败判死刑，又能更早学好？显式奖励和处罚还有多少额外作用？

V0.5基础对照已发现：在原确定性小任务中，纯反馈F、标准有奖惩Q学习、带回放Q学习的288条主任务轨迹完全相同；无处罚Q学习较差。新阶段不重跑原案例追更大效应，而只增加“可行行动也可能偶然失败”这一环境因素。

历史经验仍属于反馈；无显式奖惩不是无目标、无偏好。成功正常学习和记录，不做额外成功归因。通用品味不是本阶段必须人工造出来的成果，也不假定它必然涌现。

## 2. 按四类意图，具体落成五组

“纯强化学习/纯反馈”是方法，“有无奖惩”是信号，不能把两层混在同一标签里。为让纯RL自身也有处罚对照，建议将它分成两个版本；其余分别是纯反馈、反馈＋奖惩、反馈＋仅奖励。

|编号|组名|显式成功奖励|显式失败处罚|行为更新|
|---|---|---:|---:|---|
|RL-RP|纯强化学习：奖励＋处罚|+1|-1|直接命令Q学习＋有限真实经验回放；无事实转移模型|
|RL-R|纯强化学习：只有奖励|+1|0|同一Q实现，只改变失败reward|
|F0|纯反馈|无reward字段|无reward字段|结果频数/条件事实记忆＋目标到达概率规划；无Q头|
|F-RP|反馈学习＋奖励＋处罚|+1|-1|同一条件事实记忆＋Q头＋有限模型期望备份|
|F-R|反馈学习＋只有奖励|+1|0|与F-RP同实现，只改变失败reward|

没有第六个“reward全为0的普通Q组”：它不能代替纯反馈学习器。RL允许保存和复用自身历史，不制造没有经验的弱对照。“纯RL”仅指没有本方案额外事实模型的明确模型无关基线，不代表整个强化学习领域。

### 每个比较回答什么

- **F0 vs RL-RP / RL-R**：两条完整学习路线的效果与交互效率。
- **F-RP vs RL-RP、F-R vs RL-R**：相同奖惩条件下，条件事实模型/模型规划相对直接经验回放的增量价值。
- **RL-RP vs RL-R、F-RP vs F-R**：同一算法中，负奖励的额外作用。
- **F0 vs F-RP / F-R**：纯事实路线与混合路线的整体比较；不能假称只增删一个数，因为策略读出从到达概率变为有限更新Q值。

这些定义不排斥“反馈学习也能属于广义强化学习”；F-RP/F-R在算法分类上接近模型式RL。实验检验明确机制，不凭名称宣称新范式已优于所有RL。

## 3. 最小环境变化：失败不再是确定判决

- 固定3个连续岔路、两份镜像。沿用V0.5动作/目标含义与固定root命令交换，但在新版本环境实现中加入偶然失败；旧kernel和捕获不改。
- 每个房间两种实际行动：阻挡出口总是COLLISION；可行出口以概率1-p前进，以概率p产生COLLISION并终止。
- 只设置两种条件：**p=0、p=0.10**。p=0是新同版本桥接对照，不是重跑v169/v170 fixture；不同时扩大深度、加入地图漂移或新目标。
- 学习器只看到真实命令、执行、位置和SUCCESS/COLLISION等结果。它不知道门真值、p，也看不到“这次是运气差”的原因标记。两种失败在任务可见端具有相同结果类型。
- 同一条件下两种相反结果都必须进入经验。新事实模型不得因这种合法冲突报ProtocolError、覆盖掉旧成功或永久禁用整个动作。
- 所有组固定动作权限、控制器只读、额外原生调查0。调查价值选择、结构修正、多模态反馈、漂移与迁移留给后续独立问题，不混入本轮。

这先检验“不把偶然失败当绝对禁忌”，不要求模型从一次失败识别出真实隐藏原因。

## 4. 学习路径：不是贴标签的五份同一程序

### 共同部分

每组从空任务经验开始；给相同目标和公开分层拓扑，无旧健康Q*、成功路线、旧调查模型或checkpoint。上下文按(room, command)记录，控制映射在整条流中不变，不需要给RL额外命令执行模型。

64个训练主任务连续进行，前32与后32不重置。训练探索epsilon=0.10；同一案例/本地seed下各组共用预先独立生成的探索开关与动作坐标。成功和失败都执行普通学习；任何额外诊断/归因查询均为0。

### 纯RL两组

直接Q(room, command)，零初始化，alpha=1/2、gamma=1，普通真实转移按时间顺序更新。终止成功+1，终止失败按组为-1或0，非终止0；不加步罚、调查罚或隐藏整形奖励。

保留自身最近64条真实转移。每个训练回合结束后执行b=min(12,当前缓冲长度)次最新优先回放。重复备份是计算开销，不是新环境经验。

### 纯反馈F0

对每个(room, command)维护真实前进/碰撞计数n_forward、n_collision；用预先声明的Beta(1,1)平滑，p_hat=(n_forward+1)/(n_forward+n_collision+2)。这是对未知结果的对称先验，不是正确出口答案。

用公开分层结构计算到达目标概率：P(goal)=1，P(room)=max_command p_hat(room,command)*P(room+1)，选择最大者；相同值按command0优先。一次失败后估计下降但不归零，也不阻断将来的真实探索。

无reward字段、Q表、回报标签；成功/碰撞事实与目标仍存在。不用外部标量奖惩不等于不用数值：概率是从事实计数估计的，选择仍有目标方向。这是可执行的输入/更新路线区别，不声称到达目标在数学上无法写成奖励目标。计数学习和每次实际规划的计算工作都记录。F0是新的概率事实版本，不就地修改v169的确定性FactLearner。

### 反馈＋奖惩两组

与F0相同的真实计数和同一个Beta先验，同时有与RL两组相同初始化/alpha/gamma的Q头，先做真实转移的普通TD。

每个训练回合再执行与RL同公式数量b的模型期望备份，仅对本来源已经真实咨询过的(room,command)进行。候选按room降序、command升序循环；每一次计算都计费。目标由真实计数与声明先验估计的前进/失败概率、该组公开reward规则和当前后继Q值求期望，不从环境门真值或隐藏失败原因取值。用Q选择动作，不加任意“事实分数×权重＋reward分数”的混合评分。

例如非最后房间的期望目标是p_hat*max_a Q(next,a)+(1-p_hat)*r_failure；最后房间是p_hat*1+(1-p_hat)*r_failure。二者都用alpha=1/2备份。模型中的先验质量不是新观测，模型备份不是新raw或真实试验；计划要分别记录实际数据与预测分支。

**重要的可解释性检查：** 在本轮二元终止、gamma=1、无步罚条件下，最优期望回报分别为J_R=P(success)、J_RP=2P(success)-1，最优策略排序本来相同。我们比较的是有限数据、有限更新下的学习过程，而非声称两种reward应有不同最优路线。不能把三组都实现成同一到达概率精确规划，再用三份别名“发现奖惩无用”。这里混合组是有限Q/模型备份，F0是概率规划；真实持平仍完全允许。

模型学习与规划并非本项目独有。该混合基线属于Dyna式思路的有限表格实现，不能把它包装成新发明的大型世界模型或通用归因器。[Sutton与Barto，第8章](https://www.andrew.cmu.edu/course/10-703/textbook/BartoSutton.pdf)；直接Q基线参考[Watkins与Dayan](https://www.gatsby.ucl.ac.uk/~dayan/papers/cjch.pdf)。

## 5. 分开测“正在探索”和“已经学会什么”

V0.5的在线12连胜会受持续探索影响；V0.6不再把它作为主要学会指标。

### 在线表现：探索开启

统计前16/32/64训练主任务的成功数、累计失败、环境步数和全部计算成本。关注早期少走弯路、同交互预算下多成功，不只看末端。

### 冻结策略评估：探索关闭

在训练e=0、16、32、48、64后，从当时完整学习状态形成只读评估角色。epsilon=0；评估不写Q、计数、经验buffer或训练状态，不向学习器返回评估结果，不据此选择下一次训练或提前停止。F0的只读规划可以计算，但不更新经验。

- p=0时，每个检查点1个真实评估回合已足够；不重复跑32次相同确定性轨迹凑样本。
- p=0.10时，每个检查点32个真实评估回合；同一案例/seed下各组、各检查点共用独立于训练的评估噪声坐标，保留完整银行和顺序。
- 主要展示完整冻结成功率曲线，不要求最后一直领先。
- 辅助达标指标：第一次达到该条件可达成功率上界的90%的检查点。当前环境外部可算上界(1-p)^3，因此阈值分别0.90和0.6561。门真值、p、上界和阈值仅在外部分析中使用，绝不成为训练特征或停止条件。
- 未达到保留null/右删失，后续跌落全部保留；达标时刻只有16回合网格的精度，单个32回合银行跨阈值不是永久掌握或统计置信结论。

### 资源比较

固定训练回合位置、共同训练环境步数预算两种结果分开报告；后者按每案例的成对B=min(两组实际训练总步数)，在25/50/75/100%位置比较已交付成功数。

采集评估工作不是免费开销：同时给训练交互、评估交互及全过程总量。另列真实TD、回放、模型备份、概率规划边展开、事实写入、CPU时间与状态/内存观测。不把“备份次数相同”说成CPU成本完全相同，不跨不同原始reward求和排名。

## 6. 第一轮保持有限

|项目|固定安排|
|---|---|
|学习组|5|
|地图实例|3岔路、2镜像|
|偶然失败概率|0、0.10|
|本地工程重复|4个seed：6001、6002、6003、6004|

|确定性评估|40流×5点×1=200|
|随机条件评估|40流×5点×32=6400|
|最小接线检查|最多20个独立真实回合|
|全部原生回合上限|11740|
|按12步上限计环境步预算|140880|
|运行资源|本地CPU；整次native最多600秒；capture最多128MiB；不租GPU|

最小接线采用独立一房间合法来源、同一命令和事前固定外生数值，实际产生成功→偶然碰撞→成功→成功，每组4回合。前两回合普通学习，后两回合从同一冻结学习副本评估、不回写。它用于确认矛盾事实可以合法更新、信号真的分开、冻结评估0写入，不作为随机总体样本。没有自动重试旧fixture。

新本地PRNG只在将来运行本方案时启用，本次不生成随机带、science keys或任何实验样本。预先独立生成训练探索、训练环境、评估环境三类外生坐标，不因分支长短改变后续随机数，也不把序列给学习器。训练环境坐标为(seed,mirror,train_env,episode,room)，训练探索用独立train_action流；评估坐标为(seed,mirror,eval_env,bank_item,room)，**不含arm或checkpoint**，以固定同一评估银行比较各组/各检查点。p=0/p=0.10复用相同潜在环境数值但独立运行。共同随机数是配对控制，不使多个检查点或32个评估回合成为独立重复。

四个seed是工程重复，不是旧400/200正式确认。成对比较以seed为重复单位，同一seed内先合并两镜像，p两条件分开报告；逐seed差值、均值及范围都公开，任务/评估回合不能冒充独立N。不用小样本无显著性来宣称等效。

## 7. 完成标准与执行顺序

本轮完成标准是：五条路径真实有效、偶然失败处理正确、对照与预算有效、冻结评估不污染训练、结果与全部成本清楚。正、零、负都可结案；不要求所有组/条件都赢、陌生问题迁移或涌现品味。

实施时先做**新概率事实入口＋冻结评估隔离＋四回合最小接线**，再一次执行这份有限矩阵。首次错误/partial保留，若确需修订另建明确版本；不更改旧实验、不按效果换seed/阈值/地图/探索流，不重复跑已有完整bank追非零。

旧V0.3/V0.4/V0.5结果、旧未执行确认方案及自动任务状态均不改。本轮只制定方案，运行次数0；下一步是实现本方案，不是把方案文件称作已完成实验。
