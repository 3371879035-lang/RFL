# V0.4 v152：把已有机制接成连续运行的反馈学习原型

## 本轮不是再加一个单次示例

新增continual_agent.py / ContinualFeedbackAgent，将v150真实可见前缀试验与v151原生候选观察/机制条件普通TD组合为一条可重复调用的任务接口run_observed_task。去掉“只允许第一次失败调查”的工作流限制。成功只普通学习；每个新失败可根据可见指令/执行偏差提出候选、真实试验、保留或修正，再吸收适用经验。没有偏差时保留不改，不靠读取fault原因填责任。

每个角色独立在同一条32任务输入序列中运行：A6次→B6次→C6次→D6次→回A4次→回B4次。完整current R+L与protected I贯穿32个主epoch，不在切换场景时重置，也不再次安装故障。初始一份真实来源用原store安装8项D/X，其中含一个未读sentinel；3角色完整clone起点相同。
