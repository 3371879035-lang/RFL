# V0.4 扩展：把一次实践变成可复用的诊断经验

2026-11-06（Asia/Shanghai）

本轮检验一个此前未测的问题：实践结果如果只用于当次选择，下一次还得再试；是否能保留条件化经验，在另一个任务条件中少试一次而不损失任务表现？

## 实际结果

同一个预先固定20任务流，状态持续、不重置；第二次歧义改变κ、相位和错误位置。

| 路径 | 方法 | 主任务成功 | 平均主任务回报 | 额外实践回合 | 诊断记忆命中 |
|---|---|---:|---:|---:|---:|
| DQ | 普通学习 | 2/20 | -1.007 | 0 | 0 |
| DQ | 冻结特征选择 | 5/20 | -0.694 | 0 | 0 |
| DQ | 每次歧义重新实践 | **14/20** | **0.256** | **12** | 0 |
| DQ | **保留并复用实践经验** | **14/20** | **0.256** | **6** | **1** |
| 修订patch | 四组相同 | 16/20 | 0.466 | 0 | 0 |

两个DQ实践组不仅成功次数/均值相同，**全部20个主任务的逐回合结果和binary64回报序列相同**。这不是总体统计等效声明，只是所测序列的实际相同。

## 真正新学到了什么

新增显式`DiagnosticMemory`，与普通学习器R+L、原冻结28行基础价值表分开。最初为空，只在自己真实失败后的候选实践结束时，用全部实测回报更新：

1. 保持：均值-1.24。
2. 轨迹中的单次等待候选：均值-1.24。
3. 连续同位置/同动作停滞候选：均值0.86。

第一次歧义epoch5，共3个候选、6次任务，留下3行条件化价值记忆，每行2个真实回报。没有读取后面场景的结果训练，也没有在成功任务后新增归因。

键的表示是我们设计的：原可见候选特征＋同一格/同一动作是否连续出现多步。它不保存绝对坐标、时间、κ、相位、地址序号或隐藏故障。**表示不是学出来的，条件价值是从实际反馈学出来的。** 因而这不是把“永远改第5个地址”写进缓存。

## 第二个任务条件怎样验证复用

第一次环境为κ0/phase2，初始错误在(2,1)、t3以后；第二环境κ1/phase1，初始错误在(1,2)、t1以后。epoch11产生第二次歧义时：

- 记忆组根据第一次留下的条件价值，选择 `single:2`，即**第3个地址**，没有再实践；第一次选的是第5个地址。
- 对照组仍做真实试验：keep两次-1.24，修改第1地址两次-1.24，修改第3地址两次0.86。
- 存储核对确认，两组在这次决定前的实际post-TD完整R+L+I相同；不是对照被换成更难起点，也不是把对照结果提前给记忆组。
- 记忆组第二阶段没有更新记忆表；这次选择确实只用了之前已有的6个实践回报。

由此，本轮有**一次实际跨任务条件的诊断经验复用**。对照完整保留普通学习状态，只是不跨事件积累这份诊断经验，并未冻结普通学习或丢掉其TD更新。

## 节省了什么，没证明什么

在这次模拟流中，记忆组避免一次额外实践事件：少6个模拟任务、62个环境步骤、2次分支候选事务及相应副本工作，主任务表现未下降。

这不是“所有计算成本减半”。记忆新增查表/存储/特征计算，clone/IO/墙钟未做生产分项计时；只观察到本轮环境试验工作减少。原基础模型196个开发探测回合也仍计历史成本。

两实践组最终无故障只读回报均0.86/0.86，不是前段0.88的完美恢复。修订patch普通学习已解决所测问题，未触发实践或记忆更新，零额外收益保留。

只有一个固定双条件流、一次记忆迁移，不是独立seed总体推断、一般记忆泛化或完整因果后验。新run-span表示受先前失败启发，不声称自动发现了表示或通用品味。匹配相同特征不保证其他环境下价值仍成立；未测候选不等没价值。
