# V0.4 局部原型研究：阶段完成与条件性结论

2026-11-06（Asia/Shanghai）

## 一句话结论

**这轮选定的V0.4局部原型已完成：在已执行的小型模拟任务中，失败触发的学习式候选选择，加上歧义时有成本的实践，可以改变实际修正决策并改善后续普通学习表现。** 结果有正、有零、也有保留失败；不要求所有指标同时获胜。

这里的“完成”是所选局部机制原型与有限实证完成，不是仓库旧完整V04R方案通过，也不是通用/完整强化反馈学习。这个结论是结果后的诚实收口，不倒写成预注册PASS。

## 已真实接通的闭环

实际任务观测失败 → 同轨迹普通TD/策略更新 → 可见证据 → 学到的候选后果价值 → keep/局部修正选择 → 若同分同特征无法分辨，有限实际分支试验 → 一次主角色更新 → 持续普通学习与外部结果。

- SUCCESS只普通学习，不额外诊断、评分、查询或修正。
- 普通组也会学习与迟到恢复，没有冻结NoWrite来制造优势。
- 完整R+L持续，immediate I与未读哨兵受保护；只读检查不训练、不写入。
- 候选是显式给定的keep/删除访问条目，不是学出了通用修复语法。
- 学到的是28行轨迹特征价值表；特征、共同Q*先验、规则与预算由实验设计给定。当前没有学习因果后验p(C)，也不是从零获得世界知识。

## 实践与资源不是免费的

最终实验实际230rollout=128主任务+96只读检查+6实践任务；实践新增62步及2次分支候选事务。模型原开发的196个探测回合仍是历史训练成本，不因复用变免费。

四组任务安排相同，但总计算量不匹配，没有“同算力额外普通训练”组，因此不能说总计算更省。练习依赖模拟器重复当前条件及独立R+L副本；不能推广成现实环境可以免费克隆。只测试keep和最多两个同分候选，不宣称全菜单最优。

新增实践是单独声明并计费的能力；原查询API0调用不代表新增环境工作0成本，也不迁移旧0query资格。更新作用在post-TD当前状态，不冒称旧same-pre whole-B1。原任务失败回报未改，本轮不能回答额外惩罚的消融问题。
