## 比旧接口前进了什么

诊断不再通过任意 apply 回调自行写入、再声称成本。现在它只返回结构化 Proposal；执行器先检查地址确实出现在本回合可见轨迹里、架构写通道正确、成本不超限，再调用原事务并计数。查询目前不提供，预算为0，不把声明的查询成本冒充实际执行。

诊断收到的只有 learner-visible FactualEvidence 与不可变预算视图，不收到完整 mask、配置错误或 evaluator truth。代码接口不是恶意 Python 的安全沙箱，现有验证不作这种扩大承诺。
