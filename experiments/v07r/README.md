# V0.7 研究方案：让事实进入选择

**状态：方案已制定；新学习器尚未实现，新实验尚未运行。**

用户要求：重点解决“事实记住了却没用好”，增加独立训练与评估次数，同时保留纯强化学习、纯反馈、有奖惩和只有奖励的对照。本方案承接已完成的 V0.6，不重新打开旧阶段的总体确认门槛，也不恢复自动任务。

## 1. 核心问题与这次只改的环节

> 在同样的事实记忆、Q 更新与交互预算下，让事实直接参与行动选择，能否减少重复碰撞、更早形成较好策略？它是否比简单地“多尝试没试过的动作”更有效？

V0.6 的具体问题不是没有记录：在 seed6001 / mirror0 / p=.10 的 F-R 流，第16回合已记下同一命令16次碰撞，但两个命令的 Q 都为0，固定平局规则仍选择它。当前只有奖励的模型目标为 `p_hat * V(next)`；下游价值尚为0时，事实概率变化也不能改变这个目标。

因此本轮优先测试**行动读出**，不同时更换学习率、奖励、事实先验、地图难度、更新顺序或探索比例。不把“加入负奖励”冒充解决事实利用问题。

这是一项受 V0.6 已知结果启发的前瞻设计，不是没有看过历史结果的盲探索。新增种子和预算在本轮方案中先固定，结果出来后不挑换。

## 2. 保留五个原对照，增加四个有明确用途的变体

|组别|信号与学习路径|Q 最大值平局时怎样选|
|---|---|---|
|RL-RP|纯模型无关 Q＋自身真实回放；成功+1、失败-1|命令0优先，沿用V0.6|
|RL-R|相同纯 Q 路径；成功+1、失败0|命令0优先，沿用V0.6|
|F0|纯事实计数＋目标到达概率规划；没有reward字段或Q头|最大目标到达概率，再命令0优先|
|F-RP|事实模型＋Q＋有限模型备份；成功+1、失败-1|命令0优先，保留旧读出作对照|
|F-R|相同混合路径；成功+1、失败0|命令0优先，保留旧读出作对照|
|F-RP-FT|与F-RP相同，只换读出|优先事实估计更可行的动作|
|F-R-FT|与F-R相同，只换读出|优先事实估计更可行的动作|
|F-RP-CT|与F-RP相同，只换读出|优先实际尝试次数较少的动作，不按成功/失败比例排序|
|F-R-CT|与F-R相同，只换读出|优先实际尝试次数较少的动作，不按成功/失败比例排序|

FT = factual tie-break，CT = count tie-break。共9组，不再叠加其它算法变体。

**为什么保留CT？** 否则FT胜过固定“命令0优先”，仍可能只是因为它打破了僵化平局，而不一定用好了结果内容。CT是一个简单且有竞争力的替代解释对照。尝试次数也是广义历史反馈，不把它排除出强化反馈学习；若CT同样好，仍是有价值的经验利用结果，只是不把优势独占归给结果概率。

所有组都保留自己的历史、正常学习成功与失败，拥有相同动作权限。纯RL也有回放，不制造不会学习的弱对照。这里“纯RL”指这条明确的模型无关基线，不代表整个强化学习领域。

## 3. 两种新读出如何实施

令 `A_Q(s) = argmax_a Q(s,a)`，用现有binary64数值的**精确相等**确定平局，不新增近似平局容差。

- **FT：** 若Q最大者唯一，保持原动作；否则只在 `A_Q` 内选择 `p_hat(s,a)` 最大者；仍相同则选编号较小者。
- **CT：** 若Q最大者唯一，保持原动作；否则只在 `A_Q` 内选择 `N(s,a)=n_forward+n_collision` 最小者；仍相同则选编号较小者。
- 未尝试动作仍为真实计数0/0，声明的Beta(1,1)先验给出 `p_hat=.5`；先验不记作实际经验。
- 事实估计仍为 `(n_forward+1)/(n_forward+n_collision+2)`。一次失败降低估计但不将概率归零，不设置永久动作禁令。
- 选择之后才按共同epsilon=.10决定是否执行探索动作。探索开关与探索命令外生坐标在各组配对；FT/CT不额外抽随机数、不额外获得环境回合。
- FT与CT都只改变动作读出，不修改Q值、reward、事实计数、普通TD或模型备份的方程。

所有Q组保持零初始化、alpha=.5、gamma=1、64条自有转移缓冲；普通TD按真实时间顺序执行。每训练回合额外备份仍为 `min(12, buffer长度)`：RL用最新优先真实回放，混合组用原visited-only、房间降序/命令升序的模型期望备份。F0保持V0.6概率目标规划。

**明确的能力边界：** FT解决的是“Q无法区分时，事实不能参与选择”的断点。如果Q已形成不相等但错误的排序，FT不会推翻它。本轮必须报告这种剩余错误，不事后加权混合概率与Q，也不因这一限制否定所有反馈利用。

各组选择改变后，后续经历会自然不同。“更新规则相同”不等于强制拥有相同历史。为定位机制，在同一真实训练前状态上额外计算旧读出/FT/CT三个只读建议，不执行额外环境回合，不把这些建议称为完成过三条反事实训练。

## 4. 环境不扩大，把重复做充分

沿用V0.6的3个串联岔路、2份镜像、固定root命令交换和未读保护位置。阻挡出口必然碰撞；可行出口分别采用 p=0 和 p=.10 的偶然碰撞概率。世界在每条流内不变化。

学习器只得到公开目标、合法动作、分层拓扑及自身真实命令/执行/后继/结果。不提供正确出口、p、隐藏碰撞原因、未来随机带或评估结果。无旧Q*、checkpoint、额外控制器修正或诊断调用。成功与失败均普通学习；成功不新增归因。

|项目|V0.6|V0.7固定安排|
|---|---:|---:|
|每条件独立训练seed|4|**32：7001至7032**|
|每策略、每检查点随机评估回合|32|**512**|
|每流训练回合|64|64，前32/后32不断档、不重置|
|冻结检查点|0/16/32/48/64|**0/8/16/32/48/64**|
|镜像/环境噪声条件|2/2|2/2，保持不变|

独立训练重复增加8倍，随机评估量增加16倍。增加e8是为了观察早期改善，不声称能定位两个检查点之间的准确学习时刻。

512次并不保证能区分任何微小优势。按独立Bernoulli抽样、真实成功率.729计算，单策略成功率估计的近似95%半宽约3.85个百分点；完全正确策略仅因该批评估而低于.6561的概率约0.000122，而32次时约0.13148。这里是设计精度计算，不是已执行结果或通用功效保证。32个训练seed是否足够清楚区分方法，最终看成对差值区间；不以追加到显著为停止规则。

### 随机性与配对

使用新的本地工程命名空间 `V07|seed|mirror|phase`，训练环境、训练探索与评估环境分离。每个seed/镜像的外生数值先生成，坐标不包含arm或p；评估坐标也不包含checkpoint，各组与各点使用同一独立于训练的512项评估集。不同分支长度不改变后续坐标。

使用共同随机数降低成对比较的测量波动；**重复使用同一评估集不增加独立样本量**。各组在同一seed下是配对，不是相互独立的训练证据。推断单位为32个seed块，先在每个seed内平均两镜像，p两条件分开。不能把1152条组别流、训练回合或评估回合当成1152个独立方法重复。

## 5. 冻结评估与指标

### 不把评估数据喂回学习器

每点从完整Q/counts/buffer/history构建只读副本，epsilon=0；包括CT在内，评估中不增加尝试计数。全体读出因此都是固定状态下的确定性策略。评估0学习写入，不选择后续训练方案或停止时机。

- p=0：每检查点1次真实评估；确定性策略不重复512次凑数。
- p=.10：每检查点512次真实评估；完整结果和真实步数保留。
- 完整训练曲线保留每个整数回合的成功、失败及成本；冻结曲线保留全部6点，不挑最好点。

### 先固定主要比较，再看结果

核心比较在p=.10下：

1. `F-R-FT − F-R`：事实参与平局是否解除已观察到的利用断点？
2. `F-R-FT − F-R-CT`：是否优于仅按尝试次数避免重复？

主效果指标为**前32训练回合范围内冻结成功率的归一化梯形AUC**，点为0/8/16/32；两个比较同时完整报告，不事后只选较有利一个。

同时必须报告实际早期训练失败数、e16/32/64累计成功、完整0..64冻结曲线、后期退步和共同训练步数预算下的已交付成功数。实际成本比较仍按每seed/镜像/条件/方法对的 `B=min(两组训练总步数)`，在B的25/50/75/100%比较。

RP下两种读出变体、纯反馈F0、两个纯RL基线及有/无处罚对比全部保留，作为预先列明的次要对照，不因结果不利删掉。

### 把“路线没学会”和“这批评估运气差”分开

这个小环境可在**评估端**依据真实源配置精确计算冻结程序的成功概率：正确路线为 `(1-p)^3`，任一必碰撞命令则为0。该值只进入外部分析，不能成为学习器输入、训练目标、选择依据或停止信号。

每个检查点并列报告：

1. 512次真实评估的成功率和Wilson 95%区间；
2. 该固定策略的精确环境成功概率；
3. 两者之差，检验抽样误差是否能解释表面不达标。

保留90%可达上界阈值：p=0为.90，p=.10为.6561。但**达标标签只是辅助指标**。实测首次跨阈值和精确策略首次跨阈值分列；实测区间跨阈值记为测量不确定，不据此改写旧V0.6标签。未达null/右删失，后续跌落不删除。

### 机制记录

只在真实访问的位置统计：Q平局频率；平局内事实概率是否存在差异；旧/FT/CT读出是否不同；事实建议是否被训练探索覆盖；实际前进/碰撞；非平局错误还占多少。完整记录平局候选、Q、真实计数及所选动作。

“选择了事实估计较差动作”不等于已知真实最差；“再次碰撞”也不自动等于无效尝试。结果侧真值可用于外部诊断，但不能倒流到决策。检查点的三个同状态只读建议仅解释决策环节，完整收益结论仍来自各自真实连续训练。

### 不确定性与解释

公布32个seed的成对差值、均值、中位数、正/零/负个数；主指标用seed块成对bootstrap（预定10000次重采样）给出95%区间，保留镜像、p和检查点之间的配对结构。分析重采样单独计数，不是新增训练样本。

这些区间用于呈现效应大小与不确定性，不设置“必须显著才完成”，不将未显著称为等效，也不从全部对照里挑选赢家声称全family通过。[Agarwal等关于少量训练运行与评估不确定性的研究](https://arxiv.org/html/2108.13264v4)。

### 实施顺序

1. 在新namespace实现FT/CT读出与记录；旧学习/环境语义按V0.6复用，旧已执行字节不改。先静态检查规则分支，不能把合成计数单元测试称作原生证据。

4. 独立存储分析核对计数、实际选择、Q备份、冻结隔离、资源和全部结果；不再执行旧native或旧checker。

首次失败/超时/partial原样保留，不自动重跑已完成流，不按效应调参数、换seed或加样本到正收益。资源不足先保存具体状态，必要修订另行明确；不把技术失败包装成算法结论。

## 7. 怎样结束，怎样解释

当九组按同一预定矩阵运行、事实到动作的路径可核对、训练与评估隔离有效、成本及正/零/负结果完整，就可给出阶段结论。

- FT优于旧读出且优于CT：支持这套环境中结果内容参与选择有额外价值。
- FT与CT相近、都优于旧读出：说明解除固定平局/利用尝试历史已足够，不把收益都归给概率事实。
- FT只在早期更好、最终追平：仍是学习效率收益，不要求永久领先。
- FT效果为零或更差：保留结论，检查已记录的触发覆盖、误导性小样本和非平局错误；不当场追加新算法追正收益。

本轮不要求更复杂地图、陌生任务迁移、通用品味涌现或全指标获胜。固定alpha与最新优先回放的稳健性是已知边界，这次不同时调它们以免无法判断事实读出的作用；纯RL结果不外推为所有强化学习方法。

**本次交付仅为方案。** 新native、训练、评估、随机带生成和自动任务变动均为0。机器可读安排见 `plan_v173.json`；下一实施件是只改读出的FT/CT版本，而不是再做一轮范围审阅。
