# V214：条件化历史适用性，首次有限实验

2026-11-11；此文件、数学V6、源码及 contract.json 在第一次执行之前固定。

## 问题和主比较

历史事实不是当前正确答案。检查旧结构中“在别处预测有效，所以在这里也采用”的条件混同。新结构将历史H、当前F和适用分组G分开，先预测和行动，再用实际结果更新门控，最后F学习事实。历史原文保留；不把推测的原因写成真实结果。

五个正常学习方法：pooled_history（不遗忘的合并历史）、fresh_only（仅当前学习）、temporal_v210（延续历史的原时间算子，配共同关系混合层，并非声称完整旧部署复现）、global_gate（H/F全局适用性）、conditional_gate（H/F条件适用性）。主要机制比较为 conditional_gate − global_gate；同时必须报告强时间对照和正确历史场景，不能只与不遗忘的弱对照比较。

四类环境：stable_novel、changed_novel、selective_change、noise。3个公开二元字段，2个动作和2个实际结果；目标为提高实际成功率。各seed隐藏字段位置不同，学习器不知道真实规则。stable/changed的历史、可见新条件及随机数相同，但新结果规则相反；检验在尚无新反馈时不可辨识，之后再看适应。

## 真实交互、资源和计数

* 每类16个独立训练seed，共64个shard。各shard事先指定一次执行，不重试。
* 每shard先用均匀动作获得256条真实历史。其完整副本分发给五个方法；同一批事实被多个模型解释，不算新增环境交互。报告共用采集量和每方法享有的256条历史，不能把前段成本隐去。
* 每方法256次当前在线交互。在0/16/64/128/256各做128次独立评估，评估不写事实、计数或模型；不是训练集回测。
* 每shard实际256 + 5×(256+5×128) = 4736个一步任务；总303104个实际动作/结果交互。其中历史16384、当前训练81920、只读评估204800。3个输入字段不是3步。
* 新8项人工公式/接口检查单独记录，合成事实不是环境交互，计为0环境回合；不执行旧checkers或旧实验。
* 最多4个独立shard进程并行；同shard的5臂、训练和反馈顺序串行。CPU单线程/进程，固定解析神经参数，无GPU/优化器/梯度训练/SLEEP参数巩固。
* 总执行预算1800秒（含检查、试验和存储复算），每shard最多240秒，公式检查最多180秒，存储复算最多480秒。超时/错误保留首个日志、raw和退出事实；无自动重试。不按效果追加seed或改任务。

## 指标与边界

报告全过程训练成功率、前64次成功率、5点评估曲线、学习后4点评估均值、最终评估、预序贯log-loss、历史份额分条件变化、CPU和缓冲区成本。16个seed是重复单位，不把回合当独立训练重复。配对seed差及固定2000次bootstrap仅作探索性区间，不是多family正式确认PASS。

原始输入、实际行为概率、动作、实际结果、预测和门控均保存。独立stdlib实现逐条核对公式、实际一步核、顺序、计数、EOF和输入SHA；它是程序核对，不是独立专家审查。发现零、负结果照实保留。

输入到结果的任务段边界在本实验已知；高维/连续条件、遗漏变量、长程归因以及自主发现任务边界尚不解决。历史份额是预测相容性权重，不是因果责任概率。局部实验不会自动改变旧研究结论或部署任何候选。
