# V229：移除限制以后，模型选择调查仍然失败

2026-11-12，首次训练完成，427.09 秒。18 个从零模型：追逐图/通用任务各 3 个训练种子、3 组；每模型 24576 个实际环境步、1536 次优化调用。总训练/试验/比较 442368 步。评估为同一组固定场景，0/12288/24576 步三个检查点，每种执行模式 3×32 局。

## 本轮实际变化

- 接通事实、实际配对效果到共享编码器和记忆读取的梯度。
- 保存所有已获得的真实事件和全部已完成失败轨迹候选；64 节点为全历史抽样读取预算，不删除更早的事件。
- 不再把预测分歧作为调查优先级，也不相加 16 步效果和 64 步预测。新增组以真实完整剩余对局的行动效果训练候选头。
- 正/负/零试验都保留学习；没有逐样本改善门槛，没有中间教师及教师验收。只保留一次最终学生与等量普通学习参考的实际比较。
- 记忆仍只有向量/行动/后果，没有完整历史图像；全历史检索仍是抽样后注意力，不是已经解决了精确检索。

## 得到的具体问题，而不是绕过负结果

选择器每模型只得到 **6 个不同的配对效果标签**，然后在大量更新里重复学习它们；却被用于对最多 16 个历史状态及其多个动作排序。删除限制没有自动提供足够的任务相关监督。V229 的负结果不证明“开放学习无效”，但否定了本次直接把这个稀疏选择器当作可靠改进器的做法。

据此另立 V230，只增加“完成的真实轨迹 → 实际剩余结果”的监督，检验稀疏监督这一具体问题。V229 结果与代码保留，不重跑原对照，不把 V230 追认成 V229 通过。
