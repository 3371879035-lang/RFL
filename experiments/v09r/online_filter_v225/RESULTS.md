# V225：真实行动、历史状态与训练条件分布统一

**已完成本轮数学推导、神经网络接线及未训练有限实验。参数更新0，不宣称训练收益。**

北京时间2026-11-12，独占capture首次 native exit 0、首次 stdlib audit exit 0，无重试、无超时。launcher实测159.211966秒（包含本轮全部诊断与审计，不是生产推理速度）。

## 1. 找到并修复的具体问题

V224的世界序列训练会从开始前历史初始化一次，逐事件递推 `belief_update`；真实行动前向则每一步用全部历史重新初始化。旧网络确实读了历史，不能说它完全没有记忆；但**训练与真实行动没有使用同一个条件分布**。旧思考器已经使用递推，不能把这个问题扩大成旧模型所有递推都没用。

V225把这两条路径合并：

1. episode开始前的真实历史生成可学习先验和参考记忆。
2. 当前连续episode的新结果由同一个可微观测内核逐个吸收；事件只进入一次，保存状态和假设后验。
3. 下一实际动作使用该状态预测；没有结果时不能先吸收结果。
4. 完整序列和中段训练调用同一个内核。中段先重建实际前驱条件，不能冒充新episode。
5. 决策侧可学习reader仍能参考全部真实历史，但不把它重复当成独立似然。
6. 想象从已有实际状态出发，不把自己的模拟样本写回真实后验；实际试验是明确的新分支，不延续已经终止的源episode。

**没有盲目扩参**：仍是20,469,653参数、249个参数张量、96个可学习工作槽位、8个潜在分量、3个新候选。96不是事实节点条数上限。这次修复的是数据流而非容量不足。

## 3. 核心结果

两种子各5项定向检查，共**10项通过**。

### 真实运行与训练数学一致

- 75/75个真实动作前状态的h字节与独立离线同前缀重建一致。
- 同前缀预测最大差 **0**，后验对数权重最大差 **0**。
- 完整序列在线累积NLL与训练NLL最大差 **1.42e-14**。
- 中段条件NLL与完整NLL减前段NLL最大差 **2.84e-14**。
- 标准库从已存分量似然独立复算后验递推，最大差 **3.55e-15**。
- 每个真实事件在在线过滤器中恰好吸收一次，初始化参考与当前段证据ID交集0，预测前缀不含目标事件。

这里标准库没有重新执行神经似然网络：它独立核对的是已存分量的递推公式、计数和时间顺序，不是独立科学复现实验。

### 旧式重初始化确有可测差异

对本轮新的真实源任务前缀，额外只读计算旧式“每步重初始化”公式，不执行旧native、不增加环境调用：

- 首步两种条件化方式完全一致。
- 后续步后继均值最大差：seed137 **0.00798772**，seed149 **0.00863284**。
- 单步实际结果日志密度差绝对值最大约 **0.02503 / 0.04627**。

这定位训练/运行分布不一致，**不是这些数值大小代表新方法更优**。未训练网络的预测仍可能是错的。

### 后验并非强制越来越自信

解析例子(.5,.5)经(.9,.1)证据得到(.9,.1)，再经(.1,.9)证据回到(.5,.5)。本轮75个真实结果更新里，分量后验熵上升2次、下降73次；没有为凑双向变化改数据。熵变化不是置信校准正确性的证据。

这些分量是模型中的互斥预测假设，不是“撞墙占失败原因60%”之类因果比例。真实原因可能多个、相关或未知。

### 原实际结果训练路径仍连通

- 世界真实序列梯度：两种子均155个参数张量非零，含递归状态、记忆编码和先验头。
- 真实成本、零基线策略梯度：seed137为78个，seed149为89个；候选生成、决策记忆读取、actor均连通。
- critic真实目标梯度：两者均5个；各路线梯度有限、跨路线泄漏0。
- seed137没有实际试验，采用头及部分试验证据读取参数没有非零梯度，这是已执行路径的真实覆盖限制，不补造试验。seed149覆盖原89个策略张量；不把seed137也说成全覆盖。
- 同快照候选代码、决策概率、critic值重放最大差均0，完整日志密度差仅浮点求和量级。

额外思考诊断分别从已吸收3个真实前驱事件的状态启动，使用同一实际后验作为根权重；产生30个想象节点，真实状态和事实银行保持原样。

## 4. 仍然存在的问题

1. **还没训练**：预测准确性、条件校准、原因识别、行动收益及泛化均未证明。梯度连通和公式一致只是必要基础，不是充分条件。
2. episode内仍是假设分量k固定。状态突变、模型错配可导致后验自信地出错；没有用固定遗忘率掩盖这个问题。
3. 当前连续状态只支持目标不变、没有其他任务事件穿插的实际链。遇到穿插需明确新的条件化协议，不能静默丢弃新信息。
4. 过去episode通过神经记忆形成learned prior；不是完整贝叶斯世界知识。决策读取仍依赖这个编码器。
5. 在线缓存避免重复吸收当前段，但全部历史reader仍有成本；离线参考实现为保证完整可微条件，可能重建前缀。尚未做大规模长序列性能和保留能力验证。
6. 思考仍为有限开放环近似，不能假设未来合法动作集合已知不变；本轮实际动作集变化测试不等于一般闭环规划完成。
7. SLEEP长期巩固仍未训练。现在有一致的真实历史训练接口，不等于已获得长期能力。
8. 继承V224的目标达成/成本策略损失若用于优化，仍是RL风格目标优化接口，不自动代表严格无奖励纯反馈；本轮没有采用标量权重或更改以前组别定义。

不建议仅因可以扩参就继续堆层。下一次训练验证应关注：一致的历史递推是否真的降低预测误差、改善实际行为、保留旧能力；本轮保持“不更新参数”的边界。
