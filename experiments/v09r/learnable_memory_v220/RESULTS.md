## 2. 解决了哪些结构断点

1. **历史不作为直接答案**：原始节点区分先前预测与实际反馈、记录条件/来源/前驱/缺失。查询条件化读取和经验适用性门均可训练，不把相似场景的旧误差直接加到当前结果上。
2. **先验不循环重复吃同一历史**：没有历史时走可学习查询与空记忆路径；历史按事实身份进入一次上下文。重复导入同一id不加节点，回放不增加新交互，训练样本不见目标之后的历史。不能据此声称已解决所有事件相关性和训练过拟合。
3. **不确定性可以按条件升或降**：预测头输出条件分布，实际后果的NLL提供双向方差梯度；同时显式保留跨动作模型协方差。相同边际方差1.1/1.1，在正、负相关两种数学fixture下，动作差方差分别0.2和4.2，而简单相加都得2.2。此检查证明公式接通，不证明真实概率校准。
4. **给模型学习决策的接口**：Actor、候选生成、是否试验和实际试验后采用均由参数化网络评分，不硬编码相似即复用、不确定就禁止行动或试验成功必采用。唯一固定的是事实和实践来源边界。
5. **候选不能自证**：控制码只改变Actor，不改变同一观察/历史/动作的后果预测。检查中预测逐值相同，Actor概率发生0.00074914的最大变化；这是随机初始网络的敏感性，不是改善证据。
6. **为后续训练留好记录**：真实事件有前预测/后果；主任务、候选试验、采用选择有行为概率和历史前缀；有实测NLL、策略损失、回放蒸馏损失接口。成功只进普通学习样本，不额外触发失败反思。

## 4. 实验暴露的边界，而不是隐藏为“通过”

- 主任务93/192成功，48.4375%；动作分布平均归一化熵0.9999998202，距均匀分布最大偏移仅0.00035737。**随机网络没有因为接通反馈就自然获得好策略。**
- 24次采用中，11次对应成功试验、13次对应失败试验。失败经历不等于没有价值，失败试验也不必一律禁止采用；但这更不能当作当前Adopter已有可靠选择能力的证据。采用计数不是改进计数。
- 非零梯度只说明损失能传到模块，不保证训练稳定、样本效率好、概率校准或迁移成立。
- 适用性门没有天然因果语义；混合成分分歧不等于已识别的贝叶斯认知不确定性。仅观察实际选择动作还不足以完全识别跨动作反事实耦合。
- 向量schema可配置、动作数与记忆长度可变，不等于已经具备文本/视觉理解。记忆全量注意力为O(N²)，本次最多25个实际节点/run，没有长历史扩展结论。
- 目前想象是一轮前向的一步预测对象，没有多步梦境搜索；回放蒸馏只是训练接口，不宣称完整DreamRSI/SLEEP复现或已经得到长期巩固收益。
- 采用只切换行为控制码。真正训练修改参数后，旧控制码语义、候选有效性需要重新验证/清除；这轮没有实现并检验跨权重版本的持续采用流程。
