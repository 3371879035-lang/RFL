## 1. 确定的实现错误，不是统计波动

原`spatial_feedback_v179/learning.py:386`的多头采样公式为：

```python
(((uid + j * 17) * 1103515245 + 12345) % 7) < 5
```

原合同称它对各头提供确定性的five-of-seven样本掩码。但：

- `1103515245 % 7 == 0`
- `12345 % 7 == 4`
- 所有样本、所有头均得到`4 < 5`，即全部选中。

本轮直接提取原源码AST中的NumPy表达式，核对整个0..262143记录编号域：三个头选中率均100%，两两掩码差异均0；最大中间值远低于int64溢出界。没有执行原`Agent.learn`、训练器或旧fixture。

**原先设计的数据子集差异没有实现。** 三个头仍有不同初始化，不等于三个网络参数完全相同；也不能仅凭这处错误量化其造成了多少分数损失。原来按five-of-seven描述这批模型是不准确的，当前结果应标记为“实际含此掩码缺陷的候选实现”，不是忠实实现了全部计划特性。

该问题影响三个事实组，包括F0。原执行源码、合同和成绩不覆盖；纠错记录在这里追加。

## 2. 即时事实与后继预测分开检查

固定前12个完整种子、两个混合组的24个最终模型，沿用V181预先固定的64个回放窗口。每模型1024个位置，只对非终止位置比较真实存在的下一帧，合计23,713个位置；终止位置不把下一回合首帧伪装为当前回合后继。

对原一步估值计算做两个**只读、事后代数替换**：

1. 保持即时拾取/捕获预测，只把预测的下一内部状态替换为实际下一次观察形成的内部状态。
2. 保持预测的下一内部状态，只把即时结果替换为实际观察结果。

|组|原一步估值MAE|只替换后继表示|只替换即时结果|
|---|---:|---:|---:|
|F-RP|0.21970|**0.03135**|0.21763|
|F-R|0.15944|**0.02467**|0.16324|

两个混合组各12/12模型在替换后继表示后降低误差。误差的即时项、存活门控项和后继传播项也按恒等式分解核对。

**在这批已执行非终止转移上，较大的这部分数值误差主要来自后继表示及其Q值传播，而不是即时事实项。** 这比“反馈组差，所以反馈没用”具体得多。

重要边界：比较目标仍使用模型自身的Q估计，不是最优Q或真实长期回报；所有数据来自自身训练回放，不是独立测试。替换只用于离线诊断，没有交给策略，也不是修复后的任务得分。它没有隔离全部训练侧原因，更不直接解释F0的全部问题。

## 3. 后继表示的一项结构负担

原解码器使用`next_h = tanh(h + 0.1 * delta)`。即使delta为零，也不是保持h，而是再次压缩h。

|组|实际模型后继MSE|直接沿用h的MSE|delta为零但再次tanh的MSE|
|---|---:|---:|---:|
|F-RP|0.02902|0.02698|0.04724|
|F-R|0.02575|0.02308|0.05094|

模型学到的delta补偿了一部分压缩，但仍未胜过不变基线。这是可测的参数化负担，**不是已经通过独立训练消融证明的全部病因**；不能简单改一行激活函数就宣称修复成功。

结合V181真实冻结Q-only干预，可确定当前流程存在：**后继预测不够可靠，却无条件替代已有动作价值；三个头的计划采样差异又没有实现。** 不确定性逻辑主要决定展开深度，不决定何时应不采用这条推断。

## 4. 次要设计偏移：安全经验也可能被先验降低评分

原检索修正对n条均未被捕的记录使用`(1+0)/(2+n)`。在固定代数示例中，模型原捕获概率0.03、n=1时，加入先验得到1/3，再按原权重下调RP动作分数约0.0337；无支持记录的动作却不接受这一项修正。

这说明“事实没错”与“如何编码、加权事实”不是一件事。这只是公式例子，不是该偏移造成全局差距的独立因果证据，不能据此责怪处罚本身。既有关闭检索消融的影响远小于总差距。
