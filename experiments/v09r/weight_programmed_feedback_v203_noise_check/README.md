# 冻结 V203：独立试验噪声压力检查

**没有新算法、没有改权重。** 只检验主实验的共用试验随机数是否掩盖误采纳风险。使用 V203 同一检查点，16 个新种子，两个噪声协议，三个机制对照，全部实际交互预算相同。

|任务|试验噪声|V203 完整|V203 全局门|V203 无门|
|---|---|---:|---:|---:|
|稳定随机|共用|79.49%|77.54%|78.91%|
|稳定随机|独立|79.49%|78.32%|79.30%|
|随机反转|共用|74.22%|66.80%|74.02%|
|随机反转|独立|75.39%|69.14%|76.95%|

各格是最后 4 周期的 512 个留出评估回合均值，独立比较单位为 16 条种子序列；本表的新实例不能与主实验旧实例分数直接拼成差值。

完整版在独立试验噪声下仍比同条件年龄的全局门高，但随机反转末窗和全程均值仍低于无门版。独立噪声反转的 2048 对采用前/后留出评估中，完整版观察到 117 对改善、1 对退步；无门版 129 对改善、14 对退步。这些不是错误采纳率的置信估计，不表示无门或有门普遍更好。

反转后最初两周期，完整版仅 21.88%，因此及时发现并应对变化仍是实际缺口。不能以恢复后的成绩宣称已经解决。

候选/现行策略的独立试验噪声由两个不同确定性种子流产生，初始条件与动作并列选择流相同。采用前/后外部评估仍配对共用噪声以减少报告方差；这些评估结果从不进入记忆或采纳规则。
