# V0.9：二维追逐中的自主反馈利用

**状态：方案已制定，尚未实现或运行新训练。**

直接依据用户要求：“你自己决定，计划V0.9吧……逐渐放权……让反馈更加有效果……提高训练次数。”本版沿用四个核心组，不把旧V0.3确认方案搬回来，也不要求总体正收益才能结束。V0.8已完成，不重跑旧实验。

## 1. 这次要回答什么

> 在局部可见、存在追逐和资源权衡的二维任务中，让智能体逐渐取得经验检索与多步决策的使用权，能否使它在相同真实交互预算下更早学好，并减少可避免的重复失误？

改进针对V0.8实际留下的两个问题：**有限事实估计会误导选择；一步读出仍可能被错误的后继价值拖累。** 增加地图复杂度不是为了保证差距变大；增加训练也不是一直跑到反馈组获胜。

人的、程序的、历史经历的和实际结果的反馈，都可以属于反馈。本版只把其中可直接执行的环境事实、历史与目标接通，不引入LLM裁判、人工逐步标注或完美责任Oracle。Dream-RSI/RRSI仅用于助手的研究方法，不接入学习器。

## 2. 环境决定：本地类峡谷追逐，而不是冒称官方复现

采用已读腾讯文档中的任务形态，但**自建本地64×64版本**，不等待平台训练权限、云GPU或官方SDK。保留21×21视野，地图明显大于视野；不只是把旧岔路画成二维。

官方参考见[环境评阅](../environment_references/tencent_gorge_chase_15_0_1/README.md)。官方原版为128×128，本地尺寸、时限、怪物算法和生成地图均是明确的新实验设定。

|项目|本版固定安排|
|---|---|
|地图|64×64；道路、障碍、环路、支路、资源点|
|地图集合|12个预定生成种子：90101–90108训练；90109–90112保留测试；不按算法成绩筛图|
|生成方式|9×9路口网格，中心坐标4+7j；宽3格道路；随机生成树保证连通，再以0.25概率加入未使用邻接边形成环路；边界不可通行，不做按效果的地图拒绝采样|
|视野|以英雄为中心21×21地形和当前可见物件；视野外怪物只有方向与距离桶；未知地形保持unknown|
|动作|所有组从第一步起都有八方向移动、八方向闪现；冷却掩码相同；不替纯RL删除闪现|
|资源|10宝箱、2加速点；加速50步、刷新100步；闪现冷却32步；直向10格、斜向8格|
|单局上限|256步；到上限仍存活是完成，被捕是失败；预算中断、运行错误另列|
|任务目标|尽量存活并收集宝箱；外部得分S=1.5×存活步数+100×宝箱数|
|两种局势|solo：一只怪物、速度1；duo：第二只于第96步出现于英雄10步前位置，第160步后怪物速度2|

训练从头到尾均使用同一地图/solo-duo平衡混合，不与放权阶段一起换难度，从而不把“换任务”和“放权”完全混在一起。每16个新回合覆盖8训练图×2局势，顺序由外部训练源固定；四组共享同一编号回合的初始条件。不同方法在同样步数内可能完成不同数量回合，如实记录。

**本地怪物定义：** 每个移动子步，0.9概率选择到英雄最短路距离更小的合法邻格（等距随机），0.1概率选择任意合法邻格；无路则留在原地。寻路仅供环境内部执行，不能被学习器调用。第二怪物出生依赖本方法实际英雄历史，不强行与其它方法固定到同一绝对坐标。所有随机量按回合、步、怪物及子步坐标分离，避免轨迹长短改变后续随机流。

**更新顺序：** 英雄动作/路径收集后检查捕获，再按怪物编号逐子步移动和检查捕获，最后输出观察并更新冷却；首次捕获即结束。捕获用Chebyshev距离≤1。普通移动逐格检测；斜移要求目标通行且两邻边至少一边通行。闪现从远到近选可通行落点、沿途拾取、只在落点检查英雄阶段捕获；无落点仍消耗冷却。它是本地明确约定，不推断官方所有边界也这样实现。

出生与资源只在合法道路生成，英雄不与资源重叠，初始怪物与英雄至少相距8格。第一怪物优先使用视野边缘道路；若边缘无候选，使用距离≥8的道路集合。固定候选列表后抽一次，不因回合结果换源。生成器不提供最优路线、全图、隐藏怪物策略或未来随机数给学习器。

## 3. 四个主组：只保留真正需要的对照

|组|实际学习路径|显式标量训练信号|
|---|---|---|
|RL-RP 纯强化学习|小型循环Double-DQN，真实经验回放、历史输入；无显式事实预测规划|有奖励、有处罚|
|F0 纯反馈|自己的事实预测、条件经验、目标规划；无Q奖励头、无奖励包|无外部标量奖励/处罚|
|F-RP 反馈＋奖惩|与RL相同Q学习核心，另接事实预测、经验检索和规划读出|有奖励、有处罚|
|F-R 反馈＋仅奖励|与F-RP相同实现，仅移除捕获负奖励|有奖励、无额外处罚|

奖励固定为 `r_plus=0.015×本步新增存活步数+本步新增宝箱数`；RP组另在被捕时减1，R组不减。无撞墙罚、探索奖、闪现奖或事后增加的塑形。正常上限没有额外奖罚。被捕本来就会失去后续存活与收集机会，R组仍能从真实结局学习。

这次处罚项**不保证与仅奖励目标具有相同的最优排序**；应区分学习信号效应与风险偏好变化，不能沿用V0.8二元终止条件下的仿射等价解释。

### 公平条件

- 同样的局部观测、16动作、时间与技能信息、当前可见事实，以及由自己观察形成的地图记忆。所有组都保留成功和失败的普通经验。
- 所有组拥有相同的历史存储上限、历史检索接口和循环记忆容量；纯RL可以学习使用历史，不能被故意做成健忘对照。它不接额外事实预测器或规划器，这是方法区别，不是少给合法输入。
- 地图工作记忆每个新回合从空开始，只写本回合实际观察；跨回合通过自身长期记录和已学参数复用经验，不按隐藏地图ID读取预存全图。检索键排除map_id、seed和评价标签。
- 三个Q组共用同一循环Q实现、初始化配对、真实回放和更新安排。反馈模块新增的参数、训练、查询和规划成本另外公布，不说完全等算力或只有归因这一因素不同。
- 每组只使用自己的经历，不借其它组失败、测试结果、全局`extra_info`或环境内部怪物寻路结果。

### “纯反馈”具体是什么意思

F0训练的是“采取动作后会出现什么事实”，例如位移、被捕、拾取和后续可存活步数；损失来自真实事实预测误差，不接收`reward/score`作为优化标签。行动仍有公开目标，规划时会把预测的存活与宝箱按同一任务目标比较。

**它不是没有目标、没有损失函数、没有内部数值比较。** 目标规划与模型式RL存在概念交叉；本版“纯反馈”是“无外部标量奖惩训练信号”的操作性定义，不宣称一种与所有RL数学上互斥的新范式。不能偷偷把事实组合成奖励后又喂给F0的TD或策略梯度。

## 4. 渐进放权：先交出行为权，再交出经验和计算的使用权

全部阶段均保持同样16动作与环境配置。阶段按真实训练步数固定，不按哪个组先赢或预测达到多少分才开门。

|阶段|每模型已用训练步|开放内容|
|---|---:|---|
|A：自主行动|0–16,383|路线、移动、闪现由本组选择；记录自身事实和普通学习。反馈组使用轻量一步预测；不提供人工路线或逐次修正答案|
|B：自主复用经验|16,384–65,535|开放共同的条件历史检索；查询由当前处境产生。反馈组可用相似经历修正读出，不必等Q平局，也不要求每次失败一定改写|
|C：有预算的多步判断|65,536–262,143|反馈组可依据自身预测分歧选择1/4/8步预测，决定是否继续展开；每8个真实步的窗口最多一次深规划，窗口中何时使用由观测决定|

这是**受限自主决策**，不是元学习已解决：动作、路线和事实预测来自模型；检索范围、预算及不确定度驱动的展开规则仍由本版设计。V0.9不假称智能体已学会自行设计反思算法、任意改变奖励、修改评估器或无限申请算力。

对助手的放权则是：正常实现、批处理和吞吐优化由助手自行处理，不再为普通工程选择逐次求确认；不得按结果改目标、筛seed或默默扩大资源。

## 5. 让反馈真正进入选择，而不只是越记越多

### 5.1 条件化记录，保留反例

每条记录至少包含局部地形、怪物相对位置/最近可见运动、技能冷却、当前速度、动作和真实后果。保留新旧矛盾记录、数量和时间，不把一次死亡写成全局动作禁令。成功也更新普通事实；不新增成功后诊断调用。

共同真实回放容量65,536转移；同一容量的原始记录可供所有组检索。每次查询在固定可重现的128条候选中按可见条件距离返回最多8条，不由助手逐例筛选。该检索是数据驱动的固定接口，**不是已经学会价值选择的检索网络**。旧经验不因本次不利就删除；容量淘汰用共同FIFO规则，完整外部记录仍保留。

### 5.2 轻量事实预测与可靠性

三个反馈组使用相同规格的三个小型预测头，学习自身转移的位移、怪物可见运动、拾取和捕获分布；未观察到的怪物真坐标不充当训练标签。另预测真实后续存活/拾取的事实向量，供F0估计搜索末端后果。它是轻量任务模型，不先研发通用世界模型。

一步预测先产生并记录，再看到真实后果，再学习，避免用已经看过答案的拟合误差冒称预测能力。记录Brier/对数损失及实际支持数量；三个头的分歧只是经验性不确定度，不包装成校准正确的置信证明。

### 5.3 多步读出和展开规则

- A/B阶段H=1。C阶段在预算可用时，如果三个头的最佳动作不一致，或最佳两动作的差小于近期预报误差中位数，则展开H=4；仍有分歧可到H=8。误差样本不足64条时按不确定处理。这里的误差与动作分数使用同一读出单位，来自实际执行路径的事前累计后果预测与已观察累计后果之差；不能拿Brier概率误差直接与Q差比较，也不伪造未执行动作或未完成尾部的标签。这是展开启发式，不是已证明有效的价值信息准则。
- 每次规划最多16条候选动作序列，第一步覆盖全部合法动作；后继动作由自身策略/预测产生，不硬编码逃跑或宝箱路线。用相同候选随机坐标做比较；深度递增复用前缀，最多128条逻辑模型转移，每条三个头，工作量分别计数。
- F0比较预测事实对应的任务目标；混合组用预测的本组训练信号加末端Q估计，保留Double-Q实际学习，不让当前Q排序先否决事实。这里只减少对一步和不准后继的依赖，不保证消除后继误差。
- 进入未见地形的模拟分支保留unknown并停止该局部展开，用自己的末端预测估计；不查询真地图，也不把unknown直接当墙或死亡。真实动作仍可进入未知区域。
- 所有组训练探索epsilon从1在前65,536个真实步线性降至0.1，之后保持；评估为0。预测不确定触发更多调查而不是强制原地保守。每次真实尝试都在共同训练预算内，没有免费重置、隐藏分支试跑或外部完美反事实。

放权阶段与继续训练同时发生，因此**阶段前后变好不能单独证明放权的因果收益**。主结论来自同环境同预算的四组对照；另做少量冻结消融，检查当前经验/多步读出是否真的影响行为。

## 6. 学习器与实现取舍

不把V0.8的小Q表直接当大空间强基线。三个奖励组采用同一个小型循环Double-DQN：局部卷积编码16/32通道、128维投影、64维GRU、16动作头；相同观察编码和64维循环工作记忆也供F0事实预测使用。

共同Q训练默认：Adam学习率3e-4，gamma=.99，真实回放容量65,536，预热2,048真实步；之后每128真实步更新一次，batch16条序列，每条8步burn-in＋16步训练段；目标网络每2,048真实步同步。正常上限是本任务终点，不对不存在的第257步bootstrap；人为预算截断不伪装被捕。事实头在相同更新时点使用同一规模的自有真实序列，无免费的额外环境样本。网络、优化器和依赖版本在首次执行前随源码记录；普通实现问题不需要再开一轮范围审批。

选择循环Q而非直接让规划器覆盖PPO动作，是为了让实际行为改变与真实经验的off-policy更新关系明确。不是声称循环Q优于所有PPO或已构成最佳RL基线。

既有方法参考：[DRQN](https://arxiv.org/abs/1507.06527)、[Double DQN](https://arxiv.org/abs/1509.06461)、[不确定度模型与规划PETS](https://arxiv.org/abs/1805.12114)。这里只借鉴记忆、价值估计和预测规划思路，不复制它们的性能结论，也不称本方案是全新算法范式。

## 7. 增加训练，但以真实交互步数公平分配

|项目|V0.8|V0.9安排|
|---|---:|---:|
|独立训练seed块|32|**64：9001–9064**|
|每模型训练量|256回合|**262,144真实环境步**|
|每模型完整训练回合|256|单局≤256步，故**至少1,024回合**；实际可能更多|
|每最终检查点评估总量|每原条件512回合|**每模型1,024回合**，已见/未见各512|
|核心组数|九组含多个旧读出|**四组**，不永久累积历史变体|

V0.9共256个独立模型（4组×64seed），总训练步数 **67,108,864**，至少 **262,144个完整训练回合**。这不是将短回合数量冒充环境交互量，也不声称每个地图细分格的评估数都翻倍。

检查点固定为0 / 16,384 / 65,536 / 131,072 / 262,144真实训练步。前四点每模型128次评估，最后点1,024次：已见/未见各占一半，再各按solo/duo和地图均衡。每个最终地图/局势单元的次数低于总bank，须分列，不把总数当每格样本数。

训练、评估、模型初始化/回放、探索与模拟候选用独立本地随机命名空间；环境随机坐标不含组名。评估源独立于训练，跨组及检查点配对。不会把不同回合共享随机带称为独立训练重复。

**评估冻结的是参数、长期事实与持久历史。** 每次评估从冻结副本开始，允许当回合GRU状态和观察到的局部地图工作记忆更新，否则局部观察任务无法正常执行；评估结束丢弃这些临时状态，不跨评估回合积累，不回流训练。未见图没有预装地图记忆。

## 8. 结果指标与结束标准

### 主结果

使用任务分数 `S/1384`（1384=1.5×256+100×10，是量纲上限而非已知可达最优），对共同训练步检查点作归一化梯形AUC。主要看**训练地图duo条件**，三个预定配对：

1. F-RP − RL-RP：相同奖惩下，完整反馈利用方案有没有增量？
2. F0 − RL-RP：不用外部标量奖惩的方案表现如何？
3. F-RP − F-R：共同反馈机制下，额外处罚带来什么变化？

同时给出0–65,536步早期AUC、最终分数、存活步数、宝箱数、被捕率和未见图结果。未见图是次要泛化检查，不以必须迁移成功作为本阶段完成条件。

共同操作目标为平均存活≥192步且平均宝箱≥3；报告首次被观察到达标的检查点、未达标和后续退步。区间跨阈时标记不确定，不把一次评估好运当确定学会。连续指标是主依据，不以达标标签决定加训/换方法。

统计单位是64个独立训练seed块；地图/局势在块内汇总，再报告成对均值、IQM、中位数、正/零/负seed数与10,000次配对bootstrap区间。区间用于局部描述，不制造“全family PASS”，未显著不等于等效。不同阶段、不同地图的原始分数不直接相减。

### 反馈是否真的生效

保留预测、查询、读出前建议、实际动作和随后真实后果。统计记忆被调用却未改变动作、有效改变、随后不利结果及旧经验失效；一次不利结果不是反事实错误的充分证明。

最终对三个反馈组各做两个**冻结执行消融**，每模型每变体128回合，使用最终主评估的匹配子集：

- 固定H=1，关闭深规划，保留已学参数与经验；
- 关闭跨回合历史检索，保留已学参数和当回合观察工作记忆。

这些是额外真实评估，不只是影子建议；只回答已训练模型在测试时对模块的依赖，不等同从头训练消融，也不把关闭检索称为清除了权重中的全部经验。
