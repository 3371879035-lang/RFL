## 实际运行边界

- V198 原来的十二小时预算、源码、检查点、终点评估与结论全部保留，不修改正在执行的源文件。
- 一个后台程序等待原运行及自动分析成功结束，再续训全部五组、四个种子，不挑最好的组或检查点。
- 新六小时计时从追加运行启动开始，等待旧运行不扣训练预算。新增阶段包含开发验证、末尾评估和报告，最长 21,600 秒。
- 原程序失败时本次不启动、不代为重试。没有新增应用自动任务，没有云资源。
- 8 个 CPU 工作进程；进程树内存上限 24 GiB；新增产物上限 32 GiB。进程级防休眠，不强制亮屏。

## 学习机制不变

直接调用原 V198 `run_task`、`Agent`、真实分支试验、候选试训和 SLEEP 函数，不复制改写学习规则。
每组每轮仍为 131,072 个计费环境步、1,024 次优化更新。普通 RL 仍然没有额外机制；其他四组保留实际历史、实际试验和验证后采用。

- 直接复用已经实际执行的十二小时终点评估，不重跑。
