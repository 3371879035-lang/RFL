# V202：通用转移记忆、延迟结果与实际试验采纳

## 本轮目标与边界（实验前写定）

不是继续游戏适配，也不是梯度训练。保留 V200 原权重与结果，另外编译一个固定权重张量程序。所有任务共用同一检查点；不同任务仅提供状态数值描述、合法动作描述、公开目标和真实转移/结果。模型不读取任务标签、隐藏规律、正确动作表或模拟器。

本轮只解决有界、完整可观测的离散回合中“后面的事实如何经真实后继关系影响前面的候选选择”，以及候选策略必须经过新的实际试验才可替换已采用策略。它不是自然语言归因器、普适世界模型或普遍因果证明。尚不解决任意原始图像表示、隐藏混杂、多步无限规划或 SLEEP 参数巩固。

## 1. 记录真实转移，不把终局结果硬贴到所有先前动作

每条记录为 `(s_i, a_i, s'_i, terminal_i, y_i, known_i)`。
非终局的最终结果尚未知，known 为 false；不会当成失败 0，也不会把同局末尾的结果直接复制到所有先前动作。

令 `x=[s,a]`。用已经观察到的各坐标范围做尺度归一化 `z=(x-min)/(max-min)`，常量坐标的分母为 1。
由显式写入的 Q/K 权重实现：

`w(q,i) = exp(-20 ||z_q-z_i||² - 0.002 age_i)`。

它修正的是可观测数值单位差异，不自动发现语义相关特征；常量/未观测维度、无关维度和非欧氏语义仍有限制。

## 2. 分开保存平均后果、后果波动和证据不足

记录传递一阶矩 `m_i=E[Y]`、二阶矩 `M_i=E[YY^T]`，以及最终结果已有观察支持的程度 `g_i`。value 权重直接传递这些量，而不是把“检索到记录”等同于“知道原因”。

`b_i = w(q,i) g_i; N = sum b_i`

`m = (m0 + sum b_i m_i)/(1+N)`

`M = (M0 + sum b_i M_i)/(1+N)`

无数据先验为各事实独立 Uniform[0,1]：`m0=0.5`, `M0=m0*m0^T+I/12`。它是明确公开的初始化假设，不是假造经验。

对公开目标 g：`value=g^T m`, `outcome_variance=max(0,g^T M g-value²)`。
探索代理为 `u=sqrt(outcome_variance/(1+N)+0.25/(1+N)²)`；探索读出 `value+0.5u+0.1/(1+N)`。

后果波动不会因为样本多就消失；证据不足代理可以下降。N 是加权局部证据量，传播后可能相关，**不是独立样本数**，u 不是经校准的置信区间。

## 3. 沿观察到的后继关系传播候选后果

终局记录固定为实际观测的矩；缺少目标所需字段的终局不会给该目标提供完整支持。非终局初始无支持。

每次传播，对记录的实际后继 `s'_i` 查询各动作的候选后果，按公开目标选择最大期望；并列动作平均，避免标签 0 优先。非终局接收此后继候选的矩和支持程度。最多传播 6 次（本轮计算预算）。

这相当于基于经验转移的有限深度规划。它允许条件性地说明“这个选择通向了什么”，**不声称观察相关性已识别真实因果**。未观察转移、覆盖不足和噪声都会导致候选失误，因此规划值不能直接批准策略替换。

## 4. 候选与正式采用分离

每周期先执行 4 个实际探索回合；从当时记忆冻结一个候选。随后候选和已采用策略各执行 8 个真实回合，使用相同初始条件及外生随机数配对。两者在这一批试验中均不吸收新经验；完整结果出来后才把真实试验记录加入工作记忆供下一周期使用。

令实际结果差 `d_j=g^T(y_candidate-y_incumbent)`。

`margin = mean(d) - 2 * sample_std(d)/sqrt(n)`。

权重写入的门只在 `n>=8` 且 `margin>0` 时采用候选策略快照，否则保留旧快照。这里采用改变的是可调用的策略/记忆状态，**不是神经参数**。

这是事前固定的有限工程采纳规则，不冒称严格 95% 区间、跨多次选择的错误率保证或所有场景的最优规则。每周期另外 4 个实际评估回合不进入记忆/采纳判断。所有探索、试验、评估回合均计入成本。

## 5. 对照与防止自证

- V202 完整：后继传播 + 实际试验采纳。
- V202 去采纳门：相同试验/交互预算，但不看试验优劣，每周期直接采用候选。不是免试验成本对照。
- V202 去后继传播：同一权重/记忆接口，切断非终局的结果传播，采纳门仍保留。
- V200 原版：原权重、原观测接口，不改原代码；在**新任务**里获得它能接收的真实条件/动作/已知事实，不能伪造非终局结果。它有相同实际回合预算，按其原有经验检索方式更新行为，不冒充训练后的强基线。

这四项是机制对照，不是此前“纯 RL / 纯反馈 / 有奖惩 / 只有奖励”的训练矩阵。

三类新任务：延迟选择（2/5 步）、三步联合选择、随机结果且关系反转。每类 8 个独立工程种子，16 周期；每周期 4 探索 + 16 配对试验 + 4 评估 = 24 回合。共 36,864 回合，上限 184,320 环境转移。另有不调用环境的构造检查。无需全部胜出，保留所有零/负结果，不在看到分数后改超参/任务/权重。
