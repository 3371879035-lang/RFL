## 1. 实际修改，而不是单纯加参数

上一版V220有2870271个可训练参数，但：全量记忆有N²注意力；采用头直接证据只取某个候选的最新一次回执；没有同等的“再试当前做法”选择；控制码缺少跨参数版本失效机制。

本轮先写数学推导，再实现V221。首版10220095参数的运行通过14项检查，之后数学复查发现反对称比较仍不保证三个方案的预期差值一致。没有隐藏这一点，也没有改写首跑输出；追加独立定向修订。**当前推荐网络10093631个可训练参数，179个参数张量全部得到有限非零梯度。**参数略少于首版，是消除不一致参数化，不是省掉能力。

## 2. 记忆节点

原始事实不删减、不以摘要冒充新增事实。用可训练工作节点进行双向交叉注意力，单层的主要注意力配对项从N²改为2NS+S²，默认S=64，可配置。动作查询仍可读取所有事实位置。工作节点是计算表示，不是64条新证据；当前参数每次重新编码原始记录。

首版V221实际检查128/512/2048/4096个合成节点。4096节点未被裁剪，实际注意力形状为64×4097、64×64、4097×64，连续两层；没有4097×4097记忆自注意力。4096的单次前向0.7672秒，512为0.0794秒、2048为0.2927秒；128的首次调用1.1122秒包含初次调用开销，不能拿这四次做严格吞吐拟合。未重跑V220比较时间。

这是计算结构及保留事实的检查，不是已训练的4096条知识记忆/检索准确率，也没有证明工作节点瓶颈不损失语义。定向比较修订不改变该记忆实现，未重复长记忆测量。

## 3. 让实践成为真正的数据，而不是最后一次结果

一次失败建立会话：当前做法作为arm0，网络生成候选作为其余arms。模型每次可停止、试当前做法、试候选、再次试同一候选；全部真实结果按事件身份追加，不覆盖早先成功或失败。预算限制只是本次试验资源边界。

触发失败保留在原始历史中，但不自动充当当前做法的新实践基线。否则“在失败后开始”会使基线只剩失败样本。候选/当前做法共享证据编码和评分规则；是否值得再试、是否采用仍由参数化网络决定，不强制固定成功率阈值。

首次主实验：3个初始化种子×2种小向量环境×12个三步任务，共72个任务、216次主任务环境步骤；另外118次真实局部实践。其中当前做法25次、候选93次。46个失败会话、20次采用。

- 37次是对会话中已经试过的同一臂再次执行，不是复制旧反馈。
- 29个“会话-做法”组合得到多次试验，其中13个同时出现成功和失败；全部保留。
- 15个会话同时有新基线和候选实测，构造了目标事件严格晚于支持前缀的比较训练样本。
- 20次采用中8次有新基线实测，12次没有。**这不是采用有效的证明，反而明确显示未训练的试验分配/采用模块尚不会可靠判断证据是否充分。**没有因此添加强制必试基线的任务规则来伪造能力。

实际实践只重执行失败终止处的局部动作，不是免费反事实，也不是整条三步路线重新训练。所有环境调用计成本。

## 4. 比较公式的真实发现与修复

首版满足mu_ab=-mu_ba，却未保证mu_ab+mu_bc=mu_ac。已存46个采用矩阵中最大残差为4.2532337829470634e-06。数值虽小，结构含义不能忽略；原14项检查确实漏了这一性质。

修订后：

    mu_ab = phi_a - phi_b
    Sigma = L L^T + diag(v), v>0
    Var(Y_a-Y_b) = Sigma_aa + Sigma_bb - 2*Sigma_ab。

因此比较均值来自同一组方案价值势，协方差正半定；自差为0。没有用更多固定“风险惩罚”代替建模。价值势公共偏移、协方差公共因子并非全部可识别；这些是模型内部结构，不是已经找到真正原因。

定向修订仅做3项新检查与两个新初始化种子的有限真实流程：8个三步任务、24个主步骤、17次实际实践，其中基线5次、候选12次；6个失败会话、3次采用。首次主进程0、首次存储核对0。6个实际采用矩阵最大循环残差实测0.0。原主实验、长记忆检查不重跑；没有“修好后覆盖第一次”的做法。

## 6. 能说什么，不能说什么

可以说：更长的原始记忆可进入网络、同一候选多次有成有败的证据不会在采用接口丢失、比较目标具备一致的数学结构、训练目标不泄漏到历史输入、模块有梯度、模型版本改变不会默许旧控制码继续生效。跨版本检查只替换了一次独立初始化的fixture模型，没有进行优化器学习；旧事实与回执保持原样。

不能说：随机网络已会归因/校准/高效试验、采用等于改善、较多参数保证学好、4096节点意味着4096条知识已学会。首版动作归一化熵0.9999999282，仍近乎均匀。训练和独立效果评估不可由结构检查替代。

仍需后续工作：真正的训练调度与跨阶段候选credit assignment、独立评估数据、适合离散目标的观测似然/校准、多步内部推演与实训后的SLEEP巩固。目前保留的是一步想象和事实回放/蒸馏接口，不冒称完整DreamRSI/SLEEP。已有候选码日志不可直接当作对当前Proposal参数可微的历史目标；训练器需要使用保存的生成前缀和行为概率构建正确学习目标。

历史事实是信息，实践提供新证据，是否采用是可训练判断——这三者现在分得更清楚，但实际能力还要通过训练取得。
