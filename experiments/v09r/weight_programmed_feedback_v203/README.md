# V203：实际试验的局部采用与条件相关的经验更新

本轮已经实现并完成主实验，以及不改权重的独立噪声压力检查。不是继续游戏适配，也没有梯度训练或恢复自动任务。

## 新增机制

### 1. 不再因为只有一部分条件改善，就否决整个候选

V202 把所有条件合并，要求 `实际均值差 - 2SE > 0` 才整体替换。V203 根据真实试验中相同的公开初始条件分别计算差值：有至少两对实际试验且局部收缩差值为正，只在该条件下调用候选；其他条件保留原策略。

路由只在回合开始选择一个完整、已冻结的策略，不在回合中拼接未经试验的新行为。规则不是显著性证明，少量观测仍可能误选。外部另做采用前/后的配对评估，结果不进入学习。

### 2. 旧经验按相关的新证据老化

仍用相同 Q/K 数值相似度，但不再让所有无关交互等量增加某条经验的年龄。新衰减以查询附近的后续记录量为单位；8 条近似匹配新记录使旧记录贡献约减半。

它只是条件相关的遗忘规则，不是已经识别“为什么世界改变”的因果检测器。数值相似不等于语义相关；容量限制和未知条件问题仍在。

### 权重与结构边界

新模型 **600 个参数，55 个非零**。V202 的公共参数逐项完全保持原值；新增衰减与局部读出参数直接编写。全程神经参数冻结，变化发生在实际经验记忆、候选快照和调用策略状态。

排序、记忆管理、真实试验和作用域路由属于公开的固定程序结构；匹配、矩值通道、目标读出、衰减和判别由参数化张量模块实现。不能把结果描述为“600 个参数已经包含完整通用智能”，也不能把结构与权重的共同改动只归因给权重数值。

## 主实验：同一批新实例上的末段成功率

16 条独立工程种子序列；每格为末 4 周期、共 512 个留出评估回合。五个版本的实际探索、试验、采用前/后评估预算相同。此处的 V202 是在本轮新实例上执行的原模型，不是把上轮旧分数拼进表格。

|任务|V202 原版|V203 完整|V203 保留全局门|V203 保留全局年龄|V203 无采纳门|
|---|---:|---:|---:|---:|---:|
|2/5 步延迟选择|97.27%|100.00%|97.27%|100.00%|100.00%|
|三步联合选择|96.29%|100.00%|96.29%|100.00%|100.00%|
|稳定随机结果|79.30%|80.08%|79.88%|80.08%|79.10%|
|随机规律反转|69.53%|79.10%|71.88%|74.02%|80.27%|

随机任务的较好动作真实成功概率为 .8；样本均值略高于 80% 是有限样本波动，不是超越其期望上限。

### 可以支持的结论

- 局部采用在前两类任务中保留了进步，不再留下旧全局门造成的一些未采用情况。
- 随机反转任务中，完整版本相对原版末窗高约 **9.57 个百分点**。保留旧全局年龄但使用局部门为 74.02%；使用新年龄但保留旧全局门为 71.88%。本轮消融支持两个改动各自有作用，但不是一般环境的收益证明。
- 仍存在速度/稳定性取舍。无门版本在不少全程指标上更高，反转末窗也略高于完整版；不能宣称加入采纳机制就普遍获胜。

## 发现并补查的评估盲点

主实验的候选/现行策略配对试验共用结果随机数。在这类由 .8/.2 阈值生成结果的任务中，共用随机数会让某些优劣对比异常干净。因此，主实验没有观测到完整版采用后退步，不能直接推成实际反馈带独立噪声时也可靠。

随后冻结同一个 V203 检查点，另用 16 个新种子，比较“配对噪声 / 独立试验噪声”。没有修改权重、门、衰减或预算来追结果。该检查在相邻目录 `weight_programmed_feedback_v203_noise_check`，其两个协议内部使用相同新实例与评估流。

### 独立试验噪声的末段成功率（不同实例，不与上表交叉拼接）

|任务|V203 完整|V203 保留全局门|V203 无采纳门|
|---|---:|---:|---:|
|稳定随机结果|79.49%|78.32%|79.30%|
|随机规律反转|75.39%|69.14%|76.95%|

完整版没有因去除试验噪声耦合而失效，但仍未在全部分数上超过无门版本。反转任务中，采用前/后留出评估共有 2048 对：完整版观察到 **117 对改善、1 对退步**，无门版为 **129 对改善、14 对退步**。这些是评估回合对的计数，不是独立采纳事件的真实错误率或零风险保证。

采用前/后外部评估依然使用共用随机数减少比较噪声，但永不进入门或记忆；实际试验在 independent 协议下确实使用相互独立的结果噪声。

## 最具体的未完成点

**遇到突然变化，仍然不能立即反应。** 主实验反转后最初两周期完整版仅 22.66%；独立噪声检查约 21.88%，随后才逐步恢复。新衰减改善了后面的恢复，但它不是变化检测/主动复测机制，不能把最终追上当作已经及时应对。

其他限制：

- 仍是完整可观测、短回合、可重复初始条件的数值任务，不是任意图像/语言输入、连续无重复场景或复杂长程任务的通用模型。
- 小样本局部点估计可能误选，采纳规则不是统计置信保证；当前也没有高风险任务的安全适用证明。
- 历史衰减可能忘掉仍有价值的信息；测试稳定随机任务不能覆盖所有保留/复用问题。
- 没有梯度训练基线、SLEEP 参数巩固、自动语义特征学习或隐藏混杂下的因果识别。
- 这些是五个机制对照，不是历史上四种奖惩条件的训练矩阵。

下一关键件应围绕实际预测误差与针对性复测，检验何时旧经验真的需要重新验证；不需要先加游戏规则、恢复长时训练或继续堆同类确定性演示。
