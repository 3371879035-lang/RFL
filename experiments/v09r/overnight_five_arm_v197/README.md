# V197：真正普通 RL 对照与最多六小时的五组续训

本轮按用户明确要求执行，不沿用 V196 把增强 RL 简称“纯 RL”的口径。

五组：普通 RL、RL＋候选试训/择优/SLEEP、无环境奖惩的事实＋目标偏好、反馈＋奖惩、反馈＋仅奖励。普通 RL 从与增强 RL 完全相同的每个种子检查点出发，但从始至终不接定向分支调查、教师择优或蒸馏；它正常采集、TD 学习和回放，不冻结。

每个共同训练块，五组各花 131072 个实际环境步骤、1024 次优化器更新。增强组的试验、开发测试、被拒候选和学生工作全部占预算，剩余用于普通练习和回放；普通 RL 全部用于普通训练。报告评估另列，不能算成免费的训练。更新次数匹配不是 FLOPs 完全相同，将记录 CPU 和墙钟时间。

保留 4 个已有训练种子，20 条独立延续轨迹；不是新增 20 个从零训练种子。每块结束保存真实检查点，以全部组都完成的共同块作为终点。最多运行 6 小时，预留最终评估时间，不按分数好坏提前停止或延长。

修复的主要设计边界：

- 增加真正普通 RL，不再用增强 RL 代替。
- 普通新经验真正进入各自回放/检索，不只对旧静态回放做几次更新。
- 改法执行三个真实未来分支配对；反馈标签需要多数方向一致，不把单条后继当确定原因。
- 教师普通参考与教师候选更新数一致；学生/参考使用相同真实数据、次数与小批次 RNG。
- 开发探针由 16 增到 64 回合，采用要求两个新 32 回合块同向；仍不是科学显著性保证，也不额外惩罚失败。
- 开发与报告都分层覆盖普通地图/各自保留地图；本轮报告地图不参与训练选择。地图本身属于既有地图库，不能称全新世界。
- 最终每组每种子 512 个新报告回合。只报告四种子配对结果和局势覆盖，不把回合数冒充独立模型数。

这是“更长训练＋修复对照/验证”的新实验，不是只改变训练时间的单因素实验。F0 仍无奖励包和 Q 头，但有公开任务目标偏好；没有新增原因概率器、游戏网络自然语言计划或原论文代码自改写。
