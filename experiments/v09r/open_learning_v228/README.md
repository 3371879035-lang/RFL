本修订依据用户 2026-11-12 的直接要求制作。V227 的三小时双域训练继续，旧执行源码、标准、捕获与结果未改。V228 尚未启动新的长时间六组对照。

## 已实际修改

1. 事实损失与实际配对效果损失共同训练共享编码器、记忆读取和适用性网络；不再提前 detach 切断。Q 的目标网络和蒸馏教师作为目标时仍不反向更新，这是目标计算，不是禁止学习。
2. 配对试验按有符号平均效果学习：正效果支持被试方案，负效果学习相反条件偏好，零效果不凭空创造方向；删除“两次都必须改善”的入口否决。
3. 删除独立的教师整局验收层。候选试训、临时教师、SLEEP 后，只比较一次最终学生与等量普通学习对照；按配对平均结果选择，不再要求每个小样本都不变差。
4. 记忆改为按事件身份追加保存、按历史前沿读取；去掉固定最近 16 个节点的截断。回放引用历史视图而非反复复制历史，后来的观察不进入较早状态。
5. 所有已完成失败轨迹的状态都保留为调查候选，不再限于最新失败最后 8 步；每次从全部候选中抽样，再用模型预测分歧排序。候选批量是本次读取成本，不是删除旧经验。
