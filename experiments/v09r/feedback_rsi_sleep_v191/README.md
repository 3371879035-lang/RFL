# V191：反馈驱动的复习策略改进与参数级 Sleep

本轮按用户当前直接要求实施，不恢复旧 64 种子训练或自动任务。四主组为纯 RL、纯事实反馈 F0、反馈加奖惩、反馈加仅奖励。每组保留四个已有训练种子，均从对应真实 V190 base 检查点开始；旧手工移动纠偏规则不用于本轮选动作，旧结果和检查点不动。

每个主组有两个新分支：

- `matched_replay`：普通学习正常进行，采样暂停期再做 24 次均匀历史回放更新。
- `adaptive_sleep`：普通学习正常进行，每轮自动提出 4 个复习分配策略，各在临时网络上做 4 次实际更新；使用与拟合窗口不重叠的真实训练历史检查预测/TD误差。把已执行候选及正负反馈保存在历史中，学习下一轮复习策略；选中的临时教师通过 8 次真实标签加软目标蒸馏更新持久网络。

两边每轮均为 24 次额外梯度更新，外部交互相同；候选筛选额外前向计算如实计时，不能称完全等计算。三轮各 4096 步，更新后的参数和复习策略继承到下一轮实际任务。固定步预算可能暂停未结束对局，不能伪造终止或补未实现的未来标签；Sleep 后重新编码实际观察前缀、恢复原局面。

这是 Dream-RSI 的“真实探索历史—改进探索/计算分配策略—再次实际部署”思想在学习过程上的参数化改编，并非原论文探索代码生成的复现。可学习策略目前只分配历史练习，尚不自主提出任意因果解释或自改网络架构。Sleep 是小网络的临时教师到持久参数的实际巩固，不是把外部字典改名，也不声称实现原 MoE 架构。

纯 RL 只用原奖励/Q目标，纯反馈组没有奖励包、Q头或Q更新，按真实事实误差选择复习并蒸馏事实头；混合两组保持原目标。人工规定接口、模型容量、优化器和有限预算，不再手写具体地图应对规则。最终评估不参与策略选择。

新完整预算和输入见 `contract.json`、`checkpoint_binding.json`。新评估 episode 1024 起；同一组两个分支初始参数和动作代码完全相同，只执行一次初始银行并明确共享。末点每种子 256 回合，训练种子仍是 4，不把回合数当独立训练 N。已有 V190 的成绩不能与本轮不同评估银行混比。
