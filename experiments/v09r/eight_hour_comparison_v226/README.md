# V226：八小时通用反馈网络训练与五类对照

用户将训练预算改为 8 小时，并要求与之前的强化学习/反馈学习对照组比较。本轮遵循此前“不做游戏适配”的方向，保留旧五组的学习条件，**不是重跑旧游戏程序，也不是把两个任务的分数拼在一起**。

## 六组

|组|训练方式|
|---|---|
|RL-plain|普通 Q 学习、实际经验回放，无候选试验/蒸馏|
|RL-outer|同一起点的 Q 学习，加历史提案、实际分支试验、教师/学生实测和条件化蒸馏|
|F0|无显式奖励包、无 Q；监督学习实际后继与实际回合终点，依据公开目标选择动作，并做实测候选学习|
|F-RP|事实学习＋Q，有奖励和失败/退步处罚，接局外闭环|
|F-R|事实学习＋Q，只有正向奖励，接局外闭环|
|N226|真正训练现有 V225 约 2047 万参数网络：条件记忆、逐事件后验、脑内候选、实际试验、目标回报策略梯度、条件化行为巩固|

**N226 不是严格纯反馈组**：它和 F-R 使用同一正向目标回报定义；F0 才没有奖励包和 Q。五个参考实现是可移植的新实现，不是旧 V198/V199 的卷积追逐网络。参考网络更小，参数量、实际算时和更新数均报告；本轮是完整方案比较，不能单独归功于参数量或某一个模块。

## 数学与实际边界

- 任务：公开 16 维观测、8 维目标/动作，稳定、随机、延迟、条件改变四族。网络只能读公开字段和真实历史；动作效果、噪声种子和变化规则只在环境执行器内。
- 正向信号 `r+=max(0,d_before-d_after)+success`；奖惩组再扣 `max(0,d_after-d_before)+terminal_failure`。报告成功率、最终目标距离，不横比不同配方的训练损失。
- N226 世界目标为实际序列负对数似然。当前回合证据只进入后验一次，历史重放是再次优化已观察的样本，**不新增一份事实、不重复计算为独立证据**。
- 给定训练块开始前的实际历史 H，策略目标是 `E[sum r+ | H]`，更新为实际决策及脑内随机决策联合对数概率乘之后的实际回报减基线。只对这一块做条件梯度；不声称对整个跨训练块历史分布求了无偏梯度。
- 全部策略/世界梯度先在固定行为快照上算完，然后才更新权重。新权重开始新会话，旧候选代码和旧后验状态不会冒充当前状态。
- 动作候选须实际试过才能采用；参考组的临时教师和学生另经实际配对任务测试。N226 的策略梯度也只使用实际主任务结果，想象结果不作为物理训练标签。
- N226 的巩固资格是：候选在实际同条件试验中优于实际 baseline，且其后真的成功执行过任务。蒸馏只用实际执行时的行为概率。这是有限工程资格，**不是统计确认，也未额外验证巩固后必然改善**。无资格时明确记零，不强迫触发 SLEEP。
- 三个独立训练种子。每个共同预算块每组都执行 64 个实际环境步，包括失败诊断、教师/学生测试。普通 RL 将预算用于正常练习，不冻结对照。最多三个优化器更新/块，不是严格等 FLOPs/等更新数消融。
- 历史原始事实全部写入压缩档案；N226 工作记忆仅保留最近不超过 96 个节点且不截断回合。参考组另有 8192 样本回放。不同记忆实现属于方案差异，不声称记忆容量单因素公平。

策略梯度依据：[Sutton 等，1999](https://proceedings.neurips.cc/paper/1999/hash/464d828b85b0bed98e80ade0a5c43b0f-Abstract.html)。这里的条件训练块及实际轨迹重建是本项目实现，不把论文当作本实现正确性的证据。

## 预算、结果和停止

- 单独一次有限训练接线检查：新种子 179，两块/六组，768 训练步，432 报告步，上限 30 分钟；保留第一次失败，无自动重试。
- 通过后才启动 8 小时本地运行。总墙钟预算 28800 秒，包含初始化、训练、评估及最终报告，预留 15 分钟。三条独立 seed 进程，每进程一线程，六组在每个 seed 内按轮换顺序执行。
- 不是“每一组独占 CPU 8 小时”。这是 **8 小时总墙钟、共同实际交互预算** 的比较；大网络成本会限制总共同进度，必须如实报告。
- 每块保留全部真实执行记录、参数前后指纹、梯度/损失、记忆和试验计数。每个预先固定预算档做隔离评估。最终选所有种子都有的最大共同预算档，不按效果选检查点。
- 初始/中间评估各 16 回合，最终共同档各 64 回合；比较起点改善时只对齐两者共同前 16 个回合，最终绝对水平报告全部 64 回合。评估历史只在评估副本里累积，不回流训练；评估不改权重、不做候选参数学习。
- 云端、付费服务、旧自动安排均不启动。程序只申请本进程存续期系统不自动睡眠，屏幕可熄灭；关机、断电和强制睡眠仍会中断。
- 源码/契约/输入钉在执行前，失败/partial 永久保留。无训练重试、无效果筛场景、无事后改指标。

主要入口：`eight_hour/progress.json`、各 seed 的 `live.json` 和 `progress.json`、`eight_hour/REPORT.md`、`eight_hour/result_summary.json`、`eight_hour/exit.json`。报告文件只在真正结束后生成，不提前宣称完成或有效。
