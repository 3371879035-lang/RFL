# V224：真实结果接回可学习网络

## 1. 实际修复了什么

1. **候选生成的梯度断点。** 旧运行时把候选控制码存成常数。V224 保留真实运行所有权，同时记录创建前缀和候选来源；训练损失重新计算当时前缀下的候选，不从完整事后历史产生答案。真实后续任务结果和成本因此能进入候选生成器的梯度计算。
2. **决策侧历史读取缺口。** 在不让策略回报改写世界预测的前提下，新增可训练的条件记忆 query/reader/适用性门及上下文融合器。它学习“当前怎样利用历史”，不是直接用旧误差覆盖新答案。
3. **思考联合概率错误。** 原思考器共用各候选的政策抽样随机数却相乘边缘概率。新实现让政策抽样按候选独立，物理噪声仍可共同使用；内部动作、继续/停止和外部试验选择一起进入真实路径概率。
4. **跨版本复用边界。** 相同世界、不同策略使用整个闭合路径的概率比，不是单个动作比率。世界改变时拒绝把旧想象直接当新世界轨迹；旧真实事件仍可以训练新世界的观测似然。重放数据不重建 live session/receipt 资格。
5. **行为概率只作日志。** propensity 留在真实回执和重要性权重中，不再作为神经记忆特征。否则历史输入混有旧策略自身的概率，破坏上述同世界重放解释。

## 4. 关键验证结果

两种子各 7 项，共 **14 项定向检查通过**：

- 同快照重放：候选代码、外部决策概率、critic 值最大差均 **0**。全路径日志密度差约 -2.05e-6 / -7.06e-6，来自求和数值精度。
- **真实成本、零基线**的梯度到达 89 个策略参数张量，包括候选生成、记忆读取、实际行动、思考、试验选择和采用；不是靠编造 advantage 检查连接性。
- 反向对照：只切断候选生成的梯度，前向各步概率**完全不变**，候选生成器梯度变成 **0**；其余 actor 仍有梯度。这定位的是旧版具体的训练断点，不是新模型学习效果排名。
- 世界真实序列似然到达 155 个世界参数张量；critic 真实目标到达 5 个 critic 张量。各路线均有限，跨路线非零梯度 **0**；三条路线合计覆盖全部 249 个参数张量，但不保证可优化性、收敛或校准。
- 同世界、另一组新初始化策略的完整路径权重约 **1.07142 / 0.84085**，强制原动作后全部物理想象节点逐值相同。这是人工快照兼容检查，不是训练进步；不证明长轨迹权重稳定。
- 新世界拒绝旧想象的此种策略重放；同一批真实历史在新世界下的似然可正常计算。
- 重复同 ID 真实事件不增加记忆；只改日志 propensity 的诊断副本不改变神经记忆；把候选创建前缀移到未来会被拒绝。

## 5. 数学目标的性质必须说清楚

世界/事实路径仍是观测似然学习，无需环境奖励。新增的目标达成/成本 score-function 策略损失，**如果以后用它优化参数，就是 RL 风格的目标优化路径**；不能把“没有环境显式分数”偷换成严格无奖励的纯反馈训练。当前不选择三项目标权重、不更新参数，也不替换以前四组/五组实验定义。它只是为通用反馈模型增加一个可审阅的实际结果训练接口。

目标、事实、因果解释和控制权仍不同。这里没有证明“模型找到了真正原因”，也未训练原因概率分配器。是否采用某种反馈方法，仍要由后续真实训练与实际对照决定。

## 6. 仍需解决、但不在本轮伪称完成的事项

1. 未训练网络不具有可靠归因、校准、泛化或持续改进能力。非零梯度不是有效学习的充分条件。
2. 完整轨迹重要性采样长程可能有高方差；同世界限定也限制跨世界版本复用。没有静默裁剪或替换为未经解释的单步比率。
3. 思考保持有限开放环近似；固定公开动作集合不能代表任意未来行动空间。新实际动作会重新读取真实观察，但尚未证明实时反应能力。
4. 决策 reader 依赖世界编码；长期记忆压缩、遗忘/保留、噪声和罕见经验的适用性仍需训练后验证。
5. 三项目标的尺度与权重还未采用；思考粒子行数不是完整 FLOPs/延迟成本。
6. **SLEEP 长期巩固未训练**。已接通真实反馈训练路径不等于已蒸馏出长期能力；直接模仿旧策略也可能固化坏经验。

下一实质问题是：这条真实结果训练路径在小规模参数训练后是否改善行为、是否保留旧能力。按当前“不更新参数”的边界，本轮到此结束，不自动扩大矩阵或启动训练。
