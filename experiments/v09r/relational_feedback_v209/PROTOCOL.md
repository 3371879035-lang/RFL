# V209：联合关系反馈网络的第一次有限实验

日期：2026-11-10。依据当前直接要求“编写相关的神经网络，然后进行实验检查问题”。

## 问题与实现范围

检查 V208 关系算子能否接成一个实际学习闭环：观察历史 → 形成联合条件模型 → 选择候选策略 → 实际试用 → 采用/保留 → 继续积累经验。

模型不是 LLM；没有游戏适配、健康 Q*、任务答案输入或参数训练。固定解析神经层计算关系特征，实际经验更新外部事实状态。候选的动作表由神经事实头计算后编译，用于快速执行；这是有限域内等价的状态编译，不是已完成 SLEEP 参数蒸馏。首轮只检验历史关系与试用闭环，不声称完整多步世界模型已接通。

## 四个对照

|名称|历史表示|候选选择|最终采用依据|
|---|---|---|---|
|unary_verified|一字段|新留出反馈的 IPS 行动评分|新实际配对试用|
|joint_verified|一/二字段联合|同上|同上|
|joint_rank_only|一/二字段联合|同上|只用先前排序分数，不用本轮配对结果决定采用|
|joint_uniform_verified|一/二字段联合|从不同候选中均匀选择|新实际配对试用|

所有组都执行、保存相同数量的实际试用；rank_only 组仅在本轮采用决策中不使用新配对结果，结果仍供下一轮学习。这避免把额外练习量误当“验证机制”的收益。

四组是当前新网络的机制消融，不是旧“纯 RL / 纯反馈 / 奖惩 / 仅奖励”四组，也不能据此宣称优于纯 RL。

## 新任务族

每个回合四个观察时刻，每刻两个公开二元字段，前三步被动等待，末步选两个合法动作之一。八个字段都可见，关键字段与结果规律对模型隐藏。

- single_remote：早期四个字段中一个决定目标动作。
- pair_joint：两个未知字段的奇偶关系决定目标动作。
- pair_switch：同上，第 4 轮开始结果映射反转；模型不知道切换发生。
- triple_joint：三个未知字段的奇偶关系；保留作为二阶表示的预定能力边界。

选择正确目标动作时结果成功概率 .9，否则 .1。每组实际执行策略带同一 epsilon=.2 的探索，故理想策略的期望成功率上限为 .82，而非 .9。初始固定动作的期望为 .5。结果字段是任务事实，不另加失败处罚或奖励 TD。

这是一组有隐藏随机规律的受控微环境，不是完整导航、长链行动规划或任意任务通用性测试。

## 预算与时序

12 个独立训练种子，4 任务族，4 对照，共 192 次独立模型运行；同一任务种子下四组使用共同随机场景与噪声，组间比较按种子配对。

每组每种子：

1. 64 次真实初始探索；
2. 6 轮，每轮 32 次经验采集 → 冻结候选库 → 16 次新的留出排序采集 → 8 对真实试用（16 回合） → 32 次后续部署 → 64 次独立留出评估。

总预算 **196,608 个实际微回合 / 786,432 个实际步**。其中 122,880 回合进入事实学习，73,728 回合仅评估不写入学习器。每次只保留最近 192 个训练回合供本轮建模；原始事实全部留在采集记录中。该窗口是本次配置，不是通用最优值。

新排序数据在候选冻结后产生。已知行为概率均有正支持；事实状态使用 scale-nine 的精确整数逆倾向权重，避免只剩粗条件时混淆行为选择和结果差异。Beta(1,1) 预测先验与实际支持分开。候选评分仅用于提案，verified 组使用新实际配对结果决定采用。

固定 8 对后，平均差为正即采用，否则保留；这是一条透明、可被本次实验检验的简单决策规则，不声称消除了误采纳。rank_only 组以新的排序批次分数差为正作为采用条件。完全相同的策略不作为改变。

不会按效果替换任务、规则、种子或追加训练。首次失败/部分输出保留，不自动重跑。原历史实验、数学核验和旧 checker 不执行。

## 记录与判读

全量保存原始观察、动作、结果、行为概率、外部噪声、候选事实计数与全部候选策略、排序分数、配对结果、采用和后续评估。学习器只接收公开字段，任务族、种子、关键字段、切换时点及随机数均留在外部记录。

标准库审核器不导入原学习器或环境；从原始事实独立重建计数、所有候选动作表、排序和采用，并核对全部原始结果与时序。

主结果为留出实际成功率、全过程实际学习成本下的成功率和逐轮曲线。另由外部审核按已知生成规律计算全 256 个情境下的期望表现，作为分离评估运气与策略变化的解析诊断，绝不交给模型。

统计单位为独立训练种子，不把同一模型数百回合当作数百个独立模型。种子配对 bootstrap 区间仅作探索性不确定性描述，不是正式全总体确认。

需要如实报告：负改善、没有改善、错误采用、漏掉有益候选、规律反转后的滞后，以及二阶结构在三因素任务上的失败。实验不是为了凑出所有组都通过。
