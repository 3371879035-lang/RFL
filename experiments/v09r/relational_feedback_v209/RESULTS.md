# V209：联合关系反馈神经原型——实现与首次实验结果

日期：2026-11-10。**网络已编写，有限实验与独立代码的存储记录核对均已实际完成，不是只有方案。**

## 1. 本轮实现了什么

入口：`src/feedback_program_v209/network.py`。

实际闭环：公开历史 → 固定神经关系层 → 由真实反馈更新的事实状态 → 多个候选动作策略 → 新留出反馈排序 → 实际配对试用 → 采用/保留 → 后续交互与独立评估。

- 神经参数按解析规则编写并冻结，没有随机权重初始化或梯度步骤。
- 联合网络有 2,178 个固定 Parameter 标量；单字段网络为 274 个。参数数目不是性能结论，只说明这不是对原 14 个算术参数换一个名字。
- 模型自行在全部公开一字段/二字段组合中形成和选择候选；没有给它隐藏的关键字段、真实目标动作或切换时点。
- 后果映射来自实际事实状态；动作表由神经输出在完整 256 个公开情境上编译后执行。这是等价状态编译，不是 SLEEP 参数蒸馏。
- 处理的是通用类别序列微环境，不依赖游戏路线、敌人规则或游戏奖励 Q*。

完整多步动作规划、可自主扩展阶数的结构搜索和参数巩固不在本次已实现范围内。当前是固定非线性神经计算、可变经验状态与程序化试验控制结合的原型，不是已完成的通用神经学习系统。

## 3. 四组实际留出成绩

以下是 **12 个种子、6 轮留出成功率的平均值**，不是只挑最终点，也不是把回合数当独立模型数。

|对照|单条远期线索|两线索联合|两线索且规律反转|三线索联合|
|---|---:|---:|---:|---:|
|单线索网络 + 实际验证|81.08%|52.63%|51.87%|50.63%|
|**联合网络 + 实际验证**|**80.10%**|**78.28%**|**71.35%**|**51.26%**|
|联合网络，只按排序评分采用|74.72%|71.35%|61.26%|50.46%|
|联合网络，随机选候选 + 实际验证|55.25%|55.64%|51.91%|51.00%|

所有组都正常保存事实并继续学习。只按排序采用的组也获得完全相同数量的真实试用，只是不利用本轮新试用结果作本轮采用决定，避免把验证优势混成多练习的优势。

这是新机制的四组消融，不是旧的纯 RL/纯反馈/奖惩/仅奖励四组，不支持“已经胜过纯 RL”的结论。

本环境含 epsilon=.2 的探索和结果随机性，最优策略的期望成功率为 **82%**。有限随机评估某一轮超过 82% 仍可能发生，不是突破该期望上限。

## 4. 能支持的改善

### 4.1 联合关系的表达与利用确实改善

两线索任务，联合 + 验证相对单线索 + 验证的实际平均差为 **+25.65 个百分点**；12 个种子配对的探索性 bootstrap 95% 区间约 **[+21.79, +28.88] 个百分点**。

这次不是直接给网络完整真值表：它从带噪声的实际交互中积累事实，在不知道关键字段的位置下形成候选，经过后续实际交互得到这些结果。有限类别微环境内，先前的“单字段加权表达不出联合关系”这一具体断点得到改善。

### 4.2 实际试用结果参与采用，有额外价值

两线索任务中，相比只按排序分数采用，联合 + 验证提高 **6.92 个百分点**；探索性配对区间约 **[+2.58, +11.98] 个百分点**。规律反转任务差 **+10.09 个百分点**，对应区间约 **[+5.36, +14.15]**。

真实试用不是多余流程：在本轮全任务中，只按排序采用的组发生 12 次解析期望变差的采用；联合 + 验证组没有观察到这种有害采用。但不能因此宣布有限验证永不出错或普遍零伤害。

### 4.3 利用反馈选择候选，比随机试候选更有效

两线索任务的 78.28% 对 55.64%，说明当前目标相关的反馈排序有用。它是有限候选族中的数值化选择，不是非 LLM 自己编写任意研究计划，也没有证明完整递归自改进。

## 5. 真正暴露的问题

### A. 关系复杂度仍由我们预先限制，模型还不会自己扩展

三线索联合任务四组的解析期望均为 50%。当前候选只有一阶与二阶关系，无法表示这个三因素关系；增加同类训练不会自动改变函数族。

下一关键实现应是让模型根据持续无法改善的反馈，尝试扩展组合结构，并通过实际试用决定是否保留。不能由我们把正确三个字段直接塞进去。

### B. “实际试过”仍不等于“真实有改善”

联合 + 验证组共采用 94 次，其中 **58 次正效果、36 次零效果、0 次负效果**，按已知生成规律事后解析分类。

三线索任务里该组 26 次采用全部为零效果，虽然相应的八对实际试用有正样本差。简单的“8 对、均值为正就采用”确实把部分随机优势当成了改善。

这不是说应停止试验，而是需要让采用/继续试验决策使用效果不确定性、剩余使用机会与试验代价；不能再把一次正样本差当作稳定改进。也不应因此给所有任务统一套一个极保守门槛。

### C. 规律变化后的反应仍慢

联合 + 验证组在反转任务中的第 3–6 轮实际成功率：

**80.34% → 53.12% → 65.62% → 74.09%。**

反转后第一个候选构建点，最近 192 条学习记录中实际为 **160 条旧规律 + 32 条新规律**；下一轮为 64 + 128；最后一轮为 0 + 192。模型会恢复，但当前固定窗口把旧、新映射混在一起。

旧新混用与恢复滞后是已观察事实；本轮没有通过窗口长度/分段假设消融，单独证明它解释了多少滞后，因此不把这一解释说成已完全确证的唯一原因。

### D. 更复杂不意味着所有任务都更好

单条线索时，联合组 80.10%，单线索组 81.08%，联合组早期稍慢；后面均达到约 82% 的解析期望。扩大候选空间带来了更多选择和估计负担。

单次候选构建平均约为单线索 **3.38 ms**、联合 **10.16 ms**。这是本次实现测得的局部构建成本，不是完整端到端同时间预算基准。相同实际回合的比较没有把更多内部计算变成免费成本。

## 6. 阶段判断

本次已经完成“网络编写 + 新实际实验 + 问题定位”。结果支持：在这些受控微环境中，联合历史关系、目标相关候选选择及新实际试用共同带来改善。

它没有证明通用任务能力、多步未来推演或完整 SLEEP 参数巩固已完成。下一步的重点不是再延长相同训练，而是**可扩展关系搜索与更可靠的采用/继续试验决策**，随后再检验动态规律适用性。
