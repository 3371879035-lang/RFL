# V204：让实际预测误差选择经验尺度，让试验结论覆盖邻近新情境

在新实例、权重构造和本轮结果出现之前固定。本轮是继续编写通用数值反馈算法，不做游戏适配、不做梯度训练；不把这次改进等同完整通用智能。

## 由 V203 真实缺口出发

V203 的固定条件半衰量 8 改善了反转后的末段表现，但刚反转时仍差。精确初始条件作用域也无法在不重复的连续情境上采用改进。两者都是算法限制，不靠扩大旧确定性测试来消除。

V204 的核心是用**新结果出现之前的预测误差**比较两种历史使用方式，而不是一看失败就抹去历史，或把主观解释当成已证实原因。需要快速响应时近期经验可能更好；结果主要是噪声时较长历史可能更好。最终采用仍以新的实际试验为依据。

## 1. 两个经验尺度，使用样本前误差选择

沿用可编译到 Q/K 的核 `K(q,i)=exp(-20 ||zq-zi||²)`，当前记忆按维度范围归一化。维度有稳定数值语义是接口前提，模型并不自动理解自然语言或学会语义度量。

条件年龄 `A(q,i)=sum_{j newer than i} K(q,j)`。两个专家的记录权重分别为：

`W_h(q,i)=K(q,i) exp[-ln(2) A(q,i)/H_h]`, `H=(1,32)`。

每条终局事实 y_i 写入前，两专家仅用此前实际记录预测它，对已知事实通道计算：

`L_ihk = (y_ik - mu_before_i,h,k)^2`，只保存已知通道。

未知通道不计损失，不把缺失当失败；当前观测不能进入自己的预测。损失与原真实记录一起保存，不修改神经参数。这里的终局事实是目标结果通道；一般逐步累计代价尚未实现，不能把中间未知事实自动当终局结果。

查询 q 的专家概率为：

查询时按当前公开目标的绝对通道权重，把这些样本前通道损失汇总成 `L_ih(g)`；无当前相关已知通道的记录不计。这样不能让无关且稳定的事实通道否决当前目标所需的响应；原事实与误差仍独立于目标保存。

`E(q,i)=K(q,i) exp[-ln(2) A(q,i)/4] * relevant_loss_known_i`

`pi_h(q)=softmax_h[-2 sum_i E(q,i)L_ih(g)]`。

这相当于按近期、相关的样本前平方误差进行指数加权。半衰量 1/32、证据半衰量 4、学习倍率 2 在本轮前固定；不是经验最优值、概率校准或变化原因识别。仍可能把随机波动误判为短期规律。

各专家先分别形成有中性先验的矩值后验，再按 pi 混合，而非先把未归一化的快慢记录相加。否则慢专家庞大的记录量会抵消模型给它的较低概率。混合后的事实二阶矩保留噪声；专家分歧进入探索不确定性代理。

多步联系继续使用实际记录的后继观测传播终局事实分布，不把终局结果直接复制给所有早期动作。传播深度为配置项，本轮 6，记忆容量本轮 384；这些都是计算预算，不是声称能处理任意长程任务。

## 2. 不重复情境中的实际试验作用域

候选与现行完整策略先冻结，再在相同初始观测上各实际运行；**试验结果噪声相互独立**。对每对实际终局事实：

`d_j = g^T(y_candidate,j-y_incumbent,j)`。

在待决策初始观测 x，以相同上下文核得到：

`m(x)=sum_j K_context(x,x_j)`

`delta(x)=sum_j K_context(x,x_j)d_j/(1+m(x))`。

仅当 `m(x)>=2` 且 `delta(x)>0`，在本回合开始选用整个候选策略；否则查询此前的策略路由。采用不再需要浮点初始观测精确重复。门的范围归一化来自试验前冻结候选记忆，不能用留出评估调整。

这是带局部平滑假设的决策估计，不是显著性检验，也不是无风险许可。邻近数值情境可能有不同规律，所以新实验包含连续决策边界，直接检查外推造成的实际退步。低质量/不相关描述也可能使该门失效。策略库和路由由固定程序执行，不宣称模型自主发明了试验流程。

## 3. 新独立工程实验

五类任务：稳定随机、离散突变、五步连续条件选择、随机连续条件突变、三步连续联合选择。连续任务的初始变量每回合重新采样，动作正确性确实依赖该变量，不是给重复状态附加无关噪声。

五个机制版本：

1. `v204_full`：样本前误差自选尺度 + 核支持实际采用。
2. `v204_fixed_age`：固定 V203 半衰量 8 + 核支持实际采用。
3. `v204_exact_gate`：自选尺度 + V203 精确条件采用。
4. `v204_no_gate`：自选尺度 + 无条件刷新；同样支付所有实际试验成本。
5. `v203_original`：完整不改的 V203 模型/权重、原固定衰减/精确门。

16 条新独立种子序列，每条 16 周期；突变任务在第 8 周期后改变规律，该时刻不提供给模型。每周期 4 探索 + 16 对实际试验 + 8 采用后评估 + 8 采用前评估，共 52 回合。评估前/后使用相同外生噪声减少报告方差；评估记录从不进入记忆、尺度选择或采纳门。所有版本按相同随机带与相同真实回合预算执行。

总计 332800 回合，最大 1664000 环境步。4 个 CPU 进程、每进程一个张量线程、1200 秒上限。报告完整全过程、末段、突变后最初两周期、真实采用后的改善与退步，以及连续初始条件是否确实没有重复。独立比较单位是 16 条种子序列，不是总回合数。

源代码、公式、预算在执行前绑定，首次失败/partial 保留；不自动重试、不按结果调尺度或门槛。不改旧实验。新核心放在独立 `src/feedback_program_v204`，可以直接导入，不再依赖 experiments 中逐版串接的模型源码；维度由 Config 指定，有限合成检查另验证一组不同维度。
