# V204：可导入的基础反馈模型，打通连续情境采用

本轮已经完成新模型实现与新实例实验。核心位于独立的 `src/feedback_program_v204`，不再逐版导入 experiments 下的模型，也不依赖游戏或任务模拟器。新初始网络 **598 参数、53 非零**，全部解析编写；实际运行中参数冻结，真实经历、误差记录和策略调用状态可以更新。没有恢复长时训练或自动任务。

## 两个实际改动

1. **用样本前误差选择历史的使用尺度。** 快/慢记忆分别具有条件半衰量 1/32。每条实际终局事实进入记忆前，计算仅依赖更早记录的预测误差，按当前公开目标相关通道汇总，形成两个经验尺度的局部指数权重。不因为单次失败就把旧经验判死刑，也不把没有事实的通道写成失败。
2. **将实际试验的作用域从精确身份扩展到数值邻域。** 候选与现行策略先冻结，进行新的实际试验。只有邻近初始条件的实际结果支持改善时，才在回合开始选用完整候选；其他情况继续原策略。不在回合中拼接未经试验的新策略。这个决定是估计，不是显著性保证。

多步联系来自实际记录的后继状态，终局结果不直接复制给全部早期动作。快慢分布各自归一化后才混合，避免慢专家的大记录量抵消它较低的选择概率。

试验批次期间策略始终冻结，批次完成并决定采用后，才按真实发生顺序单遍吸收其记录并计算样本前误差。预测不读取该条或更晚记录的结果；不意味着批次执行期间已经改变了策略。

## 新实验与成本

16 条新独立种子序列，5 类任务 × 5 个机制版本 × 16 周期。每周期 4 探索、16 对实际试验、8 采用后评估和 8 采用前评估。每组实际回合与环境步数相同；没有把更多交互偷偷分配给新版。

候选/现行的试验结果采用**独立噪声**，初始情境与并列动作采样相同；外部采用前后评估采用配对噪声，且永远不进入记忆、尺度选择或采纳。

- 实际 **332800 回合、998400 环境步**，首次 native exit 0，约 **452.99 秒**。
- 包含 25600 探索、204800 实际试验、102400 外部评估回合，不能将总回合数当独立科研 N。
- 400 条运行的权重前后哈希均同，梯度/优化器更新 0、游戏调用 0。
- 4 个本地 CPU 进程；这是相同交互预算比较，不是各版本计算耗时或硬件效率资格。
- 权重构造前环境调用 0，没有从旧检查点加载新模型的参数；旧检查点仅用于明示对照。

## 主结果：最后四周期成功率

每格为 16 条种子序列、512 个留出评估回合。旧 V203 也在本轮同一批新实例/同一预算上执行，不拼接历史分数。

|任务|V203 原版|V204 完整|V204 固定年龄|V204 精确门|V204 无门|
|---|---:|---:|---:|---:|---:|
|稳定随机|79.49%|79.49%|79.49%|79.49%|78.32%|
|离散情境突变|83.01%|83.01%|82.62%|83.01%|82.03%|
|五步连续条件|49.61%|96.88%|96.88%|49.61%|89.45%|
|随机连续条件突变|49.61%|72.46%|70.70%|49.61%|74.22%|
|三步连续联合选择|12.89%|88.09%|88.67%|12.89%|82.62%|

随机任务中最佳动作的期望成功率为 .8，有限样本得到 83.01% 不等于超越该期望上限。

**大幅改善主要来自解除旧采纳机制的断点。** 连续变量每次重新取值，正确动作实际依赖该变量；不是给重复状态加无关噪声。旧精确门在全部连续任务中采用次数均为 0，实际只执行初始策略。V204 精确门消融同样被卡住。不能把这张表的巨大差距全归为新增误差学习的优势，更不能称胜过正常训练好的纯反馈或纯 RL 模型。

连续任务每条运行有 448 个不同的独立初始条件，832 次回合记录中的重复来自候选/现行及前/后评估的必要配对。采用后外部评估与试验初始条件精确匹配次数为 **0**。完整版本在三个连续任务上分别有 **475 / 791 / 513** 次在新初始观测中采用当前候选，说明不再依赖条件身份完全重复；仍只是数值邻域中的推广。

## 及时反应是否改善

真正要隔离快慢选择，应主要比较“V204 完整 / V204 固定年龄”，而不是只对比被精确门卡住的旧版。

|突变后最初两周期|V203 原版|V204 完整|V204 固定年龄|
|---|---:|---:|---:|
|离散情境突变|37.50%|42.19%|35.16%|
|连续条件突变|51.17%|42.97%|39.84%|

- 离散突变完整版本相对旧版约 +4.69 个百分点，16 条序列中 7 条改善、0 条退步、9 条相同；相对固定年龄约 +7.03 点，9 改善、0 退步、7 相同。
- 连续突变相对固定年龄的最初两周期约 +3.13 点，7 改善、5 退步、4 相同；末段约 +1.76 点，8 改善、5 退步、3 相同。不能当成已经确定的普遍收益。
- 连续突变初期仍低于旧版约 51% 的随机初始策略。旧版此前也没学会原规律，所以“旧版不需要推翻原规律”不能误叫良好的变化适应。新版先学会后仍受旧经验拖累，突变初期约 43% 也仍是实际不足。
- 连续联合任务中自适应比固定年龄末段低约 **0.59 点**；不能说自适应尺度普遍更好。

其他指标同样保留：随机连续突变的全程/末窗无门版更高，但采用前后评估中的退步对数也更多。完整版本此任务是 127 对改善/21 对退步，无门版 158/88；联合任务分别 106/10 与 204/100。这是不同学习轨迹下的 2048 对外部回合计数，不是真实误采纳率，也不能单凭它断言门普遍更安全。

全部种子差值见 `evidence/comparisons.json`，完整全过程指标见 `evidence/result.json`。这是工程机制比较，不是旧奖惩四组矩阵、独立科学确认或总体架构排名。

## 实际复核与保留的失败

第一次 `analyze_stored.py` 存储复核 exit **1**。原因是将 native 的 float32 Q/K 范数展开与 float64 的直接欧氏距离当作同一数值程序；一个权重差约 .00005167，超出事前 .00005 误差限。原源码、stderr 和退出记录保留，不改成首次通过。

新文件 `analyze_stored_float32.py` 读取相同检查点的实际 Q/K 矩阵，明确复算 float32 张量程序，**没有放宽原误差限**。新版本首次 exit **0**，约 **107.56 秒**；不调用 learner/task 类或重新运行环境。

它完整读取 371600 条顶层记录，核对所有世界观测/实际终局结果、从记录分数选动作、184320 份样本前误差回执、路由、普通记忆写入顺序、成本及汇总。误差回执最大绝对差约 **3.35e-7**。11 个 native 输入绑定仍相同，400 条权重前后哈希同。

float32 Q/K 与 float64 几何核的最大差 **0.0004990** 另列诊断；这说明权重程序的实际数值表示也有误差，不能宣称与实数公式逐位等价。新复核并未独立重演每个多步神经 forward，不是独立专家或科学资格认证。详情见 `ARITHMETIC_REVISION.md`，最终复核输出是 `evidence/stored_review_float32.json`。

## 当前还没有完成什么

- 核依赖稳定、相关的数值描述；不会自动学出语言、图像或任意符号的语义。邻近条件效果平滑的假设可能失败。
- 目前主要是短程、完整可观测任务。没有证明长程、部分可观测、突然变化后即刻恢复或陌生结构迁移。
- 目标事实为终局结果，**任意逐步代价累积尚未实现**；不能把局内反馈的一般使用都说成已完成。
- 快慢误差选择仍不是因果归因，没有证明“找到了原因”。实际复测支持局部策略选择，也可能误选。
- 没有梯度学习、SLEEP 参数巩固或与训练好模型的公平性能结论。
- 固定结构仍负责经验管理、试验调度及策略路由。598 参数并不独自包含完整闭环或通用智能。

**完整用户目标继续保持 ACTIVE。** 本轮把不重复连续情境中的实际采用打通，并形成独立可用核心；没有把“通用反馈模型编写完成”改成只通过这些任务即可。下一处实质断点是突变初期仍受旧经验拖累，以及终局事实之外的逐步反馈如何真正进入同一模型。
