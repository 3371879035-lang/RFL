# V200：直接编写权重的事实反馈基础原型

这是一个新建的、与旧游戏模型隔离的候选。先测试“能否从零写出会利用事实反馈的通用接口模型”，不是宣称通用智能或完成与纯训练模型的比较。旧 V198/V199 权重和结果不变。

## 实际写进了什么

初始所有参数清零，然后通过 `write_initial_weights` 直接设置参数张量。没有导入已有模型、健康 Q*、训练集、任务答案，也没有优化器或梯度拟合。

输入是归一化的情境描述 `c`、候选动作描述 `a`、公开目标偏好 `g`。实际反馈是观测事实 `y` 与缺失标记。模型自己的固定容量记忆只保存这些真实记录；权重负责读记忆、比较条件、预测结果并打分。动作描述需要在同一任务内有稳定语义。描述坐标或动作排列可以重新命名，但模型不理解任意自然语言。

两组 Q/K/V 矩阵实现：

\[
\ell_j(x,x_i)=-20\|x-x_i\|^2-\rho_j\,age_i,\quad x=[c,a],\quad \rho=(0.002,0.04).
\]

带缺失掩码的 attention 从真实事实中形成慢、快两种估计。没有对应事实时保留中性先验 0.5，而不是把缺失写成失败。另一个带参数的门根据两种估计的分歧调整混合。双线性读出把预测事实和当前目标结合；一个线性读出给予没有事实支持的动作有限探索倾向。所有数值事前固定，没有根据本轮结果挑选。

这是一种人为设计的归纳偏置，编译为可训练神经参数；不是网络自行发明了上述算法。平方范数特征、softmax、记忆容量和记录写入是公开的架构部分。外部运行器的 epsilon/tie 采样只读取网络分数，三种对照使用同一采样规则。

## 这里“学习”的准确含义

**第一轮权重不更新，真实经验更新模型记忆状态，后续 forward 因而改变。** 这属于有状态的经验适应，不是已经证明持久参数学习、SLEEP 巩固或自主归因。所有参数仍为 PyTorch `nn.Parameter`，以后可以在相同架构上进行真正的梯度训练对照。

初始模型是 `evidence/initial_written.pt`；它不携带本轮评估经历。只导出参数不能保存后续获得的记忆，部署若需断点续接，还须单独保存记忆。这一版不隐瞒该限制。

## 第一轮验证

事前 contract 固定六类任务：确定性条件选择、随机结果、环境映射改变、目标改变、连续条件、两步延迟归因。每类 8 个工程种子，各 256 轮。

三种版本：

- `written`：直接编写权重，正常保留观测记忆。
- `written_no_history`：同样权重，每次选择前清空经验，用于检测历史是否实际起作用。
- `random_untrained`：同一架构、普通随机初始化但不训练，仅是权重编程的机制对照。

后两者**不是已经训练好的纯反馈基线**。与正常训练模型的公平比较留到下一项，不用弱对照冒充已经胜过训练。

各模型只接收自己实际选择后获得的事实；隐藏结果表、未选择动作的结果、评估 oracle 只供外部评估，不进入模型。所有实例使用预生成公共随机带。固定报告冷启动前 64、末 64、变化后早/晚窗口，完整保留逐步事实。两步延迟任务不把终局结果自动归给最初动作，用来暴露本模型没有跨步因果归因的边界。

## 使用

以下示例不依赖任何游戏：

```python
import numpy as np
from model import load_model

net = load_model("evidence/initial_written.pt")
context = np.array([1, 0, 0, 0, 0, 0], dtype=np.float32)
actions = np.eye(6, dtype=np.float32)[:2]
goal = np.array([1, 0, 0], dtype=np.float32)
scores = net(context, actions, goal)["scores"]
# 调用真实任务后，将真实观测写入；这不是指定一个正确答案。
net.observe(context, actions[0], [0.2, 0.8, 0.5])
net.observe(context, actions[1], [0.8, 0.2, 0.5])
new_scores = net(context, actions, goal)["scores"]
```

运行证据在 `evidence`，第一次 native 的结果在 `native_exit.json`。入口只允许一个新的独占结果目录，不重跑已封存实验。预算上限 600 秒/50000 个环境转移/单 CPU 线程；无云端和自动接续。

## 不包含的能力

不包含开放语义理解、原因概率器、多步世界模型、反事实想象、完整路线搜索、SLEEP 或知识写回权重。所测大多仍是条件选择问题；不能把跨表格实例的复用叫作对复杂陌生世界的普遍泛化。
