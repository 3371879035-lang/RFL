# 已训练网络权重（不是完整训练检查点）

- `paired_domains_v227/`：2 个任务域 × 3 个独立训练种子 × 6 个分组，36 份最终网络权重。
- `sampled_practice_feedback_v231/`：2 个任务域 × 3 个独立训练种子，6 份最终网络权重。

来源均为原实验已经完成的 `final.pt`。此次只提取各分组的 `network` state_dict，没有继续训练、筛选更高分检查点或改变权重。每份导出重新加载后，所有张量均与原检查点精确相等；V227 的 36 个网络指纹还与原最终检查点绑定报告逐项匹配。

每个文件含 `network`、分组、任务域、种子、训练步数、更新次数和来源路径。逐文件 SHA-256 与网络指纹见 [MANIFEST.json](MANIFEST.json)。不同版本请使用该版本自己的网络类。

这些文件**不含优化器和原有经验记忆**，不是完整训练续跑状态。当前网络的行为会受到外部历史记忆影响，因此单独加载权重、不恢复相同记忆与评估输入，不应宣称重现了原报告分数。

加载文件本身可使用 `torch.load(path, map_location='cpu', weights_only=True)`，再把其中 `network` 交给相应版本的 `Network.load_state_dict()`。查看源码不需要反序列化本地原始大型检查点。
