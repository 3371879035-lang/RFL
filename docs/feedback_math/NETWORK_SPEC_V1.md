# 反馈算子的神经网络与权重构造规格 V1

日期：2026-11-10。配套：`MATHEMATICAL_MODEL_V1.md`。状态：可实现规格，尚未实现为新模型，未训练、未运行环境。

目的不是先挑一个网络名字再堆模块，而是把数学算子逐项变成计算图，说明固定参数究竟在做什么。保留现有 V204 原样；本文件不声称 598 个旧参数已经实现以下全部机制。

## 1. 模型边界和最终输出

**[设计选择]** 采用“固定参数的循环算术网络 + 可变经验状态 + 实际试验外层”。网络计算事实预测、行动评分和候选效果；外层保存记录、执行动作、收集试验结果和发布策略快照。

固定权重与平方、指数、除法、掩码、归约、最大值等算子共同构成网络。它不是仅由线性层/ReLU 构成的纯 MLP，更不是已训练好的通用语言模型。若将来要求只用某种受限神经元集合，乘法、指数和除法还需要额外的近似编译与误差说明。

输出不只有一个“分数”，而是：

```
action_scores[A]               # 对指定目标、指定有限规划深度的预测值
factual_means[A,F]             # 各可加事实通道的预测累计量
prediction_available[A,F]     # 哪些量真正有定义；未知不等于零
support[A,F]                  # 检索支持，不冒称独立样本数/置信概率
expert_losses / mixture       # 观察前误差和经验时间尺度分配
candidate_descriptor          # 机器可执行编辑，不是自然语言因果定论
trial_request / adoption      # 申请真实试验或依据真实证据采用
```

## 2. 输入与张量形状

记：观测维度 \(O\)，动作数 \(A\)，事实维度 \(F\)，历史窗口 \(L\)，当前记忆行数 \(N\)，专家数 \(R\)，规划深度 \(D\)。这些是接口/计算配置，不固定成某个游戏的 6/6/3。

|输入/状态|形状|语义|
|---|---|---|
|当前观测、已知掩码|`[B,O]` 各一份|允许数值、显式类别编码；没有自动文字/图像理解承诺|
|历史事件缓冲|`[B,L,J]`|\(J\) 个公开事件字段及相应掩码；按发生顺序|
|历史表示 \(z\)|`[B,Z]`|当前观测与缓冲的固定选择/连接，\(Z=2O+LJ\) 为一个可选展开|
|动作目录|`[A,A]` 单位阵|无序离散动作的 one-hot 身份；不是动作好坏|
|实际转移起点、后继|`[N,Z]` 各一份|保留实际后继，而非坐标平均|
|实际动作身份|`[N,A]`|或等价整数索引；只做身份匹配|
|过程贡献 \(c\)、终局贡献 \(y\)|`[N,F]` 各一份|可为任意声明单位的有界数值，不强制 `[0,1]`|
|贡献已知掩码|`[N,F]`|表示组合后的 \(x=c+dy\) 是否已知|
|终止标记 \(d\)|`[N,1]`|真实任务可见终止，不借助隐藏故障标签|
|时间、来源、策略对标识|`[N]` / 外部记录字段|用于历史适用性及证据归属，不输入结果作弊线索|
|目标 \(g\)|`[B,F]`|任务偏好；不由隐藏评估结果生成|
|事实尺度 \(b\)、检索尺度 \(s\)|`[F]`, `[Z]`|由公开单位或快照内的历史统计定义；不是答案|

`B` 是查询批大小，不是独立科学样本数。尺度 \(s_j,b_k\) 均为正；常量字段使用公开单位尺度而不是零除数。连续动作可使用公共参数向量，但只有声明了有意义的动作度量才允许跨动作平滑；不能把任意动作编号的数值距离当成语义距离。

真实经验、试验结果和内部模拟分别存储。模拟样本不能增加实际支持计数。缺失值可在存储中用零占位，但所有读取必须携带掩码，不能把占位零当作实测事实。

## 3. 计算图和信息时序

```text
当前观测 + 已发生的局内历史 ── 固定编码/循环移位 ── z_t
                                                   │
已采用策略快照 ── 实际历史行 ── 类型化检索 ── 一阶事实/后继算子
                                                   │
                                     g ── 目标读出 ── 行动
                                                          │
                                                   真实环境执行
                                                          │
旧实时记忆给出的预测 ─────────── 与新事实比较 ── 观察前误差
                                                          │
                          实时事实记忆更新 ── 候选快照/编辑
                                                          │
                现行包 vs 候选包 ── 实际比较 ── 效果估计 ── 发布/保留
```

部署策略不直接读不断变化的实时事实模型；否则“记忆更新但策略没更新”只是措辞。局内当前观测和事件缓冲始终实时更新，正常反应不必等待局外试验。

## 4. 模块 A：无需假装语义已学会的历史状态

对单批样本，把历史缓冲展平为 \(h_t\in\mathbb R^{LJ}\)。用固定移位矩阵 \(S\) 和插入矩阵 \(P\)：

\[
h_{t+1}=S h_t+P e_t,
\quad S_{r+1,r}=I_J\ (r=0,\ldots,L-2),\quad P_0=I_J.
\tag{N1}
\]

这里第 0 块是最新事件，未填满位置另有有效标记。选择/连接矩阵把 \((o_t,m_t,h_t)\) 拼成 \(z_t\)。所有非零参数为 0 或 1；没有训练环境答案。

这是一个可以明确编写的循环状态模块，但有限窗口可能忘掉重要旧事件。以后加入学习表征时应替换这一接口并单独检验，不能现在就称为充分状态或世界知识。

## 5. 模块 B：稳定的类型化检索，而不是坐标语义猜测

### 5.1 直接差分的核构造

对数值查询 \(q\) 和记忆键 \(k_i\)，先做差再平方：

\[
B_Z=[I_Z,-I_Z],\quad
u_i=(B_Z[q;k_i])\oslash s,
\quad \ell_i=-\beta\mathbf1^\top(u_i\odot u_i),\quad K_i=e^{\ell_i}.
\tag{N2}
\]

- 第一线性层的明确权重是 \([I,-I]\)，偏置为 0。
- 平方是逐元素算子。
- 第二线性层的明确权重是 \(-\beta\mathbf1^\top\)，偏置为 0。
- \(s\) 是输入/快照统计，不通过优化器写进参数；\(\beta>0\) 在构建配置中明确固定，不声称一个常数对所有任务最优。

这样避免旧 \(\|q\|^2+\|k\|^2-2q^\top k\) 路径的平方范数抵消。它不消除输入量化、缩放和所有浮点误差；若两个不同输入在存储时已经被量化为同一值，后面无法恢复差异。

可采用只依赖单位的固定尺度，或从历史算出并在一个策略/试验快照内固定尺度。不能一边比较同一候选，一边偷偷改变距离定义。

### 5.2 类别和缺失字段

无序离散动作采用 \(K_a=e_a^\top e_{a_i}\in\{0,1\}\)。类别字段采用相等关系，不做编号间距离。数值字段只在共同已知字段上计算声明的距离；没有共同可比字段时，输出“没有该度量下的支持”，不把它当成距离为零的完全匹配。

原始权重 \(w_i=K_i K_a\times\text{时间权重}\)。归一化 \(p_i=w_i/\sum_jw_j\) 仅在分母为正时有定义。无支持动作仍然可以被实际试验；没有支持不等于禁止行动。

\(K_i\) 是相关性检索权重，不是原因概率。任意欧氏邻近能否支持决策推广，仍取决于表示和任务。

## 6. 模块 C：所有已观察贡献的预测误差与时间尺度

每个新实际转移按以下顺序处理：

1. 在结果未进入实时记忆前，对已选择的 \((z_t,a_t)\) 保存各专家预测 \(\hat x_{r,t}\)。
2. 结果到达后，用已知贡献通道计算 \(\ell_{r,t,k}=((\hat x_{r,t,k}-x_{t,k})/b_k)^2\)。
3. 原预测无定义或结果缺失的通道不记误差；不能用新结果回填旧预测。
4. 加入新真实行，再更新候选使用的统计量。部署包不就地改变。

非终局也进入此路径，这是对 V204 仅终局误差接口的实质扩展。若一个延迟通道此时尚未知，待其真正可观察时记录对应预测目标和预测时间，不能当作本步已知零。

专家时间权重可为 \(\exp(-\lambda_r A_i(q))\)，其中条件年龄
\(A_i(q)=\sum_{j:\,t_j>t_i}K(q,k_j)\)。\(\lambda_r\) 的负数构成一个 `[R,1]` 线性层的权重；指数后得到时间权重。按实际时间衰减则使用 \(t-t_i\)，两者不同，配置须说明。

专家损失聚合后，用固定 \(-\eta\) 线性读出和 softmax 形成混合权重。**先归一化每个专家的事实均值，再混合**；否则大记忆量专家可能仅凭记录多压倒其他专家。

这些权重是数据驱动的路由状态。它们改变模型函数，但不改变 \(\theta\)；应称为非参数/状态适应，不能宣传为“没有任何学习”。本规格暂不把它们解释为校准后的概率推断。

## 7. 模块 D：过程、终局与实际后继的事实算子

### 7.1 贡献构造和已知性

对每一行：

\[
x_i=c_i+d_i y_i.
\tag{N3}
\]

若 \(d_i=0\)，不需要终局 \(y_i\) 已知；若 \(d_i=1\)，相应的 \(c_i,y_i\) 都须已知才把 \(x_i\) 标为已知。终局定义为零贡献的通道由接口明确声明，而不是把漏报解释为零。

`c + d*y` 由恒等选择矩阵和乘法算子实现。无需学习一个权重来猜“发生过的事实是什么”。

### 7.2 一阶累计事实

固定策略 \(\pi\) 下，令 \(V_0(z)=0\) 表示**零步未来**，不是未知结果的默认估计。对 \(h=0,\ldots,D-1\)：

\[
\begin{aligned}
\Psi_{h+1}(q)
&=\sum_i p_i(q)\,[x_i+\gamma(1-d_i)V_h(z'_i)],\\
V_{h+1}(z)&=\sum_b\pi(b\mid z)\Psi_{h+1}(z,b).
\end{aligned}
\tag{N4}
\]

完整通道情形的核心线性层是

\[
W_{\rm backup}=[I_F,\gamma I_F],\quad
\Psi_{h+1}=W_{\rm backup}
\begin{bmatrix}\sum_i p_ix_i\\\sum_i p_i(1-d_i)V_h(z'_i)\end{bmatrix}.
\tag{N5}
\]

深度间共享这组固定权重。\(D\) 增大增加计算深度，不产生更多独立真实证据。终止行只贡献 \(x_i\)，不能继续传播后继。

缺失通道使用数学稿式 (7) 的掩码归一化估计和独立的后继聚合；它在缺失非随机时有选择偏差。若某个必要后继量没有定义，累计预测也标未知，不把未知续接成已知零。

### 7.3 生成一个可测试的规划策略

对已定义的动作事实预测，用

\[
Q_g(z,b)=g^\top\Psi(z,b),\quad
b^*(z)\in\arg\max_b Q_g(z,b).
\tag{N6}
\]

目标读出的双线性矩阵是 \(W_g=I_F\)。选中动作的**整条事实向量**进入下一步传播，不能分别对每个事实通道选择不同动作后拼成一个不可能同时实现的结果。

若只为部分动作有定义，结果是“已建模动作集合内的候选”，不是所有动作的已知最优解。未知动作仍进入合法试验候选；不要给它们伪造一个零分或负无穷来永久排除。

同分动作使用预先规定的身份次序，或明确声明的混合策略。混合策略要同时传播完整向量和其执行规则。跨不同深度的策略/动作规则也属于候选身份的一部分。

### 7.4 不把二阶网络当必需条件

本版本只构造一阶均值、支持和误差记录，不输出冒充精确后验的 `epistemic_probability`。若后续需要分布或方差，须实现数学稿式 (8) 的交叉项或完整轨迹分布；不直接沿用旧终局二阶矩去代表一般过程收益。

## 8. 模块 E：候选是结构化编辑，不是自动写故事

先保留两类足够具体的候选：

1. **经验更新候选**：用新增真实事实重新计算一个事实模型/规划策略快照。
2. **局部动作候选**：在从历史检索到的条件域内，用另一合法动作替代现行选择，其余条件仍用现行策略。

局部条件可以由一个历史原型 \(z_h\) 和公开的作用半径 \(r_h\) 表达：

\[
s_h(z)=\mathbf1\{d(z,z_h)\le r_h\},\quad
\pi_h(\cdot\mid z)=s_h(z)\pi_{\rm alt}(\cdot\mid z)
+(1-s_h(z))\pi_0(\cdot\mid z).
\tag{N7}
\]

半径/可改动作来自公开候选配置，不由最终成绩倒推；候选可按真实历史的预测差、重复失误或模型动作分歧排序。选择一个局部编辑仍不等于识别了唯一原因。

没有预测支持的合法动作可作为探索候选，不需要先让网络自信才能尝试。候选数由当轮交互预算限制，不宣称这个小编辑集合能表示所有改进方式。

本轮不扩展一个任意程序生成器、语言归因器或“原因百分比分配器”。只有实际发现现有编辑集合不够用时，才针对该表示缺口扩展它。

## 9. 模块 F：真实比较、局部采用与权重构造

对同一策略对的第 \(j\) 次真实比较，先从事实序列计算累计量 \(G^{h}_j,G^0_j\)，再用同一目标计算

\[
d_j=g^\top(G^{h}_j-G^0_j).
\tag{N8}
\]

差分线性层是 \([I_F,-I_F]\)，目标双线性层是 \(I_F\)。作用域权重仅由条件、时间及比较对象确定，不按“这次是否有利”过滤记录。

\[
\widetilde\Delta(q)=\frac{\sum_jw_jd_j+\lambda_0\mu_0}{\sum_jw_j+\lambda_0},
\quad \widehat\Gamma(q)=R_{\rm deploy}\widetilde\Delta(q)-C_{\rm switch}.
\tag{N9}
\]

最终线性读出的权重是 `[1,-1]`，前一输入是部署预算与估计改善的乘积。最大正估计候选可被采用；没有正估计则保留现行包。输入必须含至少一次相应的真实比较；该条件不代表数据已经充分。

**不继续把固定 `mass >= 2` 当普适原则，也不偷偷把 N9 称作保证改善的检验。** 它是估计规则；采样误差、跨条件推广和历史失效已在数学稿分开。低成本任务可以积极试用，具体风险偏好是任务目标的一部分，而不是永久套用一条保守阈值。

对一个部署条件分布而非单点采用时，应对目标分布下的效果积分/平均，不用训练数据中偶然出现频率冒充目标权重。不同目标可复用完整事实结果重新计算效用，但报告需要说明目标改变了。

## 10. 乘法等非线性算子究竟从哪里来

本规格允许张量逐元素乘法、指数、归一化和最大值，和常见注意力计算一样；不是说一层线性矩阵就做完所有事情。

若以平方激活展示乘法的解析编写：

\[
xy=\tfrac14[(x+y)^2-(x-y)^2].
\tag{N10}
\]

第一层权重 `[[1,1],[1,-1]]`，平方后第二层权重 `[1/4,-1/4]`，偏置均为 0。这说明某些算术能力可以由明确权重实现；**它不说明任意语义理解也能由这些权重凭空获得**。

除法仅在声明的正支持域上定义，未知分支由可见标记输出。指数核、softmax 和除法的数学精确式与机器浮点实现有误差；不把一次代数检查当作全部数值域正确性的证明。

## 11. 网络参数、经验状态与外部程序的清单

|部分|固定参数可表达|运行时数据/外部职责|
|---|---|---|
|历史状态|移位/选择矩阵|真实事件到达、可变长度存储|
|距离|差分与平方归约权重|单位尺度、掩码、类别匹配|
|时间尺度|指数衰减系数、损失读出|真实时间、观察前损失、专家混合状态|
|事实算子|\(I_F,\gamma I_F\)、目标双线性矩阵|真实转移经验、归一化权重、循环展开|
|候选比较|差分、效用读出、净改善计算|候选描述、策略快照、真实试验执行|
|策略发布|最大值/比较算子可实现选择|保存和替换策略包、证据关联|
|实际环境|不能由编写权重替代|环境 API、真实观察、现实成本|

没有隐藏的“从评分器读取正确动作”输入。外部观测编码是通用数据接口，不得包含游戏专用最优路线、秘密状态或结果标签倒灌。

## 12. 误差与计算成本必须与模型对应

需要区分四件事：状态表示不足、有限数据/陈旧数据误差、有限深度规划误差、张量浮点误差。大幅增加训练次数不必然解决前三者中的结构性部分；换成更稳定的核也只解决第四类的一部分。

单次 `B` 查询全记忆检索为 \(O(BNZ)\)。若为 \(N\) 个实际后继的 \(A\) 个动作预先建立全连接权重，存储为 \(O(N^2A)\)，构建约 \(O(N^2AZ)\)，\(D\) 次事实传播约 \(O(DN^2AF)\)，另加历史与专家开销。分块可省峰值内存，不等于减少全部运算量。

因此下一轮比较不能只报相同回合数，还应报环境步数、候选/试验次数、规划深度、墙钟时间和内存。按预算截断记忆或邻居数会改变近似算子，需要说明；不要求一开始实现复杂的生产优化系统。

## 14. 首个实现件的可核对性质
