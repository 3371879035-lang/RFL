## 3. 关键结果，不把代数表当新训练成绩

### 3.1 联合关系确实进入了网络函数族

固定的二字段关系矩阵只有 0/1 权重及 -1 偏置。相同矩阵、不同显式事实表，可分别读出 AND、OR、XOR 的四个正确动作。没有在矩阵中预装 XOR 动作答案。

这是**四行真值表的表达/读取核验**，不是模型经过训练获得 100% 新任务得分。当前仍未检验它能否自己在大量历史中找到所需的两个字段。

### 3.2 保留一个未被二阶关系解决的反例

均匀三位 parity 中，全部一阶与二阶事实头仍给出 0.5，完整三字段联合头才可区分真值表。说明“加了两字段组合”不等于通用历史关系问题已解决。组合搜索的覆盖与成本是后续真正需要检验的部分。

### 3.3 推演、历史与证据的关系得到具体核验

- 每个结构分别计支持质量，不把同一事实经过多个结构读取算成多份独立证据。
- 重复内部读取 20 次，事实计数增量为 0；无支持动作仍明确标记为未知。
- 在声明的单步、完整情境与已知采集概率条件下，正确重加权把有偏的 0.1/0.9 还原为 0.5/0.5。这不授予未知概率历史直接使用该估计器的资格。
- 相反世界各自最优值平均为 1，不代表同一可执行策略能达到 1；例中共同策略只能达到 0.5。
- 每步重抽一个本应整局不变的模型，会构造错误的联合轨迹分布；反例总变差为 1/2。

### 3.4 三种误差不再混成“练得不够”

- 有限时域模型误差界：5,184 个有理数模型/策略/时域组合核验。
- 模型误差与搜索误差之和的规划界：1,296 个有理数组合核验。
- 快学生行动分布误差导致的回报损失界：32 个有理数组合核验。

这些小域枚举支持实现与所写公式一致；一般命题依赖正文证明及其条件，而不是靠枚举宣布普遍成立。

一个三状态的解析表中，完全不增加事实，只把推演从近视选择推进到两步，所选方案的表内值从 3/5 变成 1。它说明内部计算可以提取原先没算出的收益，不说明自己想出的经历变成了新外部证据。

### 3.5 巩固还需要覆盖行动使用分布

只覆盖情境 A 的训练表可以让蒸馏 KL 为 0，但学生在未覆盖的情境 B 出错，整体表现仍比教师低 1/2。该反例保留，不能用一个很小的离线损失宣称长期能力已经稳定。

## 4. 对现有机制的实际修订结论

优先修的是“可访问历史 → 联合条件 → 可执行改变 → 实际比较”这条链。

内部推演减少搜索不足；真实试用减少对环境的认识不足；联合关系层修复特定表达不足；巩固减少重复调用慢策略的成本。这四种作用不能互相替代。

本轮没有实现完整的新学习 Agent，没有自动组合搜索或参数巩固训练，也没有新增得分结论。下一实现的具体对象已经缩小为：把联合关系算子接入通用历史候选流程，并接到已有的实际试用方式，而不是继续堆训练时长。
