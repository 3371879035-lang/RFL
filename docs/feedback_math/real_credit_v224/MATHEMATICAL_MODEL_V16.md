# V224：实际结果怎样训练候选生成、实践选择和记忆读取

状态：先推导、后实现的有限工程实验；不更新任何参数，不宣称已经学会归因或具有通用能力。

## 1. 这次修的不是“再多加几个固定规则”

V223 已区分事实、假设、预测及实际试验回执，并处理了重复反馈和缺失信息。但此前的策略梯度检查使用人工构造的 advantage；运行时候选被保存为常数元组，因此尚未证明**真实后续结果能训练产生该候选的网络**。预测记忆只接受世界似然训练，也没有独立的、能由实际任务结果训练的记忆读取器。

本次审计还发现：旧思考器在不同候选之间共用行动/继续的随机数，却把各候选的边缘概率相乘。相关抽样不能如此计算联合概率。例如共享 U 时 P(U<.4,U<.7)=.4，不是 .28。旧前向轨迹保留，不追认其合成梯度为正确策略估计。

## 2. 分开事实表征与决策读取

设真实历史 H_t 中每个原始事件只占一个节点，派生字段沿用 V223 的来源投影，不再贡献独立证据。世界参数为 phi，决策参数为 theta：

    E_t = stopgrad(Encode_phi(H_t))
    q_t = Query_theta(o_t,g_t)
    d_t = stopgrad(c_phi(H_t,o_t,g_t)) + Fuse_theta(q_t,Read_theta(q_t,E_t))
    z_j = tanh(Propose_theta(d_creation,key_j,stopgrad(prediction_summary)))
    pi_theta(a | H_t,z_j) = softmax(Actor_theta(stopgrad(world_features),z_j+d_t))

新增决策侧的条件注意力/适用性门、上下文融合器和三输出 critic。历史不是答案：节点内容不直接替代当前结果，读取、使用及候选控制都是可训练的。世界表征仍由真实观测似然训练；策略回报不反向把世界预测“改成更好看的未来”。当前决策 reader 使用世界编码这一瓶颈仍存在，尚未证明最优。

行为 propensity 只存日志用于概率校正，不放进神经记忆。否则更换策略时，输入状态还带着旧策略的采样概率，不能把历史当作同一条件下的当前策略路径。预测字段仍是当时的预测记录，不是事实答案。

## 3. 候选必须能由原创建前缀重新计算

保存 candidate origin=(session,arm,creation history ids)，保存代码值仅用于运行所有权和数值核对。训练时从**原创建前缀**重新运行 Propose_theta，得到保留梯度的 z_j(theta)。不能从当前完整历史生成一个事后候选冒充当时的候选，也不能把旧代码元组当可微输入。

真实回执才允许候选进入采用集合；是否停想、是否试验、试哪个、保留还是采用由网络抽样。实际尝试是候选进入行为的必要边界，不保证试一次就正确或永久有效。仍允许保留现状；没有自动失败处罚。源码无地图知识、游戏规则或预制“正确原因”。

## 4. 思考路径的概率必须真实

物理粒子的外生噪声 U_phys 可以跨候选共用，作为比较时的共同随机数。**策略抽样 U_action[h,arm]、U_continue[h,arm] 改为候选间独立**。在已有世界版本下，条件于物理噪声：

    ell_thought = sum_(active h,arm) log pi_theta(continue/action | prior internal state)

遇到死亡粒子后只对仍可行动的候选计概率。训练重放固定已记录的离散选择，重新评价当前概率；不得用新策略重新采样另一段思考再与旧回报拼接。策略随机数只作运行取证，不作为条件给定的训练状态；上述概率已对策略随机数积分，保留物理噪声作为策略无关外生变量。

一个 trial_choice 宏步骤包含其之前的全部内部思考选择和外部试验选择。该步骤的 critic 基线必须在思考前计算，不读取该次思考结果，否则会成为依赖本次抽样动作的基线。

## 5. 不预先偷偷确定奖惩权重

记录三维实际结果而不是一个人为加权总分：

    r_i = (后续真实主任务成功指示/N_post, -实际环境成本, -分配的思考粒子行数)
    G_i = sum_(q>=i) r_q
    A_ij = stopgrad(G_ij - V_psi,j(H_i,phase,budget))
    L_policy,j = -sum_i A_ij ell_i
    L_critic,j = mean_i (V_psi,j(H_i,phase,budget)-stopgrad(G_ij))^2

每个真实成本只记一次，每个思考预算只记一次，采用步骤自身不虚构收益。三项分别输出，**不在本轮决定如何加权**。第三项是思考计算量代理，不是总 FLOPs 或真实延迟；不把它称为完整资源公平比较。实际后续回合是训练标签，不是独立最终测试集。零基线的真实成本梯度另行检查，避免只因随机 critic 有非零输出就声称真实反馈已接通。

推导：在世界/环境转移不依赖 theta、离散决策按已记录分布抽样时，nabla E[R_j]=E[sum_i nabla log pi_theta(u_i|H_i) G_ij]。过去回报项与当前 score 条件期望为零；任何仅依赖决策前历史的基线同样为零。确定性候选生成和读取器可沿 log policy 的计算图求导，不需要对真实环境求导。本工程采用一般 score-function 路径，不声称提出新的策略梯度定理。

## 6. 老历史可以用，但不能混淆世界版本

记录完整闭合轨迹（从空记忆开始），包括所有真实动作、思考选择、试验/停止、采用和后续任务；不能漏掉改变后续历史分布的早期选择。世界参数不变、仅策略改变时：

    log w = sum_i ell_theta,i - sum_i ell_behavior,i
    L_IS,j = -stopgrad(exp(log w)) sum_i A_ij ell_theta,i

本次只检查完整轨迹重要性权重，不裁剪、不用单个动作比率代替全程比率。它可能方差很大、长程失效，本轮不是部署级高效 off-policy 方案。若世界参数/物理抽样版本改变，旧思考轨迹的该权重不再完整，接口明确拒绝这一条策略重放；**真实历史仍可用于新世界的观测似然**，并非丢弃旧事实。未来可用实际历史重新生成新的思考并再实践；不能凭空说旧想象来自新模型。

## 7. 与历史反思、SLEEP 的关系及界限

历史反思现在能接受真实后续结果的训练信号：候选生成→思考/试验→采用/保留→后续真实结果→可微重建。这不是 LLM 语言自省，也没有“原因概率加起来为1”。这里只估计行为选择的期望后果，不把相关因素叫已识别因果。

这为后续 SLEEP 的长期学习提供了有来源的训练路径；**不等于本轮已完成 SLEEP 蒸馏**。直接模仿旧策略可能固化坏经验。需要后续真实训练与保留/退步检查，才能讨论长期巩固。此次只前向、似然与反向检查，optimizer steps=0。

## 8. 事前实验

两个新初始化种子 109/127；每个种子3个三步源任务，每个终止失败至多2次单步实际试验，之后两个新的三步普通任务。源任务起点 x0=-2，当前有限转移保证失败，用于覆盖真实反馈路径，**不用于估计任务总体成功率**；后续任务起点交替 -.1/.6。上限54个主任务步+12个试验步=66次实际调用，思考深度3。选择全由未训练网络给出，不强迫试验/采用。后续题已看结果才能计标签，但当次采用不接触这些未来结果。

检查：同快照可微重放数值对齐；真实回报能到达候选/决策记忆；世界/策略/critic 梯度隔离；共用物理噪声但独立策略抽样；旧世界拒绝错误想象重放而接纳真实历史似然；参数字节不变；全真实回执/成本由独立 stdlib 存储审计核对。失败完整保留，不自动重试。
