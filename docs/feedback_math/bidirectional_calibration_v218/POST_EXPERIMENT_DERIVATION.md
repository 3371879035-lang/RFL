# V218 实验后的推导：置信度和偏置必须分开学习

2026-11-11。本文件写在首次完整实验结果之后；不修改事前数学定义、源码、协议或原始数据。

## 1. 已验证的进步

保持原预测的恒等起点、按公开条件选择方向、行动前记账、同一事实不重复增加校准证据均已落到代码。混合可靠性任务中，温度形条件校准在全部16个seed的主要评估点平均上，对可靠条件提高较优动作的成功概率，对较噪条件降低它。该结果不是给模型输入了真实成功率；真实核只用于评价。

但“概率更准确”不是“动作更好”的同义词。对所有动作使用共同严格单调函数时，argmax必然不变。本轮条件化温度形网络并非一般性地保证排序不变，但在混合任务的8192条主要评估记录上，排序相对自身基座也没有变化。因此任务成功率不变是这次真实发生的结果，而不应直接解释为模型能力无效或环境一定达到极限。

## 2. 为什么多加一种修正能力反而可能损害校准

记评价端的真实成功率为r，基座误差为e=p-r，置信度方向修正s=A p(1-p)(2p-1)，偏置方向修正b=B p(1-p)。同一条记录上有精确恒等式：

    (p+s+b-r)^2
      = e^2 + 2 e s + s^2 + 2 e b + b^2 + 2 s b。

已存纯噪声记录中，完整条件版的分解为：

| 项 | 主要评估均值 |
|---|---:|
| 本臂同状态基座误差 e² | 0.00642611388443 |
| 置信度项 2es+s² | -0.000745383316438 |
| 偏置项 2eb+b² | +0.00262544046596 |
| 交叉项 2sb | -0.0000184033558201 |
| 完整校准后误差 | 0.00828776767813 |

这表明在这些记录里，偏置相关项抵消了置信度方向的改善。它是对同一真实轨迹的代数诊断，不是“移除偏置后重新训练会得到相同轨迹”的因果消融。

结构上，p=1/2时置信度基函数v=0，而偏置基函数u=1/4。因此即使基座在无信号情形已接近1/2，偏置分支仍能因有限样本的偶然成功/失败产生非零移动。似然混合的累计log-loss界不保证任意未来时点更好，也不保证Brier或真实核误差更好。恒等初值同样不是学习之后永不退化的保证。

混合可靠性任务中，完整分支也比仅温度形分支改善更少。局部变化任务则出现概率NLL轻微变差。当前证据支持“区分两类修正并验证适用性”，不支持“增加基函数后全面替代旧版”。

## 3. 后续真正训练的目标和数据顺序

已有prior_logits为可训练nn.Parameter，完整条件版80个、温度形版48个。当前E为事实证据buffer，原H/F为统计基座。训练先验不等于训练所有历史编码器或任务策略。

设训练任务τ的第t次预测之前已获得支持事实D_(τ,<t)，其中每个事件有稳定id和原行动前基座预测。校准状态E_(τ,<t)只由这些过去结果构成。可训练目标是：

    J(phi) = mean_(τ,t in training queries)
             -log q_phi(y_(τ,t) | z_(τ,t), E_(τ,<t), p_(τ,t))。

具体时序：固定/重建支持前缀一次 → 查询前向并计算损失 → 该查询事实按时间顺序成为后续支持的一部分。不能把当前查询结果先写入E再预测自己。多次优化epoch可以重读训练数据，但不能把重读算成多个独立环境事件，也不能将同一事件在持久E内累加多次。训练状态与评估状态分开；评估不observe。

本轮有限差分已验证梯度接口，但优化器步数为0。下一次训练应保留基座、仅温度形和完整偏置三个对照；在训练任务优化先验，在独立验证任务选择是否需要偏置能力，再在未用于选择的任务报告结果。不按这次噪声测试结果直接手调一个新先验并把同一基准的改善当泛化。

如果需要对偏置加正则，可研究J_lambda=J+lambda mean[(B_phi p(1-p))²]。lambda必须在训练/验证边界内选定，不能从本次报告的测试误差倒推最优值。这只是待检验的训练候选，不是本轮已采用算法；也不预设偏置永远有害。保留允许提高和降低置信度的双向能力。

此外，当前E累积的是校准关系；它没有独立的时间变化假设。当基座自身正在迅速适应时，早期的校准关系未必仍适用。这是下一次训练应保留的变化/回归检查，而非本轮已证明的唯一退化原因。

## 4. 仍无法靠训练先验解决的容量限制

由于q在五个固定映射的凸包内，|q-p|不超过p(1-p)。训练80个先验参数不能突破这个包络，也不能自动获得高维连续表征、多步归因或通用规划。若任务要求大幅校准或新表示，需要另外的结构修订和实际验证。本轮没有借口将这些缺口说成已训练完成，也没有因此否定已观察到的局部双向校准。
