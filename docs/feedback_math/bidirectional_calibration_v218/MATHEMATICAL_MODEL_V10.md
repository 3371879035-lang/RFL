# V218：恒等起点、条件化双向校准、可训练先验

2026-11-11；本文件先于新源码和实验。V217的单向概率收缩未被采用，本轮基座恢复为不改动的V216。不是从不利结果中删除旧版本，而是明确比较新的校准层。

## 1. 先解释为什么不直接给全部输出乘一个温度

上一轮用到的均匀收缩不能纠正不够自信。logit(q)=exp(a)logit(p)+b可以双向调整且a=b=0为恒等，但要改变输出就必须训练参数或人为赋值；在本轮尚不做优化器训练的条件下，不能把手选a/b说成模型学会了。另一个问题是任何对所有动作共用的严格单调映射都保留argmax，所以概率校准改善不必然改变本任务的成功率。

本轮选择一个有限、可逐项核算的双向校准基函数网络。真实反馈更新其证据权重，先验参数保留可微接口用于后续训练；不在评估集拟合温度。

## 2. 概率合法且包含双向调整的构造

令p为基座在行动前输出的二元成功概率；u=p(1-p)，v=p(1-p)(2p-1)。使用五个候选映射：

    h0(p)=p
    hS(p)=p+v        （提高远离1/2的置信度）
    hF(p)=p-v        （降低置信度）
    hU(p)=p+u        （校正成功概率低估）
    hD(p)=p-u        （校正成功概率高估）

五者都把[0,1]映射到[0,1]，在(0,1)严格递增：u'=1-2p，v'=-6p²+6p-1∈[-1,.5]，因此对应导数非负且内部为正。这里的“升/降成功概率”不等同于“更/不自信”，两类基方向分别保留。

该基函数族有明确容量限制：修正幅度不超过p(1-p)，不能仅靠这一层将.99直接改成.6。选此有限族是为了本轮恒等起点、概率合法及证据核算可同时验证，不声称覆盖任意校准函数。未来先验训练不能突破固定基函数容量；若实际错误需要更大幅修正，应另研究可训练温度/偏置，而不是隐瞒这一限制。

完整先验pi=(.5,.125,.125,.125,.125)；仅温度形消融为(.5,.25,.25)。每对相反方向等权，故初始混合恰好等于p，既不是仅含恒等函数，也不是凭近似希望平均不变。实现用q=p+A v+B u及系数差计算，保证零证据时A=B=0、输出逐位保持原p。

## 3. 根据什么条件判断

公共输入z=(x,候选动作a)，不含正确动作、隐含规则、最终结果、评价核。校准层比较z的候选条件分组G。每格保存各映射的累计log似然比E_(G,c,k)，初值0。

    E_(G,c,k) += log Bern(y_t;h_k(p_t)) - log Bern(y_t;p_t)

只更新实际访问的(x_t,a_t)格。p_t在结果出现前保存，不能用已经学习该结果后的p重新给同一事件评分。

以可训练先验头pi_phi(G,k)=softmax(log pi_k+theta_(G,k))，theta初值0：

    Z_(G,c)=sum_k pi_phi(G,k) exp E_(G,c,k)
    w_(G,c,k) ∝ pi_phi(G,k) exp E_(G,c,k)
    q_G ∝ prior(G) product_c Z_(G,c)
    p_cal(x,a)=sum_G q_G sum_k w_(G,c_G(x,a),k) h_k(p_base(x,a))。

条件版可给不同动作不同映射，因此有可能改变决策，但并不保证一定改对；全局版只有空分组，对所有动作共用单调映射，理论上不改变贪心动作。两者必须分开报告。由于全局版在这里不会改变行为，旧5类全局对照直接读取原V216行动前预测和真实结果，运行新校准层，不重复旧环境bank。新混合可靠性场景同样读取本轮新基座记录作为全局对照。明确标为RecordedForecast输入，不伪称新环境采样。

## 4. 同一个事实没有变成两份证据

令基座预测序列似然为P0，某校准专家在同一实际观测序列的似然为Pk。E存log(Pk/P0)，最终校准序列概率满足

    Pcal = P0 sum_k pi_k exp(E_k) = sum_k pi_k Pk

而不是P0×Pk。条件分组先分别边际化再混合，不能将各组当独立证人相乘。当前实际事实可在预测记账后用于基座普通学习一次；这是一个自适应预测算法，不是给该结果再补一次独立校准观测。

历史仍只建立原H，没有用已拟合H对同一历史作回顾校准。沿用稳定事件id去重，已知事实重放不改计数。不同真实事件即使内容相同也保留。外部伪造新id不在本接口可识别范围。

## 5. 可得到的界，不等于成绩保证

固定参数、相同实际动作序列上，对固定G与每个访问格选择k_c：

    Lcal <= sum_c L_(G,c,k_c) -log prior(G)-sum_c log pi_phi(G,k_c)。

包含空分组与恒等专家，原基座总log loss的额外最坏代价有一个有限先验界；全局校准为log2。它不是某个时刻误差更小的保证，不是实际任务收益或一般因果解释保证。多个格的代价必须累计。后续优化theta期间此固定先验界不能直接照搬，需按实际训练/冻结边界重新说明。

同时计算校准专家分歧sum omega_k(h_k(p)-p_cal)^2与成分内Bernoulli方差，验证总方差恒等式；仍不是已识别真实物理噪声。指标主要用真实结果NLL/Brier，已知合成核MSE仅为评价端诊断。

## 6. 为真正训练预留的数学接口

theta是nn.Parameter，证据E是buffer；forward与预测NLL对theta可微。完整条件版16分组×5映射=80个先验参数，温度形条件版48个，全局版5个。当前theta不做优化器更新；其数据驱动变化来自显式事实证据而非假装梯度训练完成。

后续可以在训练任务的支持前缀建立E，再在后续查询上优化theta；查询标签进入E只能发生在该条预测评分之后。保留任务不参与训练、重复epoch不增加环境样本数。比较训练候选仍需新实际对照再采用。当前基函数和H/F是有限/统计构造，不宣称已完成通用可学习编码器或端到端训练。
