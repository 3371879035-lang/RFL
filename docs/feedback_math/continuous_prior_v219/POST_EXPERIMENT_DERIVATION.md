# V219 事后推导：先验改进不等于决策风险已经处理好

本文件写在一次实验完成之后，不改动已执行网络或事前协议。实际结果支持局部改进而非全面替换。

## 1. 连续偏置先验减轻了上一版的噪声退化，但没有消除它

纯噪声核MSE：V218完整偏置0.00828777→V219连续偏置0.00717063；原基座0.00659159、V218仅双向置信度0.00570246。因此不能只拿退化较重的上一版作对照。

同一任务中的混合可靠性：V218完整偏置0.02029912→V219 0.01904131；仍不如只做双向置信度的0.01709147。条件化升/降方向保留。连续幅度、零中心与完整边际化并不是“所有不确定性都解决”的充分条件。

## 2. 一个具体反例：概率损失下降，动作却改错

整体规律变化任务的16seed平均主要成功率，从基座81.6528%变为81.3232%；差异全部来自seed13的第16次学习后评估。37条相同公开上下文[0,1,1]的记录中，本臂基座排序正确，新校准排序错误。

    基座 p(action0)=0.4782565936，p(action1)=0.4787178704
    校准 q(action0)=0.4766676409，q(action1)=0.4764640191
    正确动作由环境评价端判定为1，模型不读取这个标签。

基座正确方向的概率差只有0.00046128；校准后变成-0.00020362。对同一后验只代数去掉偏置项时，方向仍正确。这是已存真实预测的分解，不是移除偏置并重新学习的反事实实验。

若原优选动作a的均值优势m=p_a-p_b>0，则校准改变排序当且仅当delta_b-delta_a>m。很小的移动也能越过很小的决策间隔。因此不应继续用“修正幅度变小，所以一定更安全”的论证。

## 3. 接下来的不确定性问题必须与行动差值对应

当前网络正确传播了每个动作自身的候选模型方差，但读出仍为均值argmax。它没有宣称采用了完整的决策风险规则。

如果要利用不确定性判断两个动作的差异，应处理随机量D=Q_a-Q_b：

    Var(D | H)=Var(Q_a | H)+Var(Q_b | H)-2 Cov(Q_a,Q_b | H)。

两个动作可能共享同一条件格、分支选择和偏置变量，不能把它们当独立预测直接相加方差。在不含动作字段的分组中可能共享同一个b；包含动作字段时格内变量才在给定分组下独立，而分组不确定性仍会产生相关性。当前版本未输出该联合协方差，不应从两个边际方差编造“翻转正确的概率”。这给下一次结构修订提供了明确目标，而不是再添加一个凭感觉的置信阈值。

即便得到了联合后验，它仍然依赖候选模型是否适用。不能强制所有高不确定候选永不执行；探索、试验成本和任务风险必须有明确目标，并用实际后果检验。

## 4. 后续真正训练应学什么

本轮80个先验参数中，64个控制分支质量，16个控制连续幅度的浓度。两类梯度均经数值检查；真实任务优化器更新0。

先在训练任务的支持/查询切分上学习分支质量与浓度，保持原始事实身份与行动前预测。改变先验从同一份似然buffer重算，不把旧后验叠加为新先验。重复查询优化不增加事实数。只用当前已见结果训练，不把评价核或正确动作标签交给网络。

验证至少同时看概率质量、实际动作错误及相同预算成功率；本轮已经给出了NLL稍降而决策退化的实例。候选是否采用应由独立验证决定，不在这6类反复使用的开发任务上调到没有负例。冻结独立评估不更新参数；参数训练完成以后再进行新的真实任务对照，而不是以离线损失替代实际行为。

本轮不新增决策训练目标或运行参数优化；也不预设更强收缩永远正确。保留仅温度形、原基座和连续偏置三个可训练/可比较入口，下一步不能只比较上一不利版本。
