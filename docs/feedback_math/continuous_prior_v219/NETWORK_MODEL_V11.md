# V219 神经网络与后续训练接口

* 新模块ContinuousBiasHead；完整网络ContinuousPriorNet复用未修改V216基座、V218真实事件协议。
* 公共ContextLift仍比较全部公开条件及候选动作的子集分组。当前三项二元输入加动作，共16分组81格。
* 可训练参数：prior_logits[16,4]，log_concentration[16]，共80；均从零残差初始化，不随机初始化。
* 非参数证据：各格离散log似然比、连续偏置似然的log多项式系数、visits。系数只记录似然，Beta先验通过lgamma在forward中计算，可微地重算浓度；旧后验不作为下一次重新拟合的先验。
* 实际流程：缓存行动前基座和候选预测→真正执行动作→原API校验并让基座普通学习一次→用原缓存更新新校准证据一次。不得使用刚更新后的p评分该事件。历史回放只读，评估不observe。
* 输出：预测均值、分支质量、两个校准系数、偏置分支条件均值/方差、预测模型内方差与结果内方差。只作当前假设族内量，不作为物理噪声分解或因果概率。
* predictive_loss(rows, actions, outcomes)已继承可微查询接口；后续先用支持前缀构造buffer，重复优化查询损失不增加buffer计数。训练/验证/保留任务分离。
* 本轮不执行optimizer。变更先验的检验与有限差分仅在合成检查对象内临时扰动；每个实际任务重新使用声明初值。
* log系数宽度随最长格历史动态增长；不是固定到256的神经结构上限。当前256任务验证后宽度257。长历史约二次累计成本，下一阶段若训练更长需测量并选择等价近似，不能把本参考实现说成已经解决效率问题。
