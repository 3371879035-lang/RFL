# V219 数学模型：偏置幅度的连续先验，而非只在两个极端间选择

2026-11-11，先于新网络和实验结果。针对V218已经观测到的偏置分支噪声退化；不改动V218的执行代码、原始记录与结论。本轮仍不执行优化器训练。

## 1. 先定位模型假设

V218完整校准先验为恒等.5、锐化/平缓各.125、正/负最大偏置各.125。零数据时平均修正为0，但这并不表示先验相信偏置幅度小：在偏置分支内，b只可能是-1或+1，先验方差为1。对有限反馈选择一个极端，容易追逐偶然波动。这是可以具体改变的假设，不需要把反馈思想整体否定，也不应直接删去所有偏置能力。

保留q_b=p+b p(1-p)，b∈[-1,1]。令w=(b+1)/2，采用w~Beta(a,a)，a=exp(eta)，初始eta=0即a=1。该坐标下是均匀幅度先验，E[b]=0，Var(b)=1/(2a+1)=1/3；它不是坐标无关的“客观先验”，也不是对新任务真值的保证。后续可用训练任务学习eta。

保留V218聚合后的分支质量：恒等.5、锐化.125、平缓.125、连续偏置.25。因此不通过偷偷降低偏置分支总概率制造改善，也不删除大偏置：连续分布的支持仍是[-1,1]。

## 2. 精确边际化，不把后验均值再当确定答案

u=p(1-p)，v=u(2p-1)。四个分支为p、p+v、p-v、p+(2w-1)u。偏置分支给出均值与方差，不将w的均值代入后重新丢掉不确定性。

对某公开条件格内n条真实结果，记录每条行动前基座p_t与实际y_t。定义

    r_t^- = Bern(y_t; p_t-u_t) / Bern(y_t;p_t)
    r_t^+ = Bern(y_t; p_t+u_t) / Bern(y_t;p_t)
    L_n(w) = product_t [(1-w) r_t^- + w r_t^+]
           = sum_(j=0..n) C_(n,j) w^j(1-w)^(n-j)。

系数初值C_(0,0)=1；每个新事实只更新一次：

    C_(n+1,j) = C_(n,j) r^- + C_(n,j-1) r^+。

采用log系数与logaddexp计算，不做网格近似或采样。C已经包含展开项的组合重数，积分时不能再乘一个二项式系数。

    Z_bias(a)=sum_j C_(n,j) B(a+j,a+n-j)/B(a,a)
    rho_j ∝ C_(n,j) B(a+j,a+n-j)
    posterior(w)=sum_j rho_j Beta(a+j,a+n-j)。

用Beta分布的一、二阶矩得到E[b]与E[b²]。不要把真实结果y误当“选择了正偏置专家”的标签，直接累加Beta成功/失败数；真实观测是y，不是隐变量w的伯努利样本。

## 3. 条件、模型不确定性与唯一证据

沿用V218的公开z=(x,候选动作a)分组G，不读取正确动作或隐藏规律。每格四个分支证据为(1, exp E_sharp, exp E_flat, Z_bias)。

    Z_(G,c)=sum_k pi_phi(G,k) Z_(G,c,k)
    posterior(G) ∝ prior(G) product_c Z_(G,c)
    posterior(k | G,c) ∝ pi_phi(G,k) Z_(G,c,k)。

最终输出为完整后验预测均值。并保留Var(Q | 已知事实)、E[Q(1-Q) | 已知事实]，两者相加为q(1-q)。这些是当前候选模型内的不确定性，不是已证明覆盖真实规律的置信区间，更不是原因概率。均值不变而不确定性下降，是合法的学习结果；不能因输出接近零修正便声称证据不足或毫无学习。

每个分组是替代解释，必须混合而非相乘。一个固定分组内每个事件只属于一个格。所有log比率相对同一条行动前基座：Pcal=Pbase×边际似然比，而不是再乘一次基座似然。同一事实可推动基座下一次普通学习，但不能在校准里额外算第二份独立观测。

历史只用于建立原基座，旧历史不经事后预测再加入新校准计数。稳定event id去重，冲突内容拒绝；读取/重放既有事实不更新证据。不同真实事件内容相同仍保留。伪造新id不是本接口可识别的问题。

## 4. 为训练保留可重算的证据，而不是旧后验当新先验

每个G有4个prior_logits与1个log_concentration，共16×5=80个可训练参数；初值为聚合先验与a=1。C、离散log比率、事实数均为不含先验的buffer。改变训练参数后，从这些一次累计的似然重新积分；不能以旧后验作为新先验，再把历史乘一遍。

查询NLL可微地连接分支先验和Beta浓度，使用lgamma计算归一化。支持前缀建立证据后，查询只计算损失；同一训练数据多次优化epoch不等于多次环境观测。后续正式训练需要训练任务/验证任务/未参与选择任务分开。本轮只做非零梯度、有限差分和同一证据更换先验的重算检验，优化器步数0。

## 5. 已知边界与待检验问题

概率合法且初始逐位恒等。仍有|q-p|≤p(1-p)的容量限制。精确系数表示长度随事实数增长：内存约O(cells×n)，累计更新/积分计算约O(n²)，这是可核算参考网络，不是无限历史的高吞吐最终实现。连续先验不保证不追噪声、适应更快或提高任务回报，必须保留零/负结果。

累计校准关系的时变性、高维表示和多步归因仍未解决；本轮只改偏置幅度先验与对应不确定性传播，不把这些新问题混进同一次改动。

一般模型平均思想参考[Hoeting等原作者机构资料](https://stat.uw.edu/research/tech-reports/bayesian-model-averaging)。本文件的连续偏置、Bernstein系数递推和网络组合是本地推导，不声称该资料已证明RFL或本次实验的效果。
