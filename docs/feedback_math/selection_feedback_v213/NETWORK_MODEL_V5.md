# V213：数学对象到神经网络模块

先于本版源码保存；边界为有限类别外生上下文、离散动作与事实结果。通用的是接口和更新规则，不是已经证明适用所有环境。

## 数据流

    真实 Fact → V210 条件记忆 → 冻结神经候选
                          ↘ shadow 双路预序贯预测 → 可用结构候选
    冻结候选 → 全域行为商空间 → TrialMixture → 实际动作与真实 Fact
                                  ↑                ↓
                             状态权重更新 ← 正确行为倾向
    试用结束提名 → 全新配对验证 → 可认证现役替换

1. `BehaviorBank` 保存有限域完整行为签名、类成员和复杂度最小代表。枚举只用于比较，动作在线仍由神经网络生成。
2. `TrialMixture(nn.Module)` 注册冻结候选 ModuleList、目标效用和 log_weights buffer；前向输出动作概率。内部按候选逐行原 forward 执行，避免批量 GEMM 的最后一位误差改变并列 argmax。候选不接受试用数据更新。
3. `TrialLedger` 显式累计各 lease 预定风险上界与任务上限；没有新行为返回 None。`offer` 先产生绑定序号/context/分布的 receipt；`observe` 只接受该 receipt 的真实新事实、相同动作倾向及身份。类型边界不能证明环境真的运行过，实验必须保留 raw。
4. `finish` 只提名，不能改变外部 incumbent；完成的 lease 不能再追加结果。`certified_trial` 将全域不同的提名接到已有 EvidenceBook，cutoff 包含全部筛选数据。
5. `ShadowRelationProbe` 为新结构和同样可学习的基准各保留独立条件模型，接收新事实前得到 log-score，之后两者各记录一次。它仅输出进入候选池的建议，不改活动网络或现役策略。

## 复杂度和新增限制

完整行为证书最坏指数于字段数；这是明确有限域计算预算，不是可推广到连续世界的廉价去重。每个实际试用动作需要 M 个候选的 forward；所有时间和调用数应计入收益比较。并非“加一层 softmax 就免费更好”。

参数分三种：解析 Parameter 不训练；事实计数/时间后验状态可更新；专家 log_weights 是在线算法状态。代码不得把后两种偷偷报告成梯度训练或 SLEEP 蒸馏。
