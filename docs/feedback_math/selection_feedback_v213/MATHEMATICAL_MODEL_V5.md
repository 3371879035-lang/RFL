# V213：行为等价、有限试用与结构探索的分离

2026-11-10。本文在本版神经网络源码之前保存。针对 V211 已保存的三个断点推导，不修改旧源码或结果，不把理论推导写成实测收益。

## 0. 先纠正问题定义

V211 的 52.76% 完整组验证配对比较了相同行为；反转任务已有 82% 候选却提名 50% 候选；未采用又机械触发结构增长。这分别是**比较对象、试用调度、结构容量**的问题，不是一个参数需要调大。

目标不是“每次改动都证明正收益才允许动”，也不是“看到一点正数立即永久替换”。新状态区分：事实档案 D、条件模型 M、冻结行为类 P、有限试用权重 w、现役策略 pi0、长期采用证据 E。改变 w 是带预算的实际探索，不等于已经认证 pi0 的替代者。

所有结果仍是事实；目标效用 u(y)∈[0,1] 明示输入。损失 1-u 用于下面的计算，不声称数学上没有优化方向，也不把本轮称为新的奖惩消融。神经 Parameter 暂不梯度更新。

## 1. 在行为商空间上比较，而非按快照编号比较

对公开有限类别域 X=Π_j{0,...,c_j-1}，固定目标、动作空间、探索率 epsilon，定义

    pi ~ pi'  iff  对所有 x∈X、a，pi_epsilon(a|x)=pi'_epsilon(a|x)。

对确定性神经贪心头，epsilon<1 时，只需逐个合法 x 比较 argmax 动作；epsilon=1 时所有头都为相同均匀策略。按完整行为表分组，每类只分配一份初始试用质量，不能因为某个行为有十份重复快照就获得十倍先验。

行为相同 ⇒ 对同一外生上下文分布和任意结果核有相同即时期望效用。因此不启动优劣试验、不消耗采用错误预算；普通任务经验仍可继续积累。代表选择按结构单元数、结构索引、完整身份的稳定顺序。执行仍走神经 forward，不用真值表代替动作网络。

这只是完整有限域的证明。其计算量为 O(|X|·候选数)，必须计入成本；域太大或 schema 不完整就不能签发这个证书，禁止用“在几个样本上看起来一样”代替。

## 2. 不再用一次 32 条样本的最大值垄断试用机会

先冻结 M 个互异行为候选（包含旧策略），各自策略 p_j(a|x)。本轮试用内不更新这些快照。令

    w_1,j=1/M
    q_t(a|x)=Σ_j w_t,j p_j(a|x)
    mu_t(a|x)=(1-rho)pi0(a|x)+rho q_t(a|x)。

实际动作从 mu_t 采样，观察真实 y_t 后才更新。记录的倾向必须是实际 mu_t(A_t|X_t)，而不是某个被抽中的专家的倾向。取

    loss_t = 1-u(y_t)
    hat_loss_t,j = p_j(A_t|X_t) loss_t / mu_t(A_t|X_t)
    log w_{t+1,j} = log w_t,j - eta hat_loss_t,j - log Z_t。

只加实际事实一次；逆倾向是估计权重，不增加条件模型样本量。历史重放、预测结果不能进入这里冒充实际 y。模型可以随真实反馈重新分配试用，而不是一次提名错误后把全部预算锁在它上面。

### 2.1 可以证明什么

在动作前已知 X_t、所有策略和 w_t，行为倾向正确且支持充分时，

    E[hat_loss_t,j | past,X_t] = Σ_a p_j(a|X_t) E[loss_t|X_t,a]。

每个专家使用共同 epsilon>0，保证 mu≥epsilon/K。rho>0 时还有 mu≥rho q。因此

    E[Σ_j w_t,j hat_loss_t,j² | past,X_t]
      ≤ Σ_a Σ_j w_t,j p_j(a|x)² / mu_t(a|x) ≤ K/rho。

利用 exp(-z)≤1-z+z²/2（z≥0）和对数势函数，虚拟混合 q 相对任意固定专家 j 的**期望**累计损失差满足

    E[R_T(q,j)] ≤ log(M)/eta + eta T K/(2rho)。

预定 T 下可取 eta=sqrt(2rho log(M)/(TK))。M=1 不更新权重。

这是借用专家 bandit 的指数加权思路后，为当前混合重新推导的期望界；不是 Exp4.P 的高概率保证，也不是候选权重等于“某原因正确的概率”。小预算依然可能选错，缺少表达的正确策略不会被凭空创造。

实际执行的是 mu 而不是 q。对于固定 rho，

    R_T(mu,j)=(1-rho)R_T(pi0,j)+rho R_T(q,j)。

所以保留较大旧策略份额可能导致线性保守代价，**不能把 q 的界移植成整个 mu 的无遗憾保证**。

## 3. 有限试用不是永久采用：用可解释预算控制放权

对任意有界效用向量 v_a∈[0,1]，

    J(pi0|x)-J(mu_t|x) ≤ TV(pi0,mu_t)
      = rho TV(pi0,q_t) ≤ rho(1-epsilon)。

预先给定 T 次实际试用，以及相对同上下文旧策略的**累计条件期望效用损失上界预算 B**，可取

    rho=min(1, B/[T(1-epsilon)])。

逐步同时记录精确 TV 和保守上界；Σ TV≤T rho(1-epsilon)≤B。B 不是环境回合预算，也不是实际损失一定不超过 B 的概率保证。这个界不需要知道哪个动作正确，但比较的是同一上下文下的即时效用。

重要边界：若动作改变未来上下文、导致不同长轨迹，这个一步 TV 界**不能**充当整个 MDP 的安全/收益保证。本版仍只验证外生类别上下文的短任务。危险现实任务不由此自动授权试用。

本轮权重只在这份有限 lease 中有效。结束时可从 w 提名一个冻结候选；**重新用未参与试用/筛选的新配对事实**进入原 V210 EvidenceBook，才可认证长期替换。没有认证时 lease 到期失效，旧策略不变；不得换个 lease 编号无限试用而隐瞒累计预算。

有限风险预算在一个 TrialLedger 中累计，等价类无新行为时不发 lease，不耗风险预算/采用 alpha。临时混合的事实照常回到普通记忆，不能把未采用候选的事实删除。

这种双层决策解决的是“只有完全不试或永久采用”的错误二分。它不解决风险预算由谁偏好、什么任务应该承担多少风险的问题；研究中的 B 是显式工程选择，不是假装推导出的普适常数。

## 4. 结构探索独立于是否采用

保留任意阶关系的完整枚举前沿，但不再用“试用未采用 ⇒ 激活下一批结构”。用单独计算预算建立 shadow 结构：先重读已有事实初始化，然后与一个在试探前确定的现有基准头，接收同一批新事实。

每条新事实先预测后更新：

    G_n=Σ_t [log p_shadow,t(y_t|x_t,a_t)-log p_base,t(y_t|x_t,a_t)]。

本版使用显式简易描述长度代价

    kappa=max(0,C_shadow-C_base) log 2，C 为关系单元数。

若 G_n>kappa，结构才进入可生成候选的活动集合。解释是对额外单元设置每单元一比特的先验编码代价，**不是已经校准的计算/记忆成本，也没有全模型错误选择保证**。实际构建、重读、前向成本单独报告。

基准和 shadow 都按新事实正常学习，不能拿冻结弱基准比正在学习的 shadow。没有通过只是不在这次启用，原始事实、探测结果和更高阶可达性保留；顺序探索可以继续，不以低阶无收益否定高阶 XOR。预测改善只允许表达进入候选池，仍不等于策略实际收益，更不允许直接永久采用。

## 5. 神经模型需要改变的地方

* 关系激活和条件记忆继续复用 V210：解析 Linear/ReLU、einsum、时段 softmax；不重新训练旧 Parameter。
* 新增行为商空间编译器：完整域证书，不连接环境隐藏标签。
* 新增 TrialMixture(nn.Module)：候选 neural forward → 探索动作分布 → softmax 专家权重 → 与旧策略 convex mix。log_weights 是真实反馈更新的显式状态 buffer，不冒称优化器训练的权重。
* 新增有限试用 ledger、逐步实际行为 receipt；动作前给出分布，结果后更新；一个 receipt 仅用一次。
* 新增 ShadowRelationProbe(nn.Module)：双路先预测后学习，编码代价只决定结构候选资格。
* 长期采用继续使用独立事实的 V210 证据控制器，当前 alpha 规则不因希望结果好看而修改。

## 6. 与 Dream / SLEEP 的关系

历史只负责产生/初始化候选和结构假设；新的实际结果负责试用权重和采用证据。内部重读不生成独立证明。这里吸收的是“从已有探索中改进后续探索”的方法思想，不声称实现原论文的完整自改进系统。

长期 SLEEP 应巩固实际验证过、带适用条件且通过回归检查的行为。本版仍不做梯度更新或多步梦境模拟；没有用“Sleep”名称包装保存快照。

## 7. 本轮实现后的可证伪检查

依次检查：完整域等价与重复候选不增先验；前向实际策略与倾向；IPW 期望的精确枚举；softmax 更新的独立标量对照；TV 最坏效用界与累计 lease 预算；筛选/新验证隔离；shadow 预测先于观察并与标量计算相同；未采用不自动增长；Parameter/RNG 不变。

另做有限的新实际候选调度实验，而不是重跑 V211：在已知包含好/坏候选的控制场景，比较新混合调度与一次样本最大值锁定。它检验“候选已存在，是否更会使用”，**不是完整反馈网络学习能力或纯 RL 比较**。正负结果都保留，不预设新版本一定胜出。
