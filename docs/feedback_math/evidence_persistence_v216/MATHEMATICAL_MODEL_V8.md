# V216 数学模型：让证据决定应该多快改变经验判断

2026-11-11。先于本轮新网络与实验保存。V215的决策读出保持，不退回“历史预测权重=执行份额”。

## 1. 先限定已知原因

V215的selective_change/seed8，在训练120/123/127处分别出现错误动作偶然成功、正确动作偶然失败、正确动作偶然失败；H/F的观测似然比分别约5.19/9.54/22.82。128点时条件1的历史权重升到.543–.577，混合预测选错，而当前分支选对。

这定位了预测适用性的回摆，但不能仅凭轨迹断言全部由gamma或某一个参数造成。F的概率校准、样本有限与先验再开放共同参与。此轮先隔离一个具体数学假设：**为什么所有情境都以固定gamma=.02不断重新开放来源假设？**

不能简单设gamma=0然后称问题解决。gamma=0积累稳定证据更有力，但一旦规律真的恢复或改变，过去的大量证据可能导致反应过慢。因此需同时测稳定噪声和真实变化。

## 2. 新构造：多个证据持续性假设，不由人逐次判断噪声

保留真实H/F、当前预测学习、公开条件分组G及格c_G(x)。对每个格维护多个重新开放速率的假设：

    gamma_r in {0, .002, .02, .2}，初始rho_(G,c,r)=1/4。

这些是来源信念的持续性选择，不是真实环境每步变化概率的估计。0代表累计证据，较大值允许更快改变来源判断；包含原.02，并不是事后只留下本轮表现最好的速率。

每个速率有自己的H/F来源权重w_(G,c,r,e)。在新结果出现之前：

    w_tilde_(r,e)=(1-gamma_r) w_(r,e)+gamma_r/2
    p_(G,r)(y|x,a)=sum_e w_tilde_(r,e) p_e(y|x,a)
    p_G(y|x,a)=sum_r rho_(G,c,r) p_(G,r)(y|x,a)
    p_hat(y|x,a)=sum_G q_G p_G(y|x,a)。

其中q_G仍使用原先的复杂度先验和原分组预测更新。不同格可以获得不同速率权重，不能把某处噪声简单推广为所有情境都应保守或激进。

## 3. 三层更新都必须用行动前的预测

实际执行动作a_t，得到真正结果y_t后，只更新访问格：

    w'_(r,e) ∝ w_tilde_(r,e) p_e(y_t|x_t,a_t)
    rho'_r ∝ rho_r p_(G,r)(y_t|x_t,a_t)
    q'_G ∝ q_G p_G(y_t|x_t,a_t)。

最后才让F学习这条实际事实。多个假设解释同一事实，不是新增环境样本，也不是把模型脑补的结果当事实。

若持续稳定，频繁反转信念的假设要为自己的概率预测付出代价；若真实变化发生，快速假设可凭新的实际结果获得权重。**不是先判定“这是噪声/这是变化”，再按人工规则修改动作**。

输出的rate posterior只是这个有限模型内的预测相容性权重，不是“原因概率”，也不等于已识别真实变化点。有限的一串结果同时可能来自随机波动或规律变化，不能保证无延迟、无误报。

## 4. 预测与动作继续分开

历史预测份额为

    lambda(x)=sum_G q_G sum_r rho_(G,c,r) w_tilde_(G,c,r,H)。

它不直接控制动作份额。保持V215：Q_hat(a)=sum_y u(y)p_hat(y|x,a)，最大值利用+相同epsilon=.2普通探索。目标、H/F预测容量、原F内部时间算子和历史档案不改。

本轮不同时改预测概率的温度、F的平滑先验或噪声模型。这样可判断持续性层本身是否有帮助，不能把结果归给多项同时调参。

## 5. 能推导的保证与其代价

对固定G和格c，速率混合是规范的预序贯概率预测器。若L_r,c为某个速率在同一实际观测序列上的log-loss，则等先验混合满足

    L_mix,c <= min_r L_r,c + log(4)。

再对条件分组混合，对任一G及每格速率选择r(c)：

    L_all <= sum_c L_(G,r(c),c) - log pi(G) + C_G log(4)，

C_G为实际访问格数。不能把每格选择的复杂度错误地写成全局只付一次log4。

这是同一已观察动作序列上的预测损失界，不是不同策略真实收益界，不是零遗憾、安全保证或已校准变化概率。更细分组付出更高样本/状态成本；大量格只有少量经验时仍可能不稳。网格之外的持续性规律、连续条件和隐藏变量没有解决。

## 6. 必要的对照与否证

三个机制：原固定.02(V215)、固定0不重新开放的消融、四速率混合(V216)。所有组普通学习和探索，不冻结对照。

原4类固定基准各16seed只新跑固定0和混合，引用原V215记录。再增加一个事前规定的真实恢复场景：历史规律h；当前前128次为局部反转；从第129次训练起恢复h。该变化时刻/原因只给环境，不给模型，不清空F/门控。三机制都在此新场景首次执行，检验少误判是否以反应迟钝为代价。

同时报告实际训练、完整评估曲线，以及在相同已存状态上“当前分支正确但最终预测选错”的评价端诊断；不只挑seed8或只报告静态改善。正、零、负均保留，不能以公式界代替实际效果。

## 理论取用边界

在线变化检测可以维护变化位置等假设的不确定性，而非遇到单次异常就认定变化；参见Adams与MacKay的原论文[Bayesian Online Changepoint Detection](https://arxiv.org/abs/0710.3742)。本轮并非复现其run-length推断，也不声称提出了新的通用变化检测定理；这里实现的是条件格内有限来源持续性混合，并给出其自身的预测概率代数。
