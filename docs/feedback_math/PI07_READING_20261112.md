# π0.7 对当前反馈网络的启发

日期：2026-11-12。性质：原论文阅读与数学设计笔记，不是新实验结果。

## 1. 阅读来源与边界

- [π0.7: a Steerable Generalist Robotic Foundation Model with Emergent Capabilities](https://arxiv.org/abs/2604.15483)，重点 III、V、VI、IX-E 与讨论；[官方全文](https://www.pi.website/download/pi07.pdf)。
- [MEM: Multi-Scale Embodied Memory for Vision Language Action Models](https://arxiv.org/html/2603.03596v2)，重点 III-B、III-C。
- [π*0.6: a VLA That Learns From Experience / RECAP](https://www.pi.website/download/pistar06.pdf)，重点 IV-A、IV-B。

π0.7 用丰富条件组织混合质量经验；MEM 讨论不同时间尺度的记忆表示；RECAP 讨论真实经验如何进入策略改进。三者不是同一个方法，也不是我们的算法已被证明。

这组工作不能作为“完全无人工监督”的例证。π0.7 的质量和错误段包含人工标注；MEM 的语言摘要训练利用 LLM 辅助生成标签；RECAP 的优势来自奖励学习。也不能把 MEM 的局内上下文更新等同于跨任务参数巩固。

`core.py` 的 `node()` 存储前后标量观测、动作、事实和终止标识，不存历史图像；`MemoryView.arrays()` 从可用历史中抽取最多 64 个节点；`Network.encode()` 对节点做查询注意力聚合，没有跨节点相对时序编码。当前图像会进入网络，但历史视觉变化并未作为序列进入。因此，“存了历史”不等于模型获得了动作发生前后整段局势变化。节点内部有前后方向，不能据此又说网络完全没有时间信息。

当前网络已经有直接行动的 Q 头、事实预测和可学习记忆读取，不能说它完全不学习行动。额外试验选择则依赖标量 effect 差。它尚未显式学习“在何种经验条件下，哪些行动序列对应哪些实际结果”的条件行为分布。

这是可定位的数据表示与目标设计差别，不是已经证实的唯一性能瓶颈，更不证明增加新模块必然胜出。

## 3. 从数学上区分三件事（我们的推导）

### 3.1 事实与目标

一条已完成经历记为

\[
e_i=(o_{0:T},a_{0:T-1},g_i,y_i^{\rm obs}),
\]

其中 `g_i` 是当时任务目标，`y_i^{obs}` 是实际发生的结果与过程事实，不能把它替换成我们希望发生的结果。在线历史 `h_t` 只能包含决策时已经获得的信息。

预测问题是 `p(y | h_t,a)`；条件行为问题是 `pi(a | h_t,g,y)`；因果干预问题是 `p(y | h_t,do(a))`。三者不同。预测或条件拟合变好，不自动等于因果归因正确，也不自动保证控制收益。

### 3.2 一个可以检验的条件行为目标

不先增加大型语言模型或复杂世界模型。在当前离散动作环境中，可研究：

\[
\mathcal L_{\rm cond}(\theta)
=-\mathbb E_{e_i\sim\mathcal D}\sum_t
\log \pi_\theta(a_t\mid h_t,g_i,y_i^{\rm obs}).
\]

动作标签来自自己真正执行过的动作，不要求人额外提供“正确动作”；结果条件来自真实反馈。失败轨迹在失败条件下参与学习，不被冒充成功示范，也不因此自动增加惩罚。训练条件中可以使用已经完成的轨迹事实，因为这是回顾性条件拟合；部署只能传目标要求 `y^{req}` 或真实可见信息，不能传未来实际结果。

但这还不是完整解决方案：`pi(a | h,g,y=成功)` 可能偏向曾经碰巧成功的动作，且数据里没有的成功策略不会凭空产生。需要真实行动继续扩大经验，再检验策略改善，而不是把条件值设成“成功”就宣称解决了任务。

这种训练具有动作似然拟合的形式；即便数据来自自主交互，也不应把整个控制方法笼统称作纯自监督。事实预测可以自监督，控制目标仍须明确。F0 若采用任务事实/目标条件，应保持没有显式奖惩的定义；不能偷偷把原效用加权和改名为事实条件便称已做到。

### 3.3 不确定性不能靠命名消失

假设动作 A 只有一次幸运成功，而动作 B 经多次尝试大多成功。只按成功轨迹条件拟合可能过度模仿 A。需要保留全部尝试的条件与后果，并用后续实际试验检验。重复回放同一条经历不会增加独立证据数；新的随机结果来自新交互，而非又算一次旧损失。

如有可恢复的同一起点，可用配对实践比较候选；不可恢复时，应通过匹配初始分布的新对局比较。这里的任务效用比较属于评估或相应奖惩组，不能未经定义流入纯反馈组。不能把历史后验条件概率直接解释为“某因素造成失败的概率”。

## 4. 记忆网络的最小建模方向（尚未实施）

将近期连续观测编码为短时状态表示，再与跨段经验节点融合：

\[
s_t=E_\theta(o_{t-k:t},a_{t-k:t-1}),\qquad
c_t=\operatorname{Read}_\theta(s_t,g,\mathcal M_{<t}),\qquad
\pi_\theta(a_t\mid s_t,c_t,g,y^{\rm req}).
\]

这里的长期节点记录发生的事及其适用情境，不保存一个永远正确的行动答案；近期连续信息负责“刚才如何变成现在这样”。对我们的非 LLM 网络，节点可以是学习到的向量，不要求生成自然语言总结。短时状态和长期经验可以共享编码器，没必要先造许多审核网络。

这是借鉴多时间尺度表示的候选，不是复制 MEM。跨局记忆如何检索、条件行为如何适用，仍需通过本项目的实验判定。

## 5. 如何避免重蹈覆辙

1. 不把 π0.7 的机器人效果当成我们追逐地图的预期分数或保证；预训练、数据和能力基础不同。
2. 不同时换记忆、损失、动作生成器和训练预算后把全部差异称为“归因收益”。先比较同数据/同输入下的条件化学习，再单独测时序表示的增益，或在一次有限的二因素对照中明确拆开二者。
3. 不因喜欢自监督就取消有效学习目标，也不因论文使用人工标注就给本项目默认增加人类正确动作标签。
4. 不把 stop-gradient 一概视为错误：π0.7 的主干还有离散动作训练路径。要核对某条反馈能否训练到需要的参数，而不是机械地保留或删除隔离。
5. 现阶段重点是经验进入策略的方式，不是继续加审核器，亦不是先追求参数规模。
