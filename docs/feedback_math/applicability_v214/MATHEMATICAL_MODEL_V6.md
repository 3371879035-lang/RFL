# V214：历史提供条件性假设，新反馈学习适用性

2026-11-11；在网络实现和本轮实验之前保存。此版本不把旧经验一律否定，也不把它当成当前答案。目标是区分**经历是真的、过去的解释可能不完备、当前适用性还需证据**。

## 1. 先承认不可辨识的边界

设两个世界在过去所有已见数据及当前可见 x 上完全相同，但新结果核互为二元正确动作的反转。任何只依赖这些信息的算法，此时必须给出相同动作分布。若正确动作成功概率.9、错误动作.1，则两个世界下成功率之和为1，平均为.5。

因此不能保证第一次遇到新条件就知道旧经验还适不适用。相似度、时间权重、归因网络都不能凭空消除这个信息缺口。可做的是：保存未知状态、分配实际探索，收到新结果后改判。这个边界并不否定经验迁移。

## 2. 两类模型分开存放，不复制旧误差

事实记录 d_t=(id,x,a,y,mu,policy_id)。原始档案保留。结果标签只来自实际环境，不接收“模型认为原因是……”作为事实标签。

* H(y|x,a)：仅由实际历史前段学出的冻结历史预测器；冻结不等于其预测已被证明适用新情境。
* F_t(y|x,a)：以独立先验开始、用本段实际新事实正常学习的当前预测器。所有当前失败、成功都记录一次。

两者都使用同一公开关系语法、动作/结果空间。关系子集 S 的条件类别模型仍复用 V210 `TemporalRelation`，其值是结果分布，不是固定正确动作。

为避免由工程师指定哪个关系正确，关系头按事前 prior pi(S)∝2^{-|S|}/C(d,|S|) 混合，使用真实预序贯概率更新：

    v'_(S) ∝ v_(S) p_(S,t)(y_t|x_t,a_t)。

各头在读到新结果前预测，之后各把同一事实计数+1；多个假设读取同一事实不增加外部样本量。历史分支hazard=0，当前分支使用旧V210的B32、h=.05；对照另保留从历史连续运行的原时间组件。历史前段与当前段的边界由这次实验事前固定，不声称网络自主发现了任意任务边界。

## 3. 学的是“在什么条件下适用”，不是“某原因占百分之几”

考虑公开字段的各个子集 G，包括空集。c_G(x) 是该子集定义的情境格。每个格维护两个来源权重 w_(G,c,H/F)。新格先验各1/2；不按是否遇到完全相同状态直接判真/判假。

在实际结果到达前，对当前格作固定份额再开放：

    tilde w_(G,c,e) = (1-gamma) w_(G,c,e) + gamma/2，gamma=.02。

它允许先前被压低的解释重新得到检验，不表示真实环境每步有2%变化。这个变化时钟是格被访问的次数，不是墙钟时间。

每个候选分组的预测为

    p_G,t(y|x,a) = Σ_(e∈{H,F}) tilde w_(G,c_G(x),e) p_e,t(y|x,a)。

未知哪些字段决定适用性，再在分组上混合：

    q_1(G) ∝ 2^{-|G|}/C(d,|G|)
    p_t(y|x,a) = Σ_G q_t(G) p_G,t(y|x,a)。

收到真正的新 y_t 后：

    w'_(G,c,e) ∝ tilde w_(G,c,e) p_e,t(y_t|x_t,a_t)
    q'_(G) ∝ q_(G) p_G,t(y_t|x_t,a_t)。

只更新被访问格；**所有上述概率必须来自当前结果到达之前的H/F状态**。最后再让F学习这条事实。不能先拟合答案，再拿训练后的高概率给自己增加信任。

这是分组假设下的预测相容性权重。它不是“历史真实概率”、不是“因果责任比例”，也不是归因完整性的保证。H和F预测相同时，结果不能区分二者，权重不能解释为成功归功谁。遗漏关键观测变量仍可能无法辨别适用性。

## 4. 预测参考和实际行动份额也要分开

定义当前条件下历史份额

    lambda_t(x) = Σ_G q_t(G) tilde w_(G,c_G(x),H)。

令 pi_H、pi_F 是各分支对同一个目标效用u的epsilon-greedy策略（epsilon=.2），实际动作分布为

    mu_t(a|x) = lambda_t(x) pi_H(a|x) + [1-lambda_t(x)] pi_F,t(a|x)。

不能换成 argmax_a Σ_y u(y)p_t(y|x,a) 后还声称历史只控制lambda份额；argmax不保留份额语义。当前实现同时输出预测p和实际行为mu，各有明确用途。

这也不保证历史低权重就一定不伤害。对任意当前即时效用核，两分支同一x下有

    J(F|x)-J(mu|x) = lambda(x)[J(F|x)-J(H|x)]。

若F本身不熟悉环境，降历史权重可能丢掉正确经验。因此应同时测新情境收益和原有能力损失。当前五组都是有限研究中的实际在线学习，不是永久部署通过；没有新梯度参数更新或SLEEP巩固。

## 5. 能证明的范围

各分量均是规范概率分布，混合仍规范；在反馈到达前产生预测，整体构成合法的预序贯预测器。对于任一事前分组G及格内来源切换路径z，混合的序列概率包含该路径的非负项，因此

    累计log-loss(混合) ≤ 累计log-loss(路径) - log Prior(G,z)。

该比较条件于同一实际观测/动作序列，先验包含格内切换代价；不是不同策略执行不同轨迹的任务收益界，不是零遗憾、不是真实因果发现保证。网络结构先验、gamma和任务边界均是公开建模选择。

完整分组最坏指数增长。三字段检查包含8个分组/27个格；不是已解决连续/高维相似性学习。本轮不增加学得的相似度编码器，先检验最小的条件化适用机制是否产生预期区分。

## 6. 要用什么实验推翻或支持它

旧源码不重跑。新实际历史经均匀随机动作获取，不手工灌入正确候选/Q*；所有方法看到相同前段事实，拥有相同公开字段和关系头容量。

五组：原始全历史合并、只学当前、历史连续V210时间适应、全局H/F适用性、条件化H/F适用性。主要机制对照是最后两组；原时间组件是必要强对照，不能省略。

四类任务：新条件下旧规律仍有效；相同过去/相同新条件但规律失效；一部分情境失效另一部分仍有效；无信号。条件字段位置按seed置换，网络不知道哪个字段控制有效性。所有组正常学习，错误与成功都保留。

首先检查不可辨识双世界在首个新反馈前预测完全相同；再检验后续能否保留有用历史、减轻失效历史影响，是否把局部失效扩散到其他条件。保留失败/零/不利，不能只展示旧经验失效时的收益。

## 参考及取用边界

* Adams & MacKay, Bayesian Online Changepoint Detection: https://arxiv.org/abs/0710.3742 。已有时间适应处理序列规律变化；本轮针对情境适用性增加另一层，不假称原方法没有变化处理。
* Peters et al., Invariant prediction: https://arxiv.org/abs/1501.01332 。跨环境可用的关系需要条件与假设；本轮没有实现其因果识别方法，不把预测门控权重称为因果结论。
