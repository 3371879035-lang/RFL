# V214 当前模型检查：历史是否被直接当成答案

2026-11-11。先检查、推理，再实现。实际 HEAD d0edad11137a117f45ab94f5f10cf6f045a61ac3；旧文件不改。

## 实际发现，不把用户的质疑改写成用户反对历史学习

1. **没有发现旧残差直接加回当前输出的实现。** 当前 V210 的输入 Fact 是条件、动作、实际结果、倾向与身份（network.py:19–26）；条件计数按真实结果更新，并非读取一条“归因结论”作为标签。当前归因解释不是一个已完成、已验证的因果发现器，不能声称发现了真正原因。
2. **旧模型不是完全没有适用性处理。** V210 `TemporalRelation` (:85–116) 已有分段起点的预序贯更新。不能为突出新版而说旧版永远盲信历史。
3. **历史可比性仍依赖隐含假设。** V210 按结构 S 投影条件并计数（:94–101）；相同投影的不同完整情境被汇总。若被省略的字段改变结果，这些旧统计不能自动迁移。最早起点的支持数是全档案支持，不等于当前情境下有效支持。
4. **时间权重不是情境适用性权重。** 对一个结构，V210 的 log_weights 只有起点维度，同一结构下不同条件共用。一个局部情境失效会影响其他情境的时间假设。
5. **V213 调度也是全局的。** `TrialMixture.log_weights` (:122)、`_parts` (:142–147) 使用一套候选权重覆盖所有输入；observe (:180–184) 更新这套权重。它能调整候选总体分配，不能单独表达“在A条件继续用旧经验，在B条件重新学”。全域行为去重也不等于经验适用性证明。
6. **降预测权重不等于降行为依赖。** 原 `FrozenCandidate.act` 取加权预测 argmax。如果旧预测给动作1价值.9、当前分支两动作均.5，即使旧权重只有.01，混合后仍固定偏好动作1。不能把较小的预测权重误称为只少量依赖旧行为。
7. **V213 的局部实验没有验证此问题。** 它用预编译候选隔离调度，并非从实际旧经验学出模型后验证新情境迁移；不能把其结果外推为“历史适用性已解决”。

## 本轮修正目标

保留实际历史，也保留它可能不适用于当前条件的可能性。增加**由新实际结果学习的情境适用性**；同一条历史规律在不同情境可获得不同使用份额。模型不知道哪个字段是真正关键，只能在公开字段的候选分组中学习。归因仍是预测适用性假设，不是原因概率。

保留旧时间适应实现作为实质对照，而非只比较一个不会适应的弱基线。增加两种拥有完全相同过去、相同首个新输入却有相反新规律的环境，验证模型不能在尚无新反馈时凭空识别哪种经验仍有效。
