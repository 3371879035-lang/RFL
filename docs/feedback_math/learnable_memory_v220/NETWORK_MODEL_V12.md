# V220 神经网络与训练准备

本轮先构造能力的学习基础，不直接训练到会用。不继承V219解析手工先验作为答案，也不把V219固定先验成绩与新随机初始化成绩排名。

## 模块

| 模块 | 输入 → 输出 | 留给训练的内容 |
|---|---|---|
| 原始记忆库 | 实际观察、动作、预测、结果、来源、身份、前驱 | 不学习事实身份，不复制回放为新事实 |
| 事件编码/记忆注意力 | 唯一事实节点、前驱关系 → 当前参数下的节点表示 | 经验表征与关联 |
| 条件读取 | 当前观察/目标/合法动作 × 记忆 → 读取与适用性门 | 何时参考、何时不参考旧经验 |
| 共享混合预测器 | 当前条件/记忆/动作 → 后继与反馈分布 | 预测、条件方差、动作间模型分歧 |
| Actor | 条件状态、联合比较特征、控制码 → 动作分布 | 怎样用反馈和不确定性选择动作 |
| Proposal | 失败之后的条件记忆 → 数值候选控制码 | 可尝试的行为变化；不是文字推理或确定归因 |
| TrialManager | 候选、当前条件、剩余试验预算 → 保持/试哪一个 | 是否值得付出实际交互成本 |
| Adopter | 候选、真实试验记录 → 保持/采用 | 如何根据实际结果选择，不写死成功阈值 |

候选码不进入物理后果预测器：同一观察/历史/动作的预测不能因为“换个想法”就自证改善。候选会影响Actor，因此会改变实际采取的动作；之后才以实际结果判断。采用指切换控制码，不是修改神经参数。

## 可以训练但尚未训练

所有编码、注意力、适用性门、预测头和决策头均为可训练PyTorch参数；默认192宽、2层记忆注意力、8共享假设、3候选码。实际参数量由运行统计。规模可配置，不以节省参数限制这次建模。

`factual_nll`基于历史前缀和实测后果训练条件分布；`off_policy_loss`提供记录选择概率的策略梯度接口，可用于动作、试验选择、采用选择；`replay_distillation_loss`只把有来源的教师分布当巩固目标，教师停止梯度。实际任务记录与试验决策均保留选择概率。它们是损失接口，不是已经完成的数据调度、可靠离线RL或SLEEP算法；重要性比率的方差、行为支持不足仍需真正训练阶段处理。

成功经历保留为普通训练样本，但不新增失败反思调用。历史回放只取事件之前的记忆前缀，事件后果作为目标。多次epoch不会扩增真实交互数量。参数改变后重新编码原始记忆，不缓存旧编码后冒充新参数的证据。

## 本轮有限检查

数学与接线检查、一次无优化器的12个小向量环境运行。3初始化种子×稳定/变化/噪声/缺失反馈4类，每run16主任务，失败后至多1实际试验。是否试、试哪一个、是否采用由当前网络分布采样，不替它筛好方案。预算上限只是实验资源边界。

这些环境不是游戏适配，不使用原地图、健康Q*或隐藏最优动作标签作为网络输入。当前向量接口也不是通用文本/图像理解。分支实际执行、节点可追溯、梯度连通，只证明结构基础可运行；有效归因、校准、智能试验、长期巩固和跨任务迁移仍须后续训练检验。

## 已知限制

- 神经适用性门没有因果语义保证；注意力不是原因百分比。
- 混合高斯是假设，不能天然覆盖任意离散/多峰/重尾反馈。
- 共享潜在分量的跨动作耦合不能仅靠单一选择动作的观测完全识别。
- 原始记忆不设固定删除阈值，但当前注意力成本为O(N²)，还没有长历史伸缩结论。
- 当前想象只生成一步独立预测对象，不把它当实际经验；没有声称完成大量多步梦境规划。
- 候选采用不改参数。未来权重更新需要明确的训练、验证与回滚流程，不能把一次好试验当普遍有效。
