# V220：可学习的反馈—记忆—实践网络

2026-11-11。本文件先于本轮代码与实验。用户明确允许扩大参数，并要求为后续训练创造基础；本轮不再限定在V219的80个先验参数上修补，也不把新随机初始化网络冒充已具备成熟能力。

## 1. 必须固定的事实边界，与应交给训练的判断

固定的是数据语义：真实事件身份、时间先后、缺失掩码、来源、实际执行记录、候选不能充当事实。它们不是任务解法。

由参数学习的是：怎样编码事件、检索哪些记忆、经验在当前条件是否适用、预测后果、如何使用不确定性、生成候选控制方案、是否花预算试验、实践后保留哪一方案。不得固定“相似就照搬”“不确定就禁止行动”“试验一次成功就永久采用”等规则。

## 2. 记忆节点是可追溯事实，不是旧答案

事件e_i包含唯一id、此前节点、观察x_i、实际动作特征a_i、后续观察x'_i、事实反馈f_i及掩码、行动前预测与掩码、目标g_i、来源、成本和公开终止信息。人的/工具的反馈也是观察到的信息，来源标签不代表其断言必然正确。

原始记录只存一份。神经表示每次由当前编码器重算：

    m_i = Encoder_theta(e_i, Encode(previous_i))
    M = MemoryTransformer_theta(m_1,...,m_n)。

查询只看当时已知的前缀。缺失与数值0区分。全历史不因固定槽数被删除；当前有限实验使用全部可见节点。长期存储是可恢复的原始事实，节点编码/注意力可训练。不存在必须枚举所有离散字段子集的关系表。

重复id、重复回放与重复读取不能扩增事实数。同内容不同真实id仍是不同事件。潜在假设、想象轨迹、记忆表示不能作为新的实际事件写入事实库。神经网络内部多层使用同一输入并不等于多份独立统计证据；身份去重不声称已证明所有学得表征统计独立。

## 3. 经验适用性与联合不确定性

对当前观察/目标和每个合法动作形成查询q_a。可训练相关性和适用性决定读取：

    r_(a,i) = softmax_i(score_theta(q_a,m_i))
    g_(a,i) = sigmoid(apply_theta(q_a,m_i))
    h_a = Fusion_theta(q_a, sum_i r_(a,i) g_(a,i) V_theta(m_i))。

g不强制加和为1，也不叫原因概率；注意力也不是因果证据。保留无历史的查询路径与空记忆节点，让模型可以学会不依赖不适用的记忆。

预测采用共享潜在成分K：同一个k同时定义所有动作的可能后果。混合权重pi_k依赖当前观察/目标与可见记忆，不逐动作独立选择k。各成分预测后继观察、事实反馈和目标价值，并给出条件方差。

    E[U_a] = sum_k pi_k mu_(k,a)
    Cov_model(U_a,U_b) = sum_k pi_k (mu_(k,a)-mean_a)(mu_(k,b)-mean_b)
    Cov_total = Cov_model + diag(sum_k pi_k sigma²_(k,a))。

最后一项明确假设给定k时剩余行动噪声独立；不是世界事实。动作差值方差包含-2Cov项，不能把两个边际方差直接相加。

若分量内采用Gaussian，则模型内比较概率为：

    Pr(U_a>U_b) = sum_k pi_k Phi((mu_(k,a)-mu_(k,b))/sqrt(sigma²_(k,a)+sigma²_(k,b)))。

这是候选模型内的量，不自动得到真实置信覆盖或原因归因。动作策略由可训练Actor读取h_a、候选控制码、均值、方差和联合比较特征，不硬编码固定风险惩罚或仅取价值均值argmax。

自比较a=a的比较分数约定为0.5（平局分数），不是严格概率Pr(U_a>U_a)；同一动作与自身的差值方差为0。分量之间的离散程度仅称模型内分歧，不直接冒称贝叶斯参数后验或可识别的认知不确定性。仅观察每次选择的动作，不能自动识别所有跨动作反事实耦合；共享k也是建模假设，须在后续实践数据中检验。

无历史时的预测由可学习的查询路径和空记忆节点给出，这是可训练的起始预测，不是事先灌入健康Q*的答案。当前历史只作为一个去重上下文进入条件分布，不再逐条把同一历史更新后的后验当新先验乘回去。它减少显式重复证据加权，但不保证未来训练不会过拟合或学出重复相关性。

置信度不采用只能变保守的修正规则。以单高斯为例，记v=exp(s)、误差e=y-mu，则：

    d L_NLL / d s = (1-e²/v)/2。

实际误差小于预测方差时，梯度下降可缩小v；实际误差较大时可增大v。混合情形由分量后验责任加权这一梯度。条件编码器决定在哪些情境共享这个更新；数学上有双向学习能力，不等于当前随机网络已经校准。未来仍要使用独立验证记录评估NLL、覆盖率和决策损失，而非只让历史内训练误差变小。

## 4. 候选与实践

失败后的候选z_j由记忆条件化的Proposal网络生成；是数值潜在控制码，不是LLM文字反思，也不声称已找到原因。它改变Actor的行为倾向，不得直接改写世界预测器对同一观察/动作的后果预测，否则会产生“换一个想法，想象中的世界就变好”的自证循环。

可训练TrialManager选择保持或试验哪个候选；实践通过外部环境执行器真正执行动作，反馈写入事实库，费用照实计算。Adopter根据当前上下文、候选和对应真实试验记录评分。

只有经过实际实践且身份一致的候选才有资格成为当前控制码；这是“证据必须来自实践”的边界，不是“成功才采用”的固定判分规则。是否保持、采用哪个、如何看待负结果由网络学习。本原型的采用是切换行为控制码，不是直接修改网络权重；参数训练是另一个明确步骤。

想象接口返回独立的ImaginedTransition，只提供预测后果/不确定性，不写事实库。多步真实规划或完整SLEEP算法本轮不冒称完成。

## 5. 训练目标与回放

每条训练样本的输入是事件发生之前的记忆前缀，目标是之后实际观察到的反馈与后继状态。混合模型的联合NLL先在同一k内累积已观察维度，再对k做一次logsumexp，不能每个反馈维度分别挑一个有利k。

    L_fact = -log sum_k pi_k p_k(observed feedback, next observation, optional value | prefix,x,a)。

Actor、TrialManager、Adopter有可微分类/策略损失接口；实践数据需保留行为概率。对实际选择动作可用带行为概率的策略目标，或采用有明确来源的教学目标；不能用评价器隐藏最佳动作当标签。本轮只检查这些梯度路径，不执行优化器训练。

回放/巩固从已有真实事件构造prefix→outcome训练对。重复epoch允许优化参数，但不产生新环境样本、不复制事实节点；先验/表示改变后重新编码旧事实，不把旧后验作为新独立证据。真正训练仍需独立验证与未用于选择的任务；无训练不能声称学会记忆适用性、归因、试验价值或通用品味。

## 6. 本轮范围

默认采用较大的可配置网络：宽度192、两层记忆注意力、8个共享预测成分、3个候选控制码，参数由实现实际统计，不设“必须只有80个”的约束。动作数量、记忆长度可变；观察/动作/反馈向量维度由schema配置，不做游戏专用适配。向量接口不是已经具备文本/图像理解。

实验检验：联合协方差公式、未来信息隔离、去重/回放、参数可训练性、所有模块梯度、候选—真实实践—采用归属、想象不充当事实，以及小规模真实闭环。随机初始化成绩仅用于发现接线问题，不和已构造先验的V219宣称性能优劣。

参考：[End-To-End Memory Networks](https://arxiv.org/abs/1503.08895)说明可学习外部记忆的一类架构；[Conditional Neural Processes](https://proceedings.mlr.press/v80/garnelo18a.html)提供学习条件化预测的相关思想。这里是本地组合设计，不冒称论文复现或原论文已证明本模型能力。
