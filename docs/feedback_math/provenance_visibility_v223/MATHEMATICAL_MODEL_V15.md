先于新代码执行保存。本轮不训练参数；修复 V222 已指出的语义重复与想象反馈全可见问题。保留 V222 及其失败，不重跑旧环境流。

## 1. 不能凭数值相似推断信息相同

基本信息单元为 (event_id, primitive_id)。当前观察、实际动作、后继观察、公开 goal_met/terminal 已有独立身份。反馈字段可以是新的基本测量 u，也可以是已有结果的确定视图 v=T(y,x,a)。

    p(y,v | H) = p(y | H) delta[v=T(y,x,a)]。

对已声明且可核对的派生视图，只验证一致性，不再添加独立似然项。加入一个重复显示字段，不改变实际基本信息、记忆特征、世界似然或候选分布。不同来源的基本测量即使数值相同也不合并。

来源声明是数据接口事实，不是模型推测的因果解释，更不规定哪个动作好。未知语义不自动去重；须保留为不同测量，并学习其相关性。本版支持公开基本量的线性视图；新反馈基本量必须有直接可读字段，未支持一般非线性视图识别或逆问题。

记忆同时保存原始回执与规范化视图：原始事件可审计；网络输入只含一次基本反馈值、其可见性、原始已有结果和事前预测。相同 ID 冲突拒绝；重复显示不成为重复事实。

## 2. 观测模式也是要学习的变量

对每个持久假设 k 和当前条件 z=(H,x,a,h^k)，设 m 为新反馈基本量的可见性；d 为公开终止；g 为公开即时目标达成；y=(x',u) 为连续基本量。

    p(m,d,g,y | z,k)
      = p(m | z,k) p(d | z,k,m) p(g | z,k,m,d)
        N(y ; mu(z,k,m,d,g), L L^T)。

这是观测分布的因子分解，不表示 m 导致物理结果。m 在本假设内采用多 Bernoulli，k 的混合允许部分相关；d/g 是条件 Bernoulli，连续向量使用可训练的完整 Cholesky 协方差，不将相关的新反馈强行当作独立噪声。

实际训练只知道 y_O，其中 O 为后继观察坐标与 m=1 的反馈基本坐标。使用正确高斯边缘：

    ell_tk = log p(m_t | z,k) + log p(d_t | z,k,m_t)
           + log p(g_t | z,k,m_t,d_t)
           + log N(y_O ; mu_O, (LL^T)_OO)。

不是把缺失坐标补零后当成真实监督，也不是把完整高斯精度矩阵简单裁剪。序列仍只在末尾对固定 k 混合：

    L = -logsumexp_k [log pi_k(H) + sum_t ell_tk]。

参考：Little 的 [pattern-mixture 模型](https://www.tandfonline.com/doi/full/10.1080/01621459.1993.10594302)提供按缺失模式建模的统计视角；[not-MIWAE](https://arxiv.org/abs/2006.12871)研究缺失机制与深度生成模型的联合处理。本轮不是复现这两者，也不声称仅靠不完整观察就识别了未观测分布或真实缺失原因。

## 3. 想象不获得现实中看不到的信息

想象依次抽取 m、d、g 和完整连续样本；但只把 (x', m*u, m, g, d) 传给世界 GRU、思考 GRU和后续策略。未观察反馈采用占位 0 并伴随 mask=0，0 不是一次观察。模拟节点只保存可见反馈，隐藏抽样值不写入节点/事实库。

    h_next = GRU(h, x, a, x', observed_u, m, goal, g, d)。

物理连续样本用 Cholesky 相关采样。共同噪声用于同起点的候选条件比较；同一候选、同一深度跨假设共享动作，保持 V222 不偷看 k 的边界。模拟仍不是实际采用证据；新候选仍须实际执行。

## 4. 预测表示与训练

Actor 使用基本结果的模型预测，不使用重复显示字段。为避免对所有 2^P 可见性模式枚举，前向预测使用固定、保存的有限 uniform 节点近似 m 的边缘，再对二元 d/g 做四项精确求和，输出基本结果均值/协方差。它是数值近似，不是新增经验或精确已校准的概率。模拟本身则采样一条合法的完整生成路径。

派生反馈预测通过同一声明映射投影；不为副本另设独立证据头。候选生成器只读取规范化基本预测，添加别名不会扩大候选输入。世界参数只从实测目标获得梯度；决策梯度仍不修改物理预测器。

扩展宽度到 320、记忆工作节点到 96；假设/候选数可配置。扩容是容量安排，不是能力证明。

## 5. 本轮验证及不能声称的事

- 重复视图/别名不改变规范记忆、序列损失与候选输出；伪造来源关系被拒绝；独立同值基本量不被合并。
- 用完整协方差的观察子矩阵求边缘；单条目标在每个假设下只出现一次。
- 变化未观察反馈不能影响实际损失、后续工作状态或模拟记录。
- 可见性、条件终止/达成、相关连续结果均有实测训练梯度；世界与决策路由仍隔离。
- 小规模真实回合连接到有缺失反馈的内部推演和真实试验；无参数更新。

仍不等于自动理解任意文本反馈、学会因果归因、在从未观测区域保证正确插补、长期推演可靠、SLEEP 训练完成或泛化有效。新鲜数据/留出验证和以后训练将检验这些能力，而非写规则预先保证。
