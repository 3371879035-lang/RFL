# V215 数学推理：预测参考权重不是行动执行份额

2026-11-11；先于本轮新网络与新实验保存。只修V214暴露的决策连接，不假称经验适用性或因果归因已经全部解决。

## 1. 从已执行反例出发，而不是增加一层固定规则

V214用真实新结果学习条件适用性，已经能在不同条件下给历史不同权重。但随后强制实际策略 mu=lambda*pi_H+(1-lambda)*pi_F。整体旧规律失效的已存记录中，当前分支已经选对、历史分支选错，末点评均lambda=.06051753774948417；这个强制策略混合造成相对自身F约.03873122416的条件期望损失。

原gamma=.02的再开放给预测历史至少.01权重；不应因此推出历史必须获得至少.01行动控制权。保留某个解释和服从某个解释是不同数学对象。

必须纠正一个容易走偏的解释：V214发现“少量预测权重经过argmax仍可能决定动作”并不证明argmax错误。当另一个来源没有区分信息时，微弱的历史信息也可能是当前最好的线索。真正错误的是把**预测权重**描述为**执行份额**。为了强制实现份额语义而随机混合两策略是一个额外设计，不是必需条件。

## 2. 保持有效的条件预测部分不变

保留原档案、历史预测H、当前预测F_t、所有公开条件分组G、条件门控更新、gamma=.02、epsilon=.2和目标u。预测为

    p_hat_t(y|x,a) = lambda_t(x) H(y|x,a) + (1-lambda_t(x)) F_t(y|x,a)。

lambda仍由前结果的H/F预测与之后真实观测的相容程度更新。它不是因果责任概率、不是“应该执行历史动作的概率”。gamma只继续作用于预测假设的再开放，旧经验无需删掉。

## 3. 动作由候选后果决定，不抽签服从某个来源

对每个合法动作计算同一公开目标下的预计结果：

    Q_hat_t(x,a) = sum_y u(y) p_hat_t(y|x,a)
    a_hat_t(x) = argmax_a Q_hat_t(x,a)
    mu_t(a|x) = (1-epsilon) 1[a=a_hat_t(x)] + epsilon/A。

这里的Q_hat是一次预测读出，不是导入Q*或额外训练的Q学习头。相同的普通探索保留，各动作仍有epsilon/A真实试验机会；不再额外保留“为了照顾历史而执行历史”的份额。

对于当前预测分布，a_hat最大化预计目标；因此

    E_(a~mu_new)[Q_hat(a)] >= E_(a~mu_old)[Q_hat(a)]。

证明：两方法的均匀探索项相同；新方法利用项是max_a Q_hat(a)，旧方法利用项是两个动作对应Q_hat的凸组合。这个不等式只针对同一时刻、同一个预测分布；不是实际真实收益一定提高，更不是长期跨策略轨迹支配。

## 4. 为什么能消除上轮的结构性残留损失

两个候选动作h/f，定义当前分支对f相对h的预计优势Delta_F，历史分支为Delta_H。新策略的判据为

    Delta_mix = (1-lambda) Delta_F + lambda Delta_H。

若Delta_F>0、Delta_H<0，选f的条件是

    lambda < Delta_F / (Delta_F-Delta_H)。

对上轮对称反例，Delta_F=.8，Delta_H=-.8，阈值为.5。lambda=.0605不会再要求执行6.05%的历史策略；普通探索相同，预计/真核上的策略值可回到.82。原.01预测再开放不再推出额外.0064的行动损失下限。

这不是给模型塞入“.5阈值的正确规则”：网络对每个动作直接比较预测的结果效用；一般情境中优势和阈值不同。

若F对所有动作都中性，少量H可能决定当前最优候选。此时应输出小的预计优势，而不是宣称该动作已被实践证明。新条件不可辨识的边界仍在，不能凭空保证首次行动正确。

## 5. 错误历史仍可能教偏：能推导什么，不能推导什么

设真实同条件动作值Q(a)，delta=max_a |Q_hat(a)-Q(a)|，则

    Q(a*)-Q(a_hat) <= 2 delta。

由Q(a*)<=Q_hat(a*)+delta<=Q_hat(a_hat)+delta<=Q(a_hat)+2delta得到。u在[0,1]时，加共同epsilon探索后，相对真实最优确定动作的单步期望差不超过2delta+epsilon。

这是条件代数界。delta在真实任务中未知，本轮不把它或小margin当成已校准置信度。错误/过度自信预测仍可导致错误行动，长期原因遗漏和高维相似性也没有因此解决。
