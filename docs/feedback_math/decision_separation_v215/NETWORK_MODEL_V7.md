## 不加深网络，先修决策连接

复用V214的关系编码、H/F预测、条件门控和事实更新，旧文件不改。新增独立`DecisionSeparatedNet`及固定`ExpectedUtilityReadout(nn.Module)`。

    真实历史 / 当前事实
        -> 原关系Linear/ReLU与统计状态
        -> H(y|x,a)、F(y|x,a)
        -> 原条件适用性门控
        -> p_hat(y|x,a)
        -> 固定效用Linear读出 Q_hat(x,a)
        -> argmax利用 + 同一epsilon普通探索
        -> 实际结果 -> 原预序贯更新

效用读出参数为公开u，不随机初始化、不优化训练、不引入Q*。原源策略混合仅作为诊断输出，不执行。预测历史份额lambda不再被命名或解释为行动份额。

输出：原预测、实际行为概率、历史预测份额、H/F预测、动作预计效用、预计最优/次优差、仅供比较的旧混合策略。margin明确是估计而非已验证置信度。保留原完整档案、当前模型计数及冻结H检查。

主要可验证结构性质：给定同一个网络状态，新旧预测和lambda必须相同，只有行为读出改变；人为提供同一组真实格式事实后，两个预测模型的状态仍相同。这隔离决策算子，实际运行时不同动作当然可能导致不同未来训练数据。

全有限类别结构仍不等于连续/高维通用深网，不增加未经验证的复杂相似度编码器、因果概率头或安全阈值层。只读评估与事实学习分开。
