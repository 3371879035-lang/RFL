# 试用证据的第二个问题：不能用“少误采纳”掩盖低检出率

2026-11-10，在 V210 首次 18 项检查完成后提出。原数学文档、网络源码和首次检查不改。本补充先推导，再以独立标准库程序做有限概率核算；不是新环境试验。

## 1. 八对试用的信息本身可能不够

考虑一个明确的算术例子，不断言它就是 V209 的配对分布：旧、新策略结果独立，旧成功率 0.5。

* 零效应：新策略也为 0.5，\(D\in\{-1,0,1\}\) 的概率为 \(p=(.25,.50,.25)\)。
* 真改善 0.2：新策略为 0.7，\(q=(.15,.50,.35)\)。

任何只使用 \(n\) 个差值 D 的采用检验，若误采用概率不超过 \(\alpha_1=.025\)，希望真改善时采用概率至少 \(\beta=.8\)，数据处理不等式给出必要条件

\[
nD_{KL}(q\|p)\ge d_{bin}(\beta\|\alpha_1),\qquad
d_{bin}(b\|a)=b\log(b/a)+(1-b)\log[(1-b)/(1-a)].
\]

证明：独立差值序列的 KL 为 \(nD_{KL}(q\|p)\)；是否采用是序列的一个二元函数，经过此函数 KL 不能增加。若真实采用概率至少 .8、零效应采用概率至多 .025，二元 KL 下界由边界值给出。

允许在最多 n 对以内提前停止，仍可视为对完整 n 对序列的一个函数，所以上述必要条件仍成立。它不是充分条件，也不是给当前算法的实际检出率保证。若保留完整四种配对结果而不仅是 D，信息量可能更多；共同随机数也会改变 D 分布。不能把这个具体下界当成所有任务的统一最少次数。

## 2. 同时报告检出率和成本

对 V210 已固定的四投注混合，在 delta=0 时，证据仅依赖正差数 \(n_+\)、负差数 \(n_-\)：

\[
E^+(n_+,n_-)=\tfrac14\sum_{q\in\{1/4,1/2,3/4,1\}}(1+q)^{n_+}(1-q)^{n_-}.
\]

反向证据交换 \(n_+,n_-\)。令 \(m_t(i,j)\) 是第 t 对后、尚未停止且正负差次数为 i,j 的概率质量。按照 \(p_- ,p_0,p_+\) 递推，把达到正/负阈值的质量吸收到相应停止状态；在固定预算耗尽处留下 unresolved。

这是一种有限状态概率计算，不抽随机样本，不产生“实际试验次数”。同时输出：

* 采用概率（零效应下即错误采用概率）；
* 低于成本门槛的判定概率；
* 预算耗尽仍未决定的概率；
* 期望使用配对数。

预先固定三种分布：新成功率 .5 / .7 / .9，旧均为 .5且双方独立；最大配对数为 8 / 32 / 64 / 128。alpha 总预算 .05，只考察第一个候选的 .025。其他候选错误额度更小，不能借用本表。

## 3. 决策含义

若小预算下多数真改善都 unresolved，就不能宣布“新的采用机制更好”。它可能仅交换了错误类型。当前网络把最大试用预算作为明确输入，没有继续把 8 对写死，也没有把 unresolved 当成候选无价值。

本核算不自动授权无限试用，不选择某个参数为正式全任务规则。下一次实际比较必须在共同交互预算下报告实际效果、遗漏收益、误采用、结构搜索/历史重读/真实试用成本。风险中性价值最优分配与错误概率控制仍是不同目标。
