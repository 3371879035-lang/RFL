# V210 神经计算结构：公式到实现的对应

本文在网络源码之前保存。定位：**固定解析神经算子 + 显式可更新事实状态 + 序贯试用决策**。不是随机初始化后假称已训练好的通用大网络。

## 1. 公共接口

一条 `Fact` 只含顺序 ID、有限类别历史字段、实际动作、结果类别、已知行为倾向和行为策略 ID。没有任务家族、正确关系、隐藏规律或反转时刻。类别数、动作数、目标结果效用是显式任务接口；通用的是处理机制，不是无须输入表示就解决任意问题。

`observe` 只增加事实状态；记录顺序明确。不接 evaluator 真值或模拟结果。程序类型不能证明一条调用确实来自外部世界，真实实验适配器必须另存原始交互；本轮算子检查的人工输入明示为人工输入，环境回合数为零。

## 2. 四块结构

### A. `RelationLift(nn.Module)`

输入 `[batch, sum(cardinalities)]` one-hot；解析 `weight[cells, input]`、`bias[cells]`；输出 `ReLU(linear(x))`。每块是一个任意阶结构。所有 Parameter `requires_grad=False`。新增结构创建新模块，已存在模块的参数不改；这叫解析结构展开，不叫梯度学习。

### B. `TemporalRelation(nn.Module)`

状态 buffer 为 `counts[start, cell, action, outcome]`、`log_weights[start]`。每次预测使用 `einsum` 从关系激活读取各起点的条件分布，再按 `softmax(log_weights)` 混合。单位 Dirichlet 平滑与真实支持量分开，不能把未知写成已知失败。

实际更新顺序：边界时先增加新段先验 → 计算当前结果的预测概率 → 更新混合权重 → 每个假设对应计数加一。跨假设多份计数是不同解释，不是额外实际回合。存储增长约为 `O(starts * cells * actions * outcomes)`，不隐瞒这一成本。

### C. `AdaptiveFeedbackNet(nn.Module)`

保存完整事实列表及 ModuleList；结构前沿从一阶向上推进，但没有固定二阶或三阶终点。`grow(cell_budget)` 消耗关系单元预算，为新结构重读已有事实；记录重读条数和构建时间。现有结构通过新事实增量更新。

`snapshot(goal)` 输出冻结候选：复制神经模块及概率状态，通过同一神经前向计算 `argmax_a E[u(Y)|x,a]`。不是把所有可能输入的答案表硬编码到执行路径。预测目标作为明确输入，不把奖惩学习过的 Q* 塞入网络。

排序使用冻结候选之后的新事实集和真实行为倾向；只是提名，不改变现役策略。结构展开时不读取候选任务的隐藏原因。

### D. `EvidenceBook` / `PairedTrial`

非神经统计控制器：冻结策略身份、目标、未来使用次数/切换成本、最大配对数；接收新的配对结果，按数学模型 V4 第 5 节累计对数证据。编号跨候选单调递增，历史记录/同一对/同一外部观测 ID 不能再次用于新证据。

结果为 `continue / adopt / not_worth_cost / unresolved_keep`；身份相同直接 `same_snapshot`，成本不可能回收则 `cost_dominates`。不同快照散列不等于行为一定不同；不伪称散列能判断所有状态下的策略等价。

`respond_to_trial` 仅在本网络发出的固定参考/候选试验结束后：采用则替换现役快照，不采用则可按本次明确预算展开下一批结构。候选、试用记录和被拒绝的事实仍保存。新增结构不是采用证明，实测才决定是否替换策略。

## 3. 学习对象与禁止混淆

| 对象 | 本轮能否改变 | 含义 |
|---|---|---|
| 现有解析神经 Parameter | 否 | 不更新数值权重 |
| 结构 ModuleList | 能，按单元预算 | 新增表达假设 |
| 事实计数/时段权重 | 能 | 用结果更新显式记忆和适用性 |
| 现役策略快照 | 能，经独立试用证据 | 可调用行为改变 |
| 学习到的权重/SLEEP 蒸馏 | 否 | 本轮未实现/未执行 |
| 正式任务采集、旧 V209 实验 | 否 | 本轮只有有限算子检查 |

## 4. 最小检查而非新大实验

检查矩阵：类别联合激活、预算前沿无跳跃、三元奇偶表达反例与扩展、真实计数/IPW 分离、时间过滤对标独立标量递推、同动作跨假设混合、全历史保存、冻结快照不受后续事实影响、离线排序不泄漏、证据乘积/可选停止/多个候选分摊、试用成本、闭环触发、参数/随机状态不变。

这些是人工可知答案的数学和算子输入，不复用 V209 raw、训练银行或生成器。用精确枚举的零效应试用序列检查错误采用逻辑，不把它说成新实际环境训练。

下一次任务实验需要比较结构增长、时间适用性、序贯试用各自的收益和成本；尤其要测小收益遗漏率、变化后的实际响应延迟、结构搜索开销，而不只看是否少采用零效应候选。
