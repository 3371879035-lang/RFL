# V225：训练与行动共用同一个真实历史条件模型

先推导后实现；本轮参数更新 0。修复的是可学习基础，不宣称已经训练出更好的策略。

## 1. 已定位的断点

V224 继承的真实序列似然，从片段开始前的历史初始化一次，再逐事件更新 `belief_update`，一个潜在分量 k 贯穿该序列。实际 `forward` 却每一步调用 `root(当前观察,全部历史)`，重新初始化 h 和分量权重。因此：

- 已训练的多步条件模型没有按同一递推路径用于行动；
- 后续前向没有使用与序列似然一致的分量后验；
- 中段训练片段把起点当新根，也不等于完整序列模型的条件似然。

这不是声称旧网络完全没有记忆：旧网络确实读取全部历史。问题是**训练的递推条件分布和运行的重初始化分布不是同一个**。源代码证据为 V223 `losses.sequence_nll`、V222 `root`、V223/V224 `forward`。旧代码、已执行结果及其有限结论不改。

## 2. 区分历史参考与本段新证据

一个真实连续 episode 的历史分为不相交两部分：

    H_before：该 episode 第一个实际动作之前的事实节点
    E_0:t-1：该 episode 已经实际发生的结果链

初始化只使用 H_before 和初始公开观察/目标：

    (C,h_0^k,log w_0^k) = Init_phi(H_before,o_0,g)

C 是由可学习记忆编码器产生的参考上下文，h 是可学习递归状态。当前 episode 的事件不再同时进入这个初始化先验又重新乘一遍似然。决策 reader 仍可读取完整真实历史；**神经读取一个参考，不等于新增一份独立似然证据**。

每个真实事件只有一个 ID，在本 episode 的过滤状态中只能吸收一次。工作槽位仍为96个，不是历史条数上限。内存缓存只在相同世界版本、连续真实链上有效；跨版本重新从真实数据计算，不能把旧隐藏状态直接当新模型状态。

## 3. 先预测，再吸收实际结果

保留本模型的“episode 内固定潜在分量 k”假设，不偷换成已识别的因果类别。对当前实际观察到的唯一基本量：

    ell_t^k = log p_phi(m_t,d_t,g_t,y_t^obs | C,h_t^k,o_t,a_t,k)
    log Z_t = logsumexp_k(log w_t^k + ell_t^k)
    log w_(t+1)^k = log w_t^k + ell_t^k - log Z_t
    h_(t+1)^k = GRU_phi(h_t^k,o_t,a_t,y_t^obs,m_t,g,d_t)

可见性、终止、目标达成及连续基本量的条件分解沿用 V223；连续未观测维度用协方差子矩阵边缘化，不把缺失当0事实。先用 w_t/h_t 预测、选择实际行动，拿到外部结果后才更新 w/h；标签不能提前进入输入。

权重保持 float64 对数形式，不按小概率阈值永久删除分量。神经计算仍为 float32；用于加权输出的极小权重仍可能下溢，日志后验本身不被截断。

这是贝叶斯过滤在固定分量（转移矩阵为单位阵）情况下的递推，不是新的推断定理。基础参考：[State Space Models: A Modern Approach, HMM filtering](https://probml.github.io/ssm-book/chapters/hmm/hmm_filter.html)。本项目的神经条件模型、记忆分区与运行接线是工程设计，不能把标准公式当成该结构已有效的证据。

## 4. 与训练似然的一致性

由归一化常数连乘：

    sum_t log Z_t
      = logsumexp_k(log w_0^k + sum_t ell_t^k)

所以训练损失直接为 `-sum(log Z_t)`，与在线预测调用同一个 `observe` 内核。任意中段 s..t 从真实先前链构建 w_s,h_s：

    NLL(E_s:t | H_before,E_0:s-1) = -sum_(q=s..t) log Z_q

它不能重新把 s 当成新 episode。中段梯度可以穿过先前条件状态（本轮参考实现不截断 BPTT）；长段训练的内存和截断策略仍待决定，不伪称已经解决规模问题。

在已知同一模型下，不同真实证据可以使后验更集中，也可以使它重新分散。例如初始(.5,.5)，似然(.9,.1)得到(.9,.1)，再来(.1,.9)回到(.5,.5)。因此这里没有“记忆越多就强制更自信”的规则。**这只证明代数允许双向变化，不证明未训练似然已校准。**

## 5. 神经网络与实践闭环

网络保留 V224 的约2047万参数，不为凑体量增加层。修改的是数据流：

    实际历史 → 分区参考记忆与当前段证据 → 递归状态/后验
         → 条件预测 + 可学习决策记忆读取 → 候选/实际行动
         → 外部结果 → 同一个过滤内核 → 下一动作

候选生成、停止/试验/采用、实际后续信用分配仍可训练。实际状态缓存每个真实事件更新一次；训练可从冻结原始事件重建，不把 serialized state 当 live issued 对象。

反思试验重新从失败前的公开状态启动，但它是**新的实际试验分支**：可参考已有失败事实，不伪称延续已经终止的原 episode。此分支初始化包含之前已经发生的所有事实，之后自身事件只吸收一次。主任务持续链、重置试验、候选创建前缀在日志中明确区分。

想象以当时真实过滤状态为起点。想象结果不能进入真实过滤器或事实银行，不能拿自己的预测反复抬高对实际世界的确信。有限开放环模拟及未来动作集合的局限仍保留；本轮没有实现一般闭环规划。

## 6. 范围与不可忽略的限制

- 过滤式依赖当前神经似然和固定 k 假设；模型错配仍可能让后验自信地出错。k 概率不是“某个原因导致失败的比例”，多个真实原因无需加起来为1。
- 当前连续链要求同一目标、无穿插的外部事件；不支持静默忽略中途另一条任务提供的新事实。混合/穿插证据需要单独定义条件化顺序。
- 目标记忆编码器是 learned prior，不是从空白推导的完整贝叶斯后验；过去不同 episode 的知识通过它学习，本轮无训练。
- 实际 runtime 缓存避免重复过滤本段前缀，但完整历史 reader 仍有成本；离线可微参考重建未优化成长序列系统。
- 校准、因果发现、SLEEP 长期巩固、行为收益、保留旧能力都没有由本轮前向/反向检查证明。
- V224 的实际目标/成本策略损失仍属 RL 风格优化接口，不自动代表严格无奖励纯反馈组；本轮也不采用标量权重。

## 7. 事前有限验证

两新初始化种子137/149；每个种子2条源任务，长度分别5、7，每条之后2条同长度的新普通任务；源任务起点x0=-3用于真实失败路径覆盖。每个失败最多2次单步真实试验。主任务72实际步，试验最多8步，总上限80；不修改旧实验、不更新参数、不按结果重新选场景或重试。

使用变量数量的公开合法动作集（2/3/5循环），结构化数值环境，不做游戏适配。检查实际行动前状态、离线同前缀、完整/中段训练似然三者一致；同一新数据上只读比较旧式重初始化公式，量化断点但不比较算法收益。检查双向后验更新、重复事件拒绝、实时缓存一次吸收、真实信用梯度保持以及想象不污染事实。额外思考诊断每种子最多一次、深度2，不调用环境。
