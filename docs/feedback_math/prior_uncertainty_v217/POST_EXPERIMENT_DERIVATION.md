# V217 实验后推导：不确定性不等于降低所有置信度

本文在V217首次实验完成后写入，不能冒称事前假设或已验证的新方法。未修改执行源码、原数学文档或contract。

## 1. 实际否定了什么

新共享先验在本小基准中没有带来明显成功率提升。可靠性收缩降低了纯噪声任务的概率误差，但在有规律任务中增加预测误差并略拖慢早期改善。因此，不能把“概率更平缓”直接当成“不确定性处理更正确”。也不能从局部过度自信的错误案例推断所有预测都过度自信。

## 2. Brier风险推导

二元结果Y~Bernoulli(q)，预测p的期望平方损失为

    E[(p-Y)^2] = q(1-q)+(p-q)^2。

若统一使用p_eta=(1-eta)p+eta/2，风险变化为

    Delta = 2 eta (p-q)(1/2-p) + eta^2(1/2-p)^2。

如果1/2<p<q，两个项都非负（eta>0且p!=1/2时严格正），预测本来不够自信，再向1/2拉只会更差。若q=1/2，则适当收缩可以降低偏差。q只用于数学与评价端说明，学习器不能得到真实q。

V217不同eta还有不同来源权重，不能把整个网络粗写成一个公共eta。所以另做同记录计算：保持该时刻H、F和全部来源权重，把显式收缩暂时移除，其预测恰为p0=lambda H+(1-lambda)F；对比实际p与p0的核MSE，只隔离本次直接概率变换，不重算训练轨迹或声称获得新策略成绩。

## 3. 记录提供的证据

部分条件失效的原V216在真最优动作上的平均成功预测约.79815，环境真实成功概率为.9。新版共享可靠性组合在同状态不收缩时约.79076，收缩后约.77883。本记录内，直接收缩使核MSE额外增加约.00203585；完整新旧核MSE为.03139677→.03649903，不能将全部差值归为这一个直接项。

纯噪声环境则相反：同状态直接收缩降低核MSE约.00314976；完整新旧为.00659159→.00350251。成功率仍同约49.73%，不能从概率误差改善声称学会不可学的动作优势。

## 4. 对后续训练的约束，而不是立即再加一轮网格

下一候选不应仅允许向均匀分布收缩。可考虑恒等初始化的条件校准：

    logit p_phi = exp(a_phi(x,z)) logit p + b_phi(x,z)，初始a=b=0。

这允许变尖、变平及偏置修正，恒等初值不预先损坏原预测。z只能是预测前可观察的样本支持、分歧、历史适用性等信息，不能使用正确动作或未来结果。它只是后续候选公式，尚未实现、训练或证明有效；不据当前开发结果挑一个温度宣称解决。

训练任务j应区分support前缀S_j、后续training-query Q_j与独立保留任务。损失为sum_(j,t in Q_j) -log p_phi(y_jt | F_j,t-1,x_jt,a_jt)。每条事件的预测必须在该结果进入状态前形成；query若用于后续支持只能在预测损失记录后增加一次。外层训练重复epoch是对同一经验风险求解，不增加样本量或再次调用事实观察接口。

当前V217的96个先验参数已接通这种预测损失的梯度，但没有运行优化器；编码器与H/F仍主要是解析/统计模块，不能宣称全网络训练完成。任何未来训练出的修改仍须用新的实际对照检验再决定采用，不能仅因训练损失下降就替换旧模型。
