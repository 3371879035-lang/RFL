# V217：共享先验、预测可靠性与一次证据原则

2026-11-11。本文先于新网络和实验保存。目标是为后续训练建立可微参数接口，而非把当前解析构造误称为已经训练的通用模型。

## 1. 证据定位与本轮假设

V216部分失效场景：16次后74.41%→72.41%，128次后79.98%→82.18%，四点评均值基本不变。固定0可减少回摆，却在真实规律恢复后的最初16次落后。不能据此证明所有问题都来自先验。

待检验的两个断点：(a)每个条件格重新学习速率，重复支付冷启动复杂度；(b)H/F的概率可能过于自信，偶然结果使来源比值骤变。本轮做2×2机制消融，不同时增加探索、历史量、训练轮数或隐藏原因输入。

## 2. 共享的是“调整速度和概率可靠性”，不是动作答案

继续使用公开条件分组G及格c_G(x)，历史H、当前F预测，gamma_r∈{0,.002,.02,.2}。
新增可靠性假设eta_b∈{0,.25,.5}；无可靠性层的消融只保留eta=0。

    s_(b,e)(y|x,a) = (1-eta_b) p_e(y|x,a) + eta_b/K
    v_(c,r,b,e) = (1-gamma_r) w_(c,r,b,e) + gamma_r/2
    l_(G,r,b)(y|x,a) = sum_e v_(c_G(x),r,b,e) s_(b,e)(y|x,a)

eta不是推断出的真实噪声率，也不保证概率已校准。它表示“允许原预测过于尖锐”的有限预测假设；仍保留不收缩的eta=0，不固定把所有结果说成噪声。三点网格是工程师事前选择的有限空间，不做结果后搜索。

令L_(c,r,b)为访问该格的实际结果对l的累计log likelihood。可训练先验头给出rho_phi(G,r,b)=softmax(theta_G)，本轮theta=0且不进行优化器更新。

### 共享型（新假设）

    L_(G,r,b) = sum_(c in G) L_(c,r,b)
    W_(G,r,b) ∝ pi(G) rho_phi(G,r,b) exp L_(G,r,b)
    p_hat = sum_(G,r,b) W_(G,r,b) l_(G,r,b)

每个G内所有格共享一个速率/可靠性假设，但各格H/F适用性状态w仍独立。某处历史失效不直接把其他格的历史判死刑。共享本身是假设，在异质条件下可能有负迁移，必须与局部版本比较。

### 局部型（消融与V216退化）

    Z_(G,c)=sum_(r,b) rho_phi(G,r,b) exp L_(c,r,b)
    q_G ∝ pi(G) product_(c in G) Z_(G,c)
    rho_(G,c,r,b) ∝ rho_phi(G,r,b) exp L_(c,r,b)
    p_hat = sum_G q_G sum_(r,b) rho_(G,c_G(x),r,b) l_(G,r,b)

eta=0且先验均匀时，局部型在数学上退化为V216。不把共享型预设为胜者。

## 3. 同一结果进入多层，不等于多份独立证据

行动前缓存全部预测。结果y出现后，只对访问格执行：

    w'_(c,r,b,e) = v_(c,r,b,e) s_(b,e)(y) / l_(G,r,b)(y)
    L'_(c,r,b) = L_(c,r,b) + log l_(G,r,b)(y)

再由上述边际化公式重新计算权重；最后F学习该事实一次。不能额外再把G的边际似然乘到L里。因为

    posterior(r,b,e|y) = prior(r,b) v_e s_e(y) / p(y)

归一化后的来源更新与假设更新中的l会抵消，原观测因子只出现一次；不是把同一个结果当三个独立实验。H/F是替代预测解释，不将其似然相乘当成两名独立证人。

历史只构建H一次，不用最终拟合的H给同一历史回顾打分来初始化适用性或可靠性。共享先验的在线证据来自当前真实行动；未访问格可以借用已经获得的超参数证据，但不增加其访问次数或伪造当地样本。

## 4. 可检验的复杂度及不确定性

固定参数、相同观测动作序列下：共享模型的log loss至多为任一固定G,r,b预测器损失 -log pi(G)-log rho_phi(G,r,b)。等先验时超参数代价log(4B)，不是每格一次。局部型允许每格不同r,b，但支付每个访问格的相应先验代价。共享节省复杂度，不保证实际得分更高；不允许把不同策略的收益套进这条界。

对每个结果指示变量，以完整混合成分j=(G,r,b,e)权重omega_j、概率p_j计算：

    within = sum_j omega_j p_j(1-p_j)
    between = sum_j omega_j (p_j-p_hat)^2
    within+between = p_hat(1-p_hat)

输出名为“成分内结果波动”和“成分间预测分歧”。这是模型内全方差恒等式，**不宣称已经识别真实环境的偶然/认知不确定性**；H/F内部参数分布未在此完全展开。用真实结果的log loss、Brier及评价端概率误差检验，而不凭方差输出宣布校准完成。

## 5. 历史身份、重放和未来训练

相同事实id、相同内容的导入/重放幂等，不增加统计量；相同id不同内容报错。内容相同但id不同的真实重复实验仍是不同事件，不能按内容去重。id需由环境提供稳定身份，本模块不能发现调用者给旧事件伪造新id。

参数theta与证据缓冲区L/w分离。可微forward和预测NLL连接到theta；本轮只做autograd及有限差分检查，optimizer step=0。未来训练按任务/时间拆分：支持集建立状态，后续查询集计算预测损失；评估集不参与先验学习。跨epoch重复计算同一经验风险不等于多采样，不得调用observe再次增加证据。改变theta后从L重新计算边际权重，不把旧posterior再当新prior叠加相同证据。

本轮仅先验头已可训练；关系选择/事实计数/离散执行不是已经端到端可微的深度学习器。后续训练H/F或编码器需保存行动前预测或重建合法前缀，不能用后验拟合值追认先前成绩。SLEEP式蒸馏将来应单列训练目标和实测采用，不在本轮伪装已经执行。
