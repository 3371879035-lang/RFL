# V222 实验后补充：工作似然不等于已校准的联合概率

这是运行后对假设范围的补充，不回改事前 V14 文档、运行字节或失败记录。

V14 的持久假设公式仍成立：同一片段内固定假设 k，逐步累积，再在 k 上混合。实现中单步条件核采用多个预测头相加，包括后继观察、反馈、即时目标达成和终止。这个乘积只有在所建模的条件独立关系适用时，才能解释为适当的联合似然。

本轮向量接口明确存在多个语义相同的视图，例如 `feedback[0]=goal_met`、`feedback[5]=terminal`、`feedback[1]=next_observation[0]`。它们没有增加新的环境事件，却在多头监督中被再次使用。事件 ID 去重和目标前缀隔离解决了节点身份/时间泄漏，不自动解决语义重复。

如果 f 是真实基本结果 y 的确定视图 T(y)，应有

    p(y,f | H) = p(y | H) delta[f=T(y)]，

而不是把 p(y|H) 与另一个独立拟合的 p(f|H) 当两份独立实证相乘。这并不说明多任务辅助预测不能用；说明其加权监督目标应称复合损失，不能直接把其混合权重或方差当成已经校准的后验置信度。

后续建模的合理方向是：保持基本事件身份与观测视图来源；对确知的重复视图不重复计入证据似然；对未知的相关反馈学习联合/条件分布。辅助头可以保留用于表征学习，但明确区分辅助损失与证据概率。这里描述的是训练信号结构，不是替模型指定应选择什么动作。

另一个具体边界是未来反馈可见性：实测训练接收 feedback_mask，当前想象更新却使用全一 mask。未来应把可见性视为模型要学习/给定的观测过程，不能把生成的隐藏反馈当作届时一定能看到的信息。原始假设权重不被想象追加更新，解决了自造证据的一部分问题，但不等于这个观测过程已经建好。

因此，本轮可交付的是有明确训练通路的多步网络和真实实践接口；不是所有先验/不确定性/信息相关性问题已经解决的最终算法。这些限制不靠再跑同一批未训练接线实验来消除。
