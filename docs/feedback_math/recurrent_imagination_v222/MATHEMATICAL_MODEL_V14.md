# V222：历史条件下的多步推演与真实轨迹学习

先于代码和实验保存。V221的长记忆、完整实践证据、一致比较继续保留；本轮补多步内部推演及其可训练动力学，不执行优化器。

## 1. 需要避免的错误

1. 不能把一步预测反复拼起来，却每一步偷偷更换一个有利的世界假设。
2. 不能让候选控制码直接改变物理后果预测；它只能经由选了不同动作影响后果。
3. 不能把模拟产生的节点计入事实数，或用自己生成的结果给真实置信度追加证据。
4. 不能让行动目标通过梯度把预测器改成“更好看的世界”。
5. 模拟内的策略不能预先知道真实决策者看不到的世界假设编号。

## 2. 共同的序列模型

从真实历史前缀H编码记忆，形成pi_k(H)、初始工作状态h_0^k。每个假设k贯穿整个片段：

    (x_(t+1), f_t, terminal_t) ~ p_theta(. | x_t, a_t, h_t^k, H, k)
    h_(t+1)^k = GRU_theta(h_t^k, x_t, a_t, x_(t+1), observed_f_t, mask_t, goal)。

真实轨迹训练使用真实后继/反馈更新h；内部推演使用模拟后继/反馈更新临时h。两者使用同一个条件核、GRU和终止预测头；数据来源由外层类型与存储边界区分，不把“这是想象”变成可以美化物理规律的输入。

真实序列的联合似然为：

    L_world = -log sum_k pi_k(H) product_t p_theta(actual_t | actual_prefix_t, H, k)。

同一k内先累积整个片段的对数似然，然后只做一次混合logsumexp。不能改成product_t sum_k pi_k p_k，否则每一步都允许重新抽世界假设。目标事件及其后继不出现在H里，GRU只依次读取已经发生的真实前缀。

这里是共享有限假设的工作模型，不是证明了完整贝叶斯后验。Gaussian连续反馈头对离散反馈仍是工作似然；终止采用Bernoulli头。未训练时不声称预测已校准。

## 3. 多步推演不是拥有隐藏信息的策略

每个候选保留K条固定假设的预测路径，并使用共同外源噪声比较不同候选。候选码只进入Actor，不进入物理核。

本轮采用开放环行动序列：在每一想象深度，Actor汇总所有假设的可见预测表示，选一个动作，同候选的存活假设共用这个动作。它不会根据未观察到的k各选一个完美动作。真实执行仍重新读取当前实际观察与合法动作，内部计划不作为环境许可。

模拟使用调用时提供的动作目录，不声称已经预测未来可用动作集合。是条件推演，不是证明未来轨迹可行。真实接线每步仍由环境提供实际动作。

原始pi_k保留在推演记录里；模拟终止只停止该路径的继续展开，不对事实库的样本量、原始置信度或真实参数作更新。网络另有可训练的“继续想/停止想”头，资源预算只规定本轮最大深度。模型终止与停止计算是两种不同事件。

## 4. 三类节点与两个梯度通路

- 事实节点：真实事件，按id唯一保存。
- 工作状态：每个假设的临时GRU状态，不作为新事实。
- 推演节点：带真实来源前缀、模型版本、假设编号、父节点、动作、模拟结果/方差的独立记录；不能加入事实库。

世界/记忆参数theta只从实测轨迹似然学习。策略参数phi包括Actor、候选、推演读取、计算停止与实践选择/采用；它们读取停止梯度的物理预测与原始编码。另设可训练证据适配器，避免隔离世界梯度时把决策表征的可学习性也切断。

    grad_theta L_policy = 0
    grad_phi L_world = 0。

这是本版本的训练接口选择，不是所有反馈学习必须如此。代价是决策目标不能直接优化物理共享表征，需要实际训练评估。

## 5. 离散推演选择的训练信号

本轮不把离散动作伪装成可微“分数动作”。记录内部停止/动作选择的log概率与外源噪声。冻结世界快照、使用新鲜实际反馈时，可以把内部选择、试验选择、实际动作选择组成计算-行为路径，以实际结果A监督：

    L_policy = -stopgrad(A) [sum log pi_phi(internal choices) + log pi_phi(real choices)]。

这是score-function接口，方差可能大；不是已经解决跨版本离线重要性采样。只拿冻结的旧候选码反传不能训练当时的生成器，需要重建保存的生成前缀；本轮仅验证当前图的梯度路由和实测序列训练入口，不伪称完整训练器已完成。

推演摘要影响是否值得实际试验，不提供新候选的采用资格。Adopter只使用事实证据；未经真实执行的候选仍不能采用。得到新实际试验后，后续推演重新从更新后的真实前缀开始，不把旧想象追加为真实经验。

## 6. 范围与参考

本地、无游戏专用规则的向量接口；保留可配置宽度/记忆工作节点/假设数/候选数。先补序列学习和多步推演，不因参数更大宣称智能提升。SLEEP仍是实际历史回放/蒸馏接口；完整训练、独立实践验证、长期巩固效果尚未执行。

相关而非复现：[PlaNet](https://proceedings.mlr.press/v97/hafner19a.html)研究从经验学习动力学与多步规划，[Dreamer](https://arxiv.org/abs/1912.01603)研究潜在想象中的行为学习。本版本采用自己的事实/推演分离、实际采用边界和梯度隔离，不称为DreamRSI或SLEEP原论文实现。
