# V221：可学习长记忆与可比较的实践证据

2026-11-11；在新网络实现和实验之前保存。目的仍是为后续训练搭建基础，不用随机初始化成绩判定反馈学习好坏，不执行优化器。

## 1. 从V220实际源码发现的缺口

- `MemoryBlock`对全部N个节点做self-attention，单次读取含N²注意力项。V220最多25个实际节点，不能支持长记忆的计算结论。
- `PracticeAgent.receipts[candidate.id] = ...`只保留该候选最新一次回执；`trial_summary`的样本数写为常数1。原始事实库没有丢历史，但采用头的直接证据接口会覆盖先前试验，不能明确区分“试一次”与“反复验证、有成有败”。
- `reflect`只允许一次候选试验，没有同等的“再试当前做法”动作。将触发反思的失败直接当作基线均值，会因只在失败后启动而偏置。它可以用于解释问题，不能冒充无选择的效果对照。
- 当前控制码未随参数版本绑定；未来训练改变编码空间后，旧码不应不经检查继续沿用。

随机策略接近均匀不是需要靠加层“修掉”的程序错误。本轮修上述结构缺口，保留未训练状态。

## 2. 事实节点与计算工作节点分开

事实集合仍为唯一实际事件E={e_i}，记录条件、行动前预测、实测后果、缺失、来源和前驱。编码X=Encoder_theta(E)，前驱关系和时间特征保留。

引入S个可训练工作节点Z，单层计算：

    Z' = CrossAttention(Z, X, X)
    Z'' = SelfAttention(Z', Z', Z')
    X' = CrossAttention(X, Z'', Z'') + X。

配合归一化和逐节点前馈网络。注意力分数项为2NS+S²；S固定时随N线性增长。动作查询再读取全部X'，成本O((A+1)N)。工作节点不是事实、不写入记忆库，也不作为S份独立观测累积置信度。原始事件不因S个槽位而截断，仍可恢复、逐事件查询；不保证有限瓶颈不丢语义，也不声称端到端运行时间只由注意力分数项决定。

这借鉴[Set Transformer的inducing attention](https://proceedings.mlr.press/v97/lee19d.html)，不是新的复杂度定理或论文复现。保留每条事实的输出位置，而非只保存压缩摘要当事实。

## 3. 实践应保留完整证据集，而不是最新结果

一次失败开启实践会话s。控制码z_0代表当前做法，z_1...z_C是网络生成的候选。触发失败只作为上下文，不加入任何一臂的新实践样本集。

    E_(s,j) = {实际执行j得到的唯一事件，按真实id去重}。

同一候选可以被再次试验；所有真实结果追加保存，失败结果也不覆盖或丢弃。各臂的事件编码、条件读取共享参数；读取还接收log(1+唯一实测次数)。计数只是数据语义，不规定“n次后必采用”，也不当作有效独立样本数。

模型每步选择：停止实践、试当前做法、试某个候选。选择条件包括当前上下文、所有臂的实际证据、剩余预算。有限预算是资源约束；不是我们逐次指定它该试谁、试几次。

采用头看到对称的当前做法/候选证据。保留当前做法始终合法；新候选至少有一次匹配的实际执行才有采用资格。这只保证实践来源，不保证一次试验足够或效果优于原做法。

## 4. 比较目标与不确定性不能偷换

为未来训练增加直接比较头：对两个不同臂的新实测目标结果差D_ab=Y_a-Y_b预测Gaussian分布。均值通过反对称参数化、方差通过对称参数化：

    mu_ab = (g(h_a,h_b)-g(h_b,h_a))/2
    v_ab = softplus((r(h_a,h_b)+r(h_b,h_a))/2)+epsilon。

这预测的是下一对实际结果之差的分布，不是“真实因果效应已确定”的置信区间，也不是均值差的标准误。对角均值为0；对角方差若保留则表示同做法两次独立结果的差，并非同一个随机变量减自身。训练与决策比较只使用不同臂。

    L_compare = 0.5 * [log(2*pi*v_ab) + (D_ab-mu_ab)^2/v_ab]。

输入的记忆与实践证据必须严格早于两个目标事件中较早者；目标结果不能同时出现在支持集。实践结果的公共目标值由任务目标提供，不用隐藏最优动作作标签。V220事实NLL、Actor/选择策略损失和巩固接口继续保留。

只有数据、干预条件和随机化合适时，比较才支持效果推断。自适应抽样/停止会影响样本均值，不能因记录了propensity就声称自动去偏；参见[自适应采样的偏差研究](https://proceedings.mlr.press/v84/nie18a.html)。本轮不计算科学置信区间或宣称比较头已经校准。未来评估需另留未用于选择的实际运行。

## 5. 参数版本与经验存续

事实跨参数版本继续保留，使用当前编码器重新编码。候选码与试验归属绑定参数指纹。切换到新参数版本时，清除旧当前控制码、关闭旧候选的采用资格；旧事实和旧回执保留，不改写为新版本实践。新版本可从旧事实重新提出候选，再真正执行。

这不是按任务结果设置保守阈值，而是防止不同潜在空间的码被误当作同一个动作方案。

默认宽度256、2层工作节点注意力、64个可配置工作节点、8预测成分、3候选。参数量由实现统计。无优化器，检查长记忆、完整多次证据、比较头梯度/对称性、训练前缀隔离、参数版本与真实多步任务中的局内记录/局外实践。实际试验为失败终止处的局部动作再执行，不伪称重新运行整条历史路线。
