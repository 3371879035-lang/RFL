# V221 比较一致性修订：反对称不够

在首次V221运行及14项检查通过后，继续检查数学含义发现：任意反对称g(a,b)不能保证同一公共目标的期望差可加。真实定义若为mu_ab=E[Y_a-Y_b|H]，则在同一个条件信息集H下必须有mu_ab+mu_bc=mu_ac。

读取已保存的46个采用矩阵（没有重跑模型/环境），发现最大循环残差4.2532337829470634e-06，位于`changed_noisy/seed37/session/0`的(0,1,3)：-0.0009366275044158101 + 0.0007179201347753406 与 -0.00022296060342341661 不相等。差距小不是本次随机策略表现差的解释，但结构不满足期望差恒等式，原14项检查也不足以证明这一点。原运行、源码、输出不改。

## 修正

共享全部可见上下文，先预测各方案的相对价值势phi_a，再作差：

    mu_ab = phi_a - phi_b。

因此反对称、零自差及循环一致性同时成立。phi本身存在公共平移不可识别性；比较只需要相对势，不声称学到了绝对价值。

不再任意逐对输出方差，而先构建联合Gaussian的正半定协方差：

    Sigma = L L^T + diag(v),  v_a=softplus(s_a)+epsilon
    Var(Y_a-Y_b | H) = ||L_a-L_b||² + v_a + v_b, a != b。

对角差是同一随机变量减自身，严格为0。若研究同一方案两次独立运行的差，应另外建立两个观测随机变量；本比较损失只使用不同臂，不能混用两种对角解释。

比较NLL仍以更晚、未出现在支持集中的实测差值训练。联合Gaussian只是候选工作分布，公共因子/残余项不自动等于可识别的认知/随机不确定性；对离散goal_met差值也不是精确三分类概率。真正训练需选择相应观测似然或检验工作似然的校准。结构正半定和一致性不能替代校准与效果验证。

## 实现与验证范围

新增独立`consistent_network.py`，继承V221已实际运行的记忆/实践模块，仅替换比较参数化。保留旧首跑；新增定向有限验证，两个新初始化种子，每个4个三步任务，失败处最多4次局部实践，最多56次环境调用。校验联合协方差、差值恒等式、比较NLL与全模块梯度；不重跑V221的长记忆测量或旧运行矩阵。仍无优化器。
